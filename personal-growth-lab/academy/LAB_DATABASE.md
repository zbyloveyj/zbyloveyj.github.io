# 全球科研导师与研究团队长期候选库

公开入口：[labs.html](labs.html)。正式数据入口：[data/labs.json](data/labs.json)（主清单及其 `dataParts` 构成完整库）。来源清单：[data/lab-sources.json](data/lab-sources.json)。人工事实更正叠加层：[data/lab-editorial-overrides.json](data/lab-editorial-overrides.json)。来源补充输入：[data/lab-source-additions-2026-10-26.json](data/lab-source-additions-2026-10-26.json)。自动巡检：[data/lab-monitor.json](data/lab-monitor.json)。可重复构建方法见[维护 README](../../.github/lab-directory/README.md)。

## 收录目的与范围

按研究方向、团队身份与可查证的科研信息建立长期候选库。**不以当前招生、招聘、欢迎咨询或有无名额为收录条件。** 有相关方向且仍有可查证研究活动的导师和团队，可以用于提前一至两年准备联合培养、访问、博士后或后续学术合作。没有当前职位不会从库中删除，也不能推断两年后一定有名额。

2026-10-21 的 `2026.10.21-mentor-v7` 版本共有 **41,446 条候选记录**，为上一版的 **3.32 倍**：保留全部 **12,491 个基线稳定 ID**，净增 **28,955 条**，补充 **1,160 条已有记录**。其中，新增国科大目录候选220条、补证190条；从29,569条相关NIH项目PI候选中合并834条已有身份、净增28,735条。主机构／项目依托单位在中国大陆的记录有 **3,322 条**，记录共涉及 **53 个国家／地区、32,622 个来源 URL**。这轮扩充明显偏向美国科研项目；项目国家／单位不等同个人当前工作地点。候选条目不等于已逐人核验的博士导师数、独立实验室数或全球排名。

覆盖全球脑科学、计算神经科学、神经影像、脑机接口、计算生物学、AI for Biology、AI Virtual Cell、单细胞与空间组学、基因组学，以及本轮深入补充的微生物组、微生物生态、肠脑轴、计算精神病学、精准精神病学、医学人工智能、神经免疫和代谢组学。继续拓展国家、机构和重点 PI，不设五国限制。院系／研究所／网络、附属医院和独立实验室按实际性质标注；联合任职不等同主聘单位。科研实力需结合具体代表成果，不给全部收录者统一贴“全球顶尖”排名标签。

## 四类证据

`schemaVersion: 1` 保持兼容。一般候选使用 `candidateStatus: long_term`；明确作为历史贡献保留的条目使用 `historical`。证据深度、研究方向、任职状态与接收机会分别记录。

| `evidenceLevel` | 本轮数量 | 支持的判断与边界 |
| --- | ---: | --- |
| `reviewed` | 18 | 保留原详细卡和稳定 ID，含任职、核心问题、至少两篇可核验代表作、技术平台、适配分析、技能缺口、起步项目、适配边界及逐条来源。A/B/C 描述原卡的能力衔接距离，不是导师实力等级。 |
| `research_profile` | 932 | 已逐人整理官方个人、研究组、明确归属个人的项目或成果证据。官方人物专题、共享组页面及仅能读取搜索索引的情况须保留范围说明；此层不代表每人均已读网页全文、审阅全部论文或完成适配评估。 |
| `official_directory` | 11,761 | 核对官方导师、研究组或专题研究人员目录中的身份和明确可见的研究说明；未逐人补齐全部 Research 页面、代表作或指导资格。目录身份不证明排名、经费或当前招生。 |
| `project_record` | 28,735 | 官方相关科研项目中的具名PI、具体研究题目和项目来源。主题标签由项目标题与研究目标句自动提取，未逐人完成个人研究、现任主聘及博士指导资格核验；项目单位明确标为“项目依托单位”。 |

除 `reviewed` 外的三类记录使用 `tier: D`，表示尚待原详细卡式的适配分析。不得为了填充字段编造论文、项目、排名、联系资格或职位。空的 `papers`、细分标签以及机会 `status: unknown`、机会 `verifiedAt: null` 均有明确含义。有独立来源的成果可以记录在 `assessmentEvidence.outputs`，不因此自动升级为 `reviewed`。

学生、博士后、普通支持人员、技术平台或机构本身不能冒充独立 PI。临床研究网络成员可按已核实的研究身份保留，并注明 `recordType`、`roleNote`，不从成员资格推断主聘单位或独立博士指导权。退休、荣休、访问、产业、历史等身份由 `roleStatus` 和具体职务说明；历史研究线索不表示当前仍独立招生。综合生命科学教师只有目录身份时保留宽泛方向，不自动归入 AIVC、BCI 或计算生物学。

资料链接可以是官方目录列出的 HTTP／HTTPS 页面；来源证据优先 HTTPS。缺少单独个人页时保留实际目录／锚点并注明，不能猜个人网址。官方人物专题可以支持明确归属的个人信息，机构新闻首页不能充当个人资料。403、页面外壳、官方搜索索引或其他网页读取方式须保留实际读取方法和范围限制；不能把搜索索引写成全文复核。真实分页、异步数据入口、解析规则、可用 hash 和日期在来源元数据中保留。

## 合并分类、具体研究与大规模浏览

主导航由386个原始研究标签改为 **6个主领域、42组合并方向**：微生物与微生态、组学与计算生物、脑科学与精神健康、脑机接口与生物医学工程、人工智能与数字医学、基础与转化生命科学。原始标签保留在详情和搜索中；跨学科归属允许重叠，领域计数不能相加。选定主领域后，具体方向选项联动显示可用人数。旧原始方向链接继续兼容。

新增“研究资料”筛选，可筛选有具体研究说明／题目、有方法标签、有代表成果，以及资料待补充的记录。本轮逐人补充西湖大学109份、深圳先进院合成生物学45份研究档案，合计154份；对这些升级档案，以明确个人研究替换旧的宽泛目录标签，未单独整理的模态、尺度和研究设计仍留空。项目候选直接展示可点击的具体研究题目、年份与来源。国科大交叉培养方向明确标为培养项目关联，不冒充个人方法核验。

“本轮更新”筛选分别查看新增候选和补充过的已有记录；新旧筛选条件均随公开链接保留，并可保存为筛选方案。重点领域覆盖表分别显示候选条目、机构／研究单元、研究依据和方法标签数，不用资料稀疏度冒充科研实力。官方目录支持全文搜索和每批32项逐步展开，卡片按页渲染。

本轮个人研究补证保留106个已核对的中文别名，连同已有中英文姓名对应参与搜索、卡片展示与公开CSV。院系筛选统一清华、北大、复旦、南科大等已核实大学名称；附属医院和不同中科院研究所保留各自机构身份。多重任职的具体说明与来源在详情中展示，目录关联不自动当作主聘。

页面先读取 `data/labs.json.gz` 主清单，再按清单读取21个版本分片；每个文件独立支持 gzip → JSON 回退，最多4个并发请求，并显示加载进度。全部分片的版本、数量、稳定ID和总数验证完成后才显示完整统计；任一失败会提示重试，不把部分数据当作全库。维护工具另校验SHA256及压缩前后的字节一致性。原始标签和搜索索引使用缓存，关键词输入有150毫秒防抖。个人名单备份支持100,000条、64 MiB文件，原有收藏与笔记ID保持兼容。公开CSV新增主领域、合并方向、证据类型、项目题目／年度／ID／来源及机构信息类型，不包含私人笔记。

## 六轴筛选与七项证据

`facets` 有六个独立轴，跨轴筛选取交集；缺少标签不自动补成匹配。

| 字段 | 页面含义 | 填写依据 |
| --- | --- | --- |
| `domains` | 研究方向 | 具体研究主题和有说明的导航父类，与 `directions` 同步。 |
| `methods` | 研究方法 | 实际使用或开发的实验、计算、统计及工程方法。 |
| `diseases` | 疾病／健康问题 | 来源明确涉及的疾病、症状或健康问题。 |
| `modalities` | 数据与实验模态 | 数据、测量和实验干预模态，包括影像、组学、行为，以及明确列出的刺激或干预方式。 |
| `researchScales` | 研究尺度 | 分子、细胞、回路、群落、宿主、人群等层次。 |
| `studyDesigns` | 研究设计 | 实验、队列、纵向、临床试验、方法开发等明确设计。 |

`assessmentEvidence` 每项包含 `dimension`、具体说明、来源 URL 和核验日期。七个维度为 `research` 研究问题、`methods` 方法与技术、`outputs` 代表成果、`resources` 开放资源、`translation` 实验／临床转化、`collaboration` 跨学科合作、`training` 培养与申请路径。同一维度可以有多条来源，但“已整理维度数”只计一次。缺项表示尚未整理，不能解释为没有该能力；不凭声誉编满七项，也不合成导师实力总分。

自选权重的匹配率为“已匹配标签的权重之和 ÷ 全部所选有效权重之和”；权重为零的条件不参加计算。**它只反映本库已知标签覆盖，不能衡量科研质量、指导质量或录取概率。** 未记录与已记录但不匹配的条件都需要进一步确认；没有有效条件时不显示匹配分数。

## 身份与去重

稳定id随记录保留，不能每次按排序重编号。严格避免两类错误：

1. 不同人可以同名。西湖大学两位Jian Yang、Stanford与McGill的Jun Ding分别保留，除非有明确同一身份的证据。
2. 多个 PI 可能共享同一目录 URL；目录锚点需要保留。A*STAR BII、McGill 等不得仅按 URL 合并。官方专属个人页与规范化姓名一致，或经过明确人工身份核验时才合并。共同领导同一实验室时按人保留，并以 `sharedGroup`、`profileScope`、`evidenceScope` 说明共享关系。例如 Helsinki 的 Anne Salonen／Willem de Vos，以及 UCL 的 Jonathan Roiser／Oliver Robinson；不能把同组人数换算为独立课题组数。

NIH内部以官方 `profile_id` 作为初始身份键，并对8组有额外官方依据的多ID同人进行合并，全部原ID保存在 `nihProfileIds`。跨来源合并要求规范化完整姓名与机构一致且没有冲突；缺失中间名、不同中间名和不确定单位均不能强行合并。对独立审查发现的疑点使用阻止合并名单。项目依托机构不会覆盖既有官网任职。即使经过这些检查，未解析的同人候选仍可能存在，不能把条目数写成严格去重后的全球人数。

新增来源可以补充 `sources`、`affiliations`、`aliases`。目录网络成员资格只能写为网络关联，不据此宣称主聘单位。更新机构信息时保留原有 ID、历史机构状态和变更依据；原单位接收条款不能自动沿用到新单位。例如 Bassett 转任 Yale 后，原 UPenn 接收说明不再作为当前机会依据。

## 研究方向与机会

研究方向优先依据个人Research部分、具体研究组名称或专题目录；不根据网页全站导航、共同作者论文或关键词偶然出现给PI贴标签。显微成像不自动等同神经影像；普通微生物学不自动等同微生物组；一般单细胞/深度学习不自动等同AI虚拟细胞。AIVC细分直接虚拟细胞项目、扰动预测方法及图谱/评价支撑。

项目扩充读取NIH RePORTER官方API的23个相关研究院所、113页及51,741个活跃项目记录；依据明确相关的标题和实际研究目标筛选，排除F/K/T等培养项目、行政支持及明显学生／博士后角色。旧项目职务可能过时，明确的当前官网教授身份可以纠正误排除。筛选后保留29,569条PI候选，再与原库合并。每人最多展示2项代表项目；`projectsObserved`只表示本轮匹配的核心项目数，不表示全部经费、项目或产出。

项目标签使用保守语义规则区分双极细胞／双相障碍、免疫荧光／免疫学、病毒载体／微生物学、神经网络／脑科学、分子AI／临床医学AI、单细胞基础模型／AI虚拟细胞。独立审查读取六领域各5个项目，加25个高风险项目，共55个不同完整摘要；该抽样用于发现和修正规则，不能视为全库逐人深度复核或总体误差估计。

机会仅为附加信息：`recruiting`（明确当前招聘且没有关闭/过期证据）、`inquiry`（明确欢迎相应身份咨询）、`unknown`（待核验）。只有联系方式不足以标咨询，机构泛招聘不能标为组内名额。普通博士入学、博士联合培养/访问、博士后分别核验；无截止日期额外注明名额未确认。机会变化不删除方向候选。

实际核对内容后才更新相应 `verifiedAt`；HTTP 200、脚本重跑和正文 hash 变化都不能替代事实复核。抓取时间、解析时间、人工内容核验时间需区分；目录身份、个人研究、具体证据和机会的日期不能相互覆盖。旧缓存保留真实日期和 hash；失败、使用缓存及搜索索引读取须留有元数据。更改记录写入 `history`。超过 30 天、截止、机会来源变化或读取失败，只降低机会确定性，不删除导师。

## 个人关注名单与隐私

收藏、准备阶段与私人笔记仅保存在当前浏览器的独立 `localStorage` 键 **`growthlab.research-directory.notebook.v1`**。阶段包括持续关注、待读代表作、重点了解、准备申请、已核对资格；单条笔记最多 3,000 字。该键不覆盖课程进度、旧笔记和其他已有存储键，也不自动上传或跨设备同步。

专用 JSON 备份包含收藏、阶段和笔记，应由用户自行保管。导入先验证类型、版本、ID、阶段、日期和长度，按稳定 ID 合并并保留 `updatedAt` 较新的整条记录；相同时间采用导入项。备份最多 100,000 条、导入文件最多 64 MB。浏览器存储不可用时提示用户导出。

公开分享链接不包含收藏条件、个人阶段和笔记。结果 CSV 仅含公开条目、研究证据和公开匹配信息，不含收藏标记、准备阶段和私人笔记。专用笔记备份与公开 CSV 是不同用途的文件。筛选、比较和公开数据加载本身不写入个人存储。

## 持续更新

`.github/workflows/lab-evidence-monitor.yml` 每天 UTC 22:17（北京时间次日 06:17）巡检；GitHub 可能排队延迟。详细卡证据和官方目录优先检查；其余个人资料及科研项目证据 URL 按最早 `checkedAt` 轮巡，**每批额外最多 96 个 URL**。96 不是全部来源数，也不代表每位 PI 每日都核验。`batch` 给出本批、轮巡和未检查数量；各来源保留自己的检查时间，批次时间不代表所有页面同日检查。

NIH RePORTER项目页是动态页面，巡检使用官方项目API核对对应项目ID及内容，以不高于每1.1秒一次的速率请求；不对页面空壳建立成功基线。只保存内容hash、状态、时间和有界错误，不公开缓存的网页全文。第一次成功只建立机器基线；页面发生变化在实际复核前持续保留提示。403/验证码是读取失败，不代表研究组关闭。巡检不会自动推断招生或招聘。

每日工作流只提交公共`lab-monitor.json`。由GITHUB_TOKEN写入的监测commit可能不触发Pages，因此浏览器比较站点副本和公开raw GitHub feed，选择最新批次。团队数据由正常内容提交发布；不创建与既有Pages竞争的部署工作流。

2026-10-26 的编辑复核采用独立叠加层 `data/lab-editorial-overrides.json`，不重写不可变的 v7 分片或改变稳定 ID。该层记录逐条 `changeId`、日期、修改理由、前后状态、官方来源与读取方式；Python/Node维护加载器及浏览器加载器均在校验基础目录后应用同一叠加层。当前修正包括：依据EMBL官方讣告将Peer Bork保留为 `historical`（已故、历史科研贡献），不再显示为当前导师；为Nick Ramsey补入两篇2026年UMC Utrecht官方研究成果，并重新确认2022年旧博士后公告已过期。岗位状态仍为 `unknown`，不推断当前名额。新来源先写入小型补充清单，再由每日维护工作流幂等合并到大型 `lab-sources.json`；本轮来源补充已于2026-10-26合并入正式清单，现有32,622条来源记录；web open阅读不冒充直接HTTP抓取或hash核验。

现有每周研究任务继续复核来源变化、补充新导师与代表成果；范围包括所有已收录国家及其他相关地区。首要目标是维持长期候选地图，当前职位仅为附加更新。自动研究任务账户、任务ID及用户私人背景不写进公开仓库。不得自动联系导师、发送邮件或提交申请。

`.github/lab-directory/` 保存目录采集方法及经人工复核的研究输入。自动采集输出是**待复核候选**，不能直接覆盖正式库。重新抓取记录抓取时间、解析时间、缓存和失败状态，不把旧缓存标成当天核验。解析失效或数量异常减少时保留正式数据，人工检查后再更新。本轮人工补证从不可变基线重建，具体命令见维护 README；不能反复把已合并的新库当成本轮基线。
