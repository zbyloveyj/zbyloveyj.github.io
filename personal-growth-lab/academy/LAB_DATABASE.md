# 全球科研导师与研究团队长期候选库

公开入口：[labs.html](labs.html)。正式数据：[data/labs.json](data/labs.json)。来源清单：[data/lab-sources.json](data/lab-sources.json)。自动巡检：[data/lab-monitor.json](data/lab-monitor.json)。可重复构建方法见[维护 README](../../.github/lab-directory/README.md)。

## 收录目的与范围

按研究方向、团队身份与可查证的科研信息建立长期候选库。**不以当前招生、招聘、欢迎咨询或有无名额为收录条件。** 有相关方向且仍有可查证研究活动的导师和团队，可以用于提前一至两年准备联合培养、访问、博士后或后续学术合作。没有当前职位不会从库中删除，也不能推断两年后一定有名额。

2026-10-21 的 `2026.10.21-global-v3` 版本共有 **2,663 条候选记录**：在保留原有 **2,371 个稳定 ID** 的基础上新增 **292 条**，并给 **16 条已有记录**补充研究证据。本轮 308 条人工输入已经包含这 16 条更新，补证数量不能再加一次总数。这里统计人物／团队条目，**不是 2,663 个互不重叠的独立实验室**；共同负责人、临床研究人员和企业研究负责人按真实身份说明。

覆盖全球脑科学、计算神经科学、神经影像、脑机接口、计算生物学、AI for Biology、AI Virtual Cell、单细胞与空间组学、基因组学，以及本轮深入补充的微生物组、微生物生态、肠脑轴、计算精神病学、精准精神病学、医学人工智能、神经免疫和代谢组学。继续拓展国家、机构和重点 PI，不设五国限制。院系／研究所／网络、附属医院和独立实验室按实际性质标注；联合任职不等同主聘单位。科研实力需结合具体代表成果，不给全部收录者统一贴“全球顶尖”排名标签。

## 三层证据

`schemaVersion: 1` 保持兼容。一般候选使用 `candidateStatus: long_term`；明确作为历史贡献保留的条目使用 `historical`。证据深度、研究方向、任职状态与接收机会分别记录。

| `evidenceLevel` | 本轮数量 | 支持的判断与边界 |
| --- | ---: | --- |
| `reviewed` | 18 | 保留原详细卡和稳定 ID，含任职、核心问题、至少两篇可核验代表作、技术平台、适配分析、技能缺口、起步项目、适配边界及逐条来源。A/B/C 描述原卡的能力衔接距离，不是导师实力等级。 |
| `research_profile` | 250 | 已逐人整理官方个人、研究组、明确归属个人的项目或成果证据。官方人物专题、共享组页面及仅能读取搜索索引的情况须保留范围说明；此层不代表每人均已读网页全文、审阅全部论文或完成适配评估。 |
| `official_directory` | 2,395 | 核对官方导师、研究组或专题研究人员目录中的身份和明确可见的研究说明；未逐人补齐全部 Research 页面、代表作或指导资格。目录身份不证明排名、经费或当前招生。 |

后两层的 `tier: D` 表示尚待原详细卡式的适配分析。不得为了填充字段编造论文、项目、排名、联系资格或职位。空的 `papers`、细分标签以及机会 `status: unknown`、机会 `verifiedAt: null` 均有明确含义。有独立来源的成果可以记录在 `assessmentEvidence.outputs`，不因此自动升级为 `reviewed`。

学生、博士后、普通支持人员、技术平台或机构本身不能冒充独立 PI。临床研究网络成员可按已核实的研究身份保留，并注明 `recordType`、`roleNote`，不从成员资格推断主聘单位或独立博士指导权。退休、荣休、访问、产业、历史等身份由 `roleStatus` 和具体职务说明；历史研究线索不表示当前仍独立招生。综合生命科学教师只有目录身份时保留宽泛方向，不自动归入 AIVC、BCI 或计算生物学。

资料链接可以是官方目录列出的 HTTP／HTTPS 页面；来源证据优先 HTTPS。缺少单独个人页时保留实际目录／锚点并注明，不能猜个人网址。官方人物专题可以支持明确归属的个人信息，机构新闻首页不能充当个人资料。403、页面外壳、官方搜索索引或其他网页读取方式须保留实际读取方法和范围限制；不能把搜索索引写成全文复核。真实分页、异步数据入口、解析规则、可用 hash 和日期在来源元数据中保留。

## 六轴筛选与七项证据

`facets` 有六个独立轴，跨轴筛选取交集；缺少标签不自动补成匹配。

| 字段 | 页面含义 | 填写依据 |
| --- | --- | --- |
| `domains` | 研究方向 | 具体研究主题和有说明的导航父类，与 `directions` 同步。 |
| `methods` | 研究方法 | 实际使用或开发的实验、计算、统计及工程方法。 |
| `diseases` | 疾病／健康问题 | 来源明确涉及的疾病、症状或健康问题。 |
| `modalities` | 数据与实验模态 | 数据、测量和实验干预模态，包括影像、组学、行为，以及明确列出的刺激或干预方式。 |
| `researchScales` | 研究尺度 | 分子、细胞、回路、群落、宿主、人群等层次。 |
| `studyDesigns` | 研究设计 | 实验、队列、纵向、临床试验、方法开发等明确设计。 |

`assessmentEvidence` 每项包含 `dimension`、具体说明、来源 URL 和核验日期。七个维度为 `research` 研究问题、`methods` 方法与技术、`outputs` 代表成果、`resources` 开放资源、`translation` 实验／临床转化、`collaboration` 跨学科合作、`training` 培养与申请路径。同一维度可以有多条来源，但“已整理维度数”只计一次。缺项表示尚未整理，不能解释为没有该能力；不凭声誉编满七项，也不合成导师实力总分。

自选权重的匹配率为“已匹配标签的权重之和 ÷ 全部所选有效权重之和”；权重为零的条件不参加计算。**它只反映本库已知标签覆盖，不能衡量科研质量、指导质量或录取概率。** 未记录与已记录但不匹配的条件都需要进一步确认；没有有效条件时不显示匹配分数。

## 身份与去重

稳定id随记录保留，不能每次按排序重编号。严格避免两类错误：

1. 不同人可以同名。西湖大学两位Jian Yang、Stanford与McGill的Jun Ding分别保留，除非有明确同一身份的证据。
2. 多个 PI 可能共享同一目录 URL；目录锚点需要保留。A*STAR BII、McGill 等不得仅按 URL 合并。官方专属个人页与规范化姓名一致，或经过明确人工身份核验时才合并。共同领导同一实验室时按人保留，并以 `sharedGroup`、`profileScope`、`evidenceScope` 说明共享关系。例如 Helsinki 的 Anne Salonen／Willem de Vos，以及 UCL 的 Jonathan Roiser／Oliver Robinson；不能把同组人数换算为独立课题组数。

新增来源可以补充 `sources`、`affiliations`、`aliases`。目录网络成员资格只能写为网络关联，不据此宣称主聘单位。更新机构信息时保留原有 ID、历史机构状态和变更依据；原单位接收条款不能自动沿用到新单位。例如 Bassett 转任 Yale 后，原 UPenn 接收说明不再作为当前机会依据。

## 研究方向与机会

研究方向优先依据个人Research部分、具体研究组名称或专题目录；不根据网页全站导航、共同作者论文或关键词偶然出现给PI贴标签。显微成像不自动等同神经影像；普通微生物学不自动等同微生物组；一般单细胞/深度学习不自动等同AI虚拟细胞。AIVC细分直接虚拟细胞项目、扰动预测方法及图谱/评价支撑。

机会仅为附加信息：`recruiting`（明确当前招聘且没有关闭/过期证据）、`inquiry`（明确欢迎相应身份咨询）、`unknown`（待核验）。只有联系方式不足以标咨询，机构泛招聘不能标为组内名额。普通博士入学、博士联合培养/访问、博士后分别核验；无截止日期额外注明名额未确认。机会变化不删除方向候选。

实际核对内容后才更新相应 `verifiedAt`；HTTP 200、脚本重跑和正文 hash 变化都不能替代事实复核。抓取时间、解析时间、人工内容核验时间需区分；目录身份、个人研究、具体证据和机会的日期不能相互覆盖。旧缓存保留真实日期和 hash；失败、使用缓存及搜索索引读取须留有元数据。更改记录写入 `history`。超过 30 天、截止、机会来源变化或读取失败，只降低机会确定性，不删除导师。

## 个人关注名单与隐私

收藏、准备阶段与私人笔记仅保存在当前浏览器的独立 `localStorage` 键 **`growthlab.research-directory.notebook.v1`**。阶段包括持续关注、待读代表作、重点了解、准备申请、已核对资格；单条笔记最多 3,000 字。该键不覆盖课程进度、旧笔记和其他已有存储键，也不自动上传或跨设备同步。

专用 JSON 备份包含收藏、阶段和笔记，应由用户自行保管。导入先验证类型、版本、ID、阶段、日期和长度，按稳定 ID 合并并保留 `updatedAt` 较新的整条记录；相同时间采用导入项。备份最多 5,000 条、导入文件最多 5 MB。浏览器存储不可用时提示用户导出。

公开分享链接不包含收藏条件、个人阶段和笔记。结果 CSV 仅含公开条目、研究证据和公开匹配信息，不含收藏标记、准备阶段和私人笔记。专用笔记备份与公开 CSV 是不同用途的文件。筛选、比较和公开数据加载本身不写入个人存储。

## 持续更新

`.github/workflows/lab-evidence-monitor.yml` 每天 UTC 22:17（北京时间次日 06:17）巡检；GitHub 可能排队延迟。详细卡证据和官方目录优先检查；其余个人资料及研究证据 URL 按最早 `checkedAt` 轮巡，**每批额外最多 96 个 URL**。96 不是全部来源数，也不代表每位 PI 每日都核验。`batch` 给出本批、轮巡和未检查数量；各来源保留自己的检查时间，批次时间不代表所有页面同日检查。

只保存正文hash、状态、时间和有界错误，不公开缓存的网页全文。第一次成功只建立机器基线；页面发生变化在实际复核前持续保留提示。403/验证码是读取失败，不代表研究组关闭。巡检不会自动推断招生或招聘。

每日工作流只提交公共`lab-monitor.json`。由GITHUB_TOKEN写入的监测commit可能不触发Pages，因此浏览器比较站点副本和公开raw GitHub feed，选择最新批次。团队数据由正常内容提交发布；不创建与既有Pages竞争的部署工作流。

现有每周研究任务继续复核来源变化、补充新导师与代表成果；范围包括所有已收录国家及其他相关地区。首要目标是维持长期候选地图，当前职位仅为附加更新。自动研究任务账户、任务ID及用户私人背景不写进公开仓库。不得自动联系导师、发送邮件或提交申请。

`.github/lab-directory/` 保存目录采集方法及经人工复核的研究输入。自动采集输出是**待复核候选**，不能直接覆盖正式库。重新抓取记录抓取时间、解析时间、缓存和失败状态，不把旧缓存标成当天核验。解析失效或数量异常减少时保留正式数据，人工检查后再更新。本轮人工补证从不可变基线重建，具体命令见维护 README；不能反复把已合并的新库当成本轮基线。
