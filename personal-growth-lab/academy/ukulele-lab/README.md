# 尤克里里30天弹唱 · 成长学院

课程入口：https://zbyloveyj.github.io/personal-growth-lab/academy/ukulele-lab/

## 课程目标与可行性

零基础学习者，每次约50分钟，按30次训练的顺序，尝试完成周杰伦《安静》《晴天》和逃跑计划《一万次悲伤》的完整简化弹唱。可以分成两个25分钟练习段，约25小时为建议投入量，不是成功率承诺。允许看谱、整体移调、降低速度和简化前奏；原版指弹前奏、原速与舞台表现列为后续提升。

课程假定使用四弦高G标准调弦G4–C4–E4–A4，并且能通过本人合法获取的歌谱或原作者教学明确整首歌的和弦和结构。若尚不能稳定清唱目标旋律，须在每日歌曲段中先做清唱，必要时延长课程。男中音DGBE琴、其他特殊调弦不可直接按本课音高示范使用。

| 训练顺序 | 内容 | 主要验收 |
|---|---|---|
| 第1–7天 | 调弦、坐姿、读和弦图、C/Am/F/G、四拍节奏、换和弦 | 固定尝试次数下清晰且准时的转换，16小节连续节奏 |
| 第8–14天 | 《安静》：慢速主歌、分句、进入与副歌连接 | 所选版本完整弹唱的首次录音与分项自评 |
| 第15–21天 | 《晴天》：较密的句子、扫弦、主副歌衔接 | 全曲按结构演奏，错误后可以恢复 |
| 第22–27天 | 《一万次悲伤》：演唱调、长句、呼吸与持续伴奏 | 完整唱段、稳定伴奏与舒适音区 |
| 第28–30天 | 三曲间隔复习、模拟演出与结课录制 | 每首分别通过实操标准，不用平均分掩盖弱曲 |

每课都有完整讲解、分配到分钟的跟练步骤、独立原创技能练习、量化验收、证据要求、选择题与解析、未达标补练及可选升级。第7、14、21、30天是阶段检查点。未达标时保留当前进度，重复最弱的两小节；不需要追赶日历或补罚双倍时长。

## 页面和工具

- 学习首页与30天路线：查看下一次练习及练习完成/实操自评两类进度。
- 每日日课：操作步骤打卡、任务计时、和弦图、节奏格、原创练习循环、实际训练数据、录音证据和复盘。
- 三首歌档案：保存自己的谱本版本、来源、调性、主歌副歌时间与难点小节。
- 练习工具：调音参考音、和弦合成音、节奏/原创练习示范、节拍器、麦克风录音、回听和下载。
- 阶段与结业测评：回听后人工打分，网页进行规则汇总。分数与反馈不代表音频识别或教师认证。
- 练习复盘：展示实际填写的数据、缺失值与下一次补练建议。同一和弦对、相同速度与节奏型才适合前后比较。
- 完整可打印教材与[Markdown讲义](downloads/ukulele-30-days.md)。

参考音与练习音色由浏览器合成，不是原唱、原曲录音或真实尤克里里采样。网页不会用麦克风自动调弦，也不会自动判定音准、和弦、拍点或歌曲完成度。

## 测评规则

量表为节奏25%、和弦与转换20%、弹唱协同20%、旋律音高20%、结构与完成度15%。各维0–5分，按`分数/5×权重`加总，空白表示尚未测评，不能当作0分或满分。

每首分别满足总分至少80、所有维度至少3、完整唱段顺序正确、一镜到底、0整段重来和非空录音证据记录，才显示自评达标。三首均通过才完成课程的弹唱目标。练习任务勾完、小测全对、时间达到或页面浏览完成，都不自动表示会弹。音高比较应以本人选定的调和八度安排为基准，合理移调本身不算跑调。

量表、时间、速度范围和阶段顺序是本课程的教学设计，不是来自临床试验或受控研究的训练效果保证。老师或熟练演奏者的独立复核可提高自评分数的可信度。

## 曲谱与资料

基础知识参考Kala、Fender的原始教学材料，逐条来源见`assets/music-data.js`和课程资料页。歌曲页面链接到原作者教学和91谱对应曲目，记录核验范围。外部谱站部分功能可能需登录或付费，旧视频也可能失效；可以使用自己已有的合法完整弹唱谱。

本站不转载第三方完整歌词、旋律谱或编配谱，也不把通用C–Am–F–G练习循环标成任何一首歌的真实完整伴奏。曲目和弦清单是技能预备表，实际和弦、换点和段落以锁定谱本为准。吉他六线TAB与指法不能直接照搬到四弦琴。

## 记录与备份

记录保存在当前浏览器的`yixindao.ukulele-academy.v1`，不会上传到GitHub或自动跨设备同步。导出JSON后可在另一设备导入，按每条记录的更新时间合并。备份包含日课、曲目档案与测评，不包含录音音频。保存失败时网页明确提示，当前记录可导出。

麦克风仅在点击录音并授权后使用。录音只在当前页面内存中，回听后请下载文件；刷新/离开会丢失未下载音频。不支持网页录音时可以使用手机录音，在证据栏填写真实文件名。学院首页只读取本课程的已练课次数，完整数据请在本课程内单独备份。旧课程存储键保持原样。

## 维护与核验

`assets/course-data.js`是逐日内容来源，`assets/music-data.js`是指法、节奏、曲目和量表来源。修改后执行：

```bash
node personal-growth-lab/academy/ukulele-lab/tools/build_materials.cjs
node personal-growth-lab/academy/ukulele-lab/tools/validate.cjs
node personal-growth-lab/academy/tools/validate.js --full-catalog
python personal-growth-lab/academy/ukulele-lab/tools/browser_check.py
```

构建器生成30份`course/dayNN.json`、完整Markdown和学院目录桥接。验证检查内容与目录一致性、20种和弦的实际音高组成、节奏拍格、空评分、最低维度门槛、缺证据、任务进度、备份合并及页面交互。沿用仓库main分支的GitHub Pages发布，不创建第二个发布流程。
