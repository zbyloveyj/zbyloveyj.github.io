# 尤克里里30天弹唱 · 第二版

一心问道成长学院的完整练习课程。公开入口：
https://zbyloveyj.github.io/personal-growth-lab/academy/ukulele-lab/

## 学习目标与默认版本

零基础学习者按30次训练、每天约50分钟，学习周杰伦《安静》《晴天》和逃跑计划《一万次悲伤》的完整简化伴奏弹唱。总建议投入25小时；30天是课程顺序，达标取决于真实作品。可以看谱、降低速度、预先固定舒适八度和使用变调夹。原版指弹前奏与舞台级表现属于后续提升。

课程默认四弦高G标准调弦G4–C4–E4–A4，三首歌均有课内C指型和弦伴奏编配。主歌、衔接、副歌、间奏和结尾按完整演出顺序呈现，不需要购买外站谱。曲目页支持小节高亮、合成伴奏播放、段落循环、BPM和变调夹调整；下载的独立HTML曲谱可离线查看与打印。

| 课次 | 内容 | 作品 |
|---|---|---|
| 1–7 | 调音、C/Am/F/G、四拍、换和弦与弹唱分工 | 专项录音和基础实操检查 |
| 8–14 | 《安静》主歌、衔接、副歌与完整结构 | 第一首完整录音 |
| 15–21 | 《晴天》半小节换和弦、八分扫弦、E7→Am与结尾 | 第二首完整录音 |
| 22–27 | 《一万次悲伤》12小节主歌、16小节副歌及衔接 | 第三首完整录音 |
| 28–30 | 交错复习、三首分别录制的模拟演出、结课评估 | 三份独立完整作品与补练计划 |

共30课、182个任务块、365个具体操作步骤、60道理解题。旧版任务ID和步骤数量保留，不清除已有打卡。

## 录音和真实音频分析

每课上方、曲目页、测评页和录音库都提供录制或上传。使用MediaRecorder采集，在IndexedDB保存多条音频；可回放、下载、设置A/B循环、点击分析问题时间段回听，或导出含音频的完整ZIP备份。刷新页面后可从本机录音库找回。浏览器阻止存储时明确显示临时状态，提示先下载。

每条最多10分钟和20MiB；录制约599秒停止，以留出编码封装余量。不支持网页录音的浏览器可上传手机录音。麦克风仅在点击录音并授权后开启。

音频先解码成原采样率单声道，由Worker内分析引擎处理；长录音全程扫描能量与音头，音高与和弦使用分布在全程的有界采样。

| 模式 | 实际任务与输出 | 边界 |
|---|---|---|
| 闷音节奏 | 每拍闷弦一下；音头间隔、脉冲速率、拟合拍点网格偏差、疑似空缺/重复、训练参考分 | 不把八分扫弦、外放节拍器或混音的脉冲直接当成学生准确率 |
| 单音音准 | 独立G4/C4/E4/A4；中位Hz、音分偏差、可辨帧比例、训练参考分 | 保留实际八度；不是整首歌旋律跟踪或自动调弦 |
| 单和弦 | 纯乐器单个和弦；频谱音级、候选、目标模板相似度 | 不判定指法、转位、逐根弦清晰度或整曲换点 |
| 完整弹唱 | 真实录音、录音质量及有条件拍点线索 | 人声琴声未分离且无旋律参照，不自动产生整曲音准、唱词、完成度或结业分 |

静音、噪声、过短、削波风险、候选不明确等情况下拒绝能力评分，显示未评分及原因；`null`不显示为0。可信度为启发式等级，未建立真实麦克风录音准确率。合成测试用于验证功能和拒绝评分边界。

## 正式听评和结业

三首完整作品分别使用五维人工回听量表：节奏25%、和弦20%、弹唱配合20%、歌唱音准20%、结构15%。每项0–5分，空白表示未评。

每首需要：总分≥80、每一项≥3、选定版本所有唱段顺序完整、一条连续录制、0次整段重来、真实可找回的录音证据。三首均满足后才显示自评达标。专项参考分、题目答对、打卡或练习分钟不自动转换为结业结果。

## 登录与私密同步

GitHub Pages入口直接使用本机练习和课程。个人训练室采用ChatGPT真实登录、服务器端用户身份、D1进度与元数据、R2音频保存。当前训练室为账号所有者私密访问；录音不进入公开GitHub仓库。

个人训练室：
https://yixindao-ukulele-studio.lemony-fern-4058.chatgpt.site/

公开课程与个人训练室不同源。首次迁移需在公开课录音库导出完整ZIP，到训练室导入后同步；不能假称浏览器会自动跨域读取旧记录。日后在训练室的新进度、录音与分析自动同步。进度按各条记录更新时间合并，上传重试幂等；同步失败保留本机内容。每人默认250MiB云端录音空间。

进度仍沿用`yixindao.ukulele-academy.v1`与schema 1。录音单独存于`yixindao.ukulele-recordings.v2`。原进度JSON只含打卡、量表与笔记；完整ZIP包含这些内容、原始音频及报告。退出账号不删除共用设备的本机副本。

## 曲谱说明

`score-data.js`是课程原创简化和弦伴奏编配，以公开资料核对和声事实后重排为新手练习版本；不是第三方谱面复制，也不是原录音的逐音还原。不会收录完整歌词、受保护的完整旋律或第三方编配图。参考来源保留在曲目页的折叠说明，完成课程不依赖外链访问。

《安静》90小节、《晴天》85小节、《一万次悲伤》92小节。全部为4/4，每小节和弦时值合计4拍；具体分段、重复与换点以课内编配为准。
