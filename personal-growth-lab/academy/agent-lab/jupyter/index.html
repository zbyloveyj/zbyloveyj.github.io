如何使用 Notebook？

方式一（推荐）：点击“在 Google Colab 打开”，无需本地安装；首次执行时连接运行环境。从第一格开始按 Shift+Enter 执行。

方式二（本地）：安装Python 3.10+，在终端执行 python -m pip install notebook 和 jupyter notebook，打开下载的 .ipynb。

方式三（系统学习）：先读本页的概念与逐步任务，再前往已有30天课程做综合实验。默认实验数据为虚构记录，真实LLM与PubMed均需要主动打开联网开关；API Key不能提交到公开仓库。
