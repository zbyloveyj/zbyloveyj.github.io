## 01 · 理解概念

### 未知问题应该有明确出口

课程材料没有涵盖某个问题时，系统应说明证据不足。默认问题询问未知疾病的治疗，这不在教学语料能够支持的范围内，因此不应产生确定的治疗建议。

默认运行会暴露一个真实失败：unknown一词命中E08中“未知token与成本”的笔记，status可能是answered，却没有提供关于疾病治疗的相关证据。应把它记为未知识别失败，不能将非空回答当成回答正确。再用完全无匹配的问题对照，才能看见当前拒答仅覆盖部分情况。

### 证据冲突需要先识别再解释

两份材料可能给出不同结论，原因可能是研究对象、方法、时间或定义不同。不能只保留排在第一位的来源，也不能简单投票决定哪个结论正确。

本课conflict_review使用有限关键字与规则触发提醒，帮助你看见冲突检查的位置。它不是语义矛盾检测器，不能可靠识别隐含否定、数值差异、跨句推断或研究设计差异。

### 没有告警不等于没有冲突

include_conflict控制是否加入课程预设的冲突案例。关闭后告警可能消失，但你只能得出预设触发条件没有出现，不能推断所有资料在科学意义上已经一致。

写一个当前规则会漏掉的反例，例如“改善10%”与“未达到预设阈值”可能需要上下文才知道是否矛盾。把反例留在案例册里，明确它尚未被自动化覆盖。

### 失败案例比一句总评更有用

将未知问题误匹配、冲突提醒和攻击检查分别记录输入、预期、实际结果与是否需要人工接管。失败类型越具体，后续改进越容易对应到检索、工具、提示或审核机制。

本课与第23课同样使用离线规则，不声称完成真实模型红队测试。演示时要同时说明挡住了什么、没测什么、当前规则会漏什么，让使用者理解接管条件。

**预期结果：**终端显示本课配置；键名与文件中的内容一致。

### 2. 运行本课基线

**为什么做：**保持默认设置的一次运行，是后续比较的参照。

执行命令，打开新生成的 outputs/day29.json。先检查 day、mode 和 result，不急着修改代码。

**预期结果：**结果写入 outputs/day29.json；主线 mode 明确为 offline，代表规则教学流程。

### 3. 识别误匹配，再对照零命中问题

**为什么做：**不能只看程序有没有报错，要检查它实际做了什么。

检查默认unknown_answer：unknown一词可能命中E08，但该笔记没有疾病治疗证据，应记为失败。随后运行下方无匹配问题，比较状态与引用；这只展示零命中时的拒答，不能修复默认样例的误匹配。

```text

python run.py ask "zxqv nebula recipe"
```

**预期结果：**默认样例出现无关E08摘录；对照问题为abstained。把两者记录成当前检索与拒答规则的边界。

### 4. 改变一个条件并比较

**为什么做：**主动制造可解释的变化，才能验证自己理解的机制。

完成下面“改一改”实验。对比基线与新结果，记录哪些字段改变、哪些保持稳定；不要同时改模型、材料和参数。

**预期结果：**留下一组前后结果和一句解释；失败状态也可以是正确的实验产物。

### 改一改 · 移除预设冲突样例，比较告警变化

- 先执行 python run.py day 29，将 outputs/day29.json 复制为自己的基线备份。

- 在 VS Code 打开 experiments.json，只修改 day29.include_conflict 为 false，保持其他键不变并保存。

- 执行 python -m json.tool experiments.json 检查语法，再执行 python run.py day 29。

- 对比两份结果，重点观察unknown_answer、conflict_review 与 attack_check；解释改变原因后恢复原设置或明确记录保留值。

**观察什么：**预设冲突触发条件不再出现时，conflict_review的结果相应变化；unknown_answer与独立攻击检查的职责仍分开。不要将无告警解释为语义上已无冲突。

**机制解释：**单变量实验只能说明当前规则对预设样例的反应，无法外推出对所有矛盾表达的识别能力。

## 常见问题

### 修改配置后结果没有变化

原因：改了其他天的字段，或编辑后尚未保存。

处理：核对 experiments.json 中的 day29，保存后重新运行；检查实际执行目录。

### 把受控失败误当成程序坏了

原因：本课实验主动制造了边界条件。

处理：先对照 expected 和状态字段，区分设计内拒绝与未处理异常；保留错误信息再修复。

## 自测与解析

### 1. 有限规则没有发现冲突，可以得出什么结论？

- A. 所有证据一致

- B. 本次输入没有触发当前规则

- C. 研究设计完全相同

- D. 无需阅读原文

**答案：B。** 规则覆盖面有限，无告警只能按实际检测条件解释。

### 2. 面对材料外治疗问题，最合理的输出是什么？

- A. 猜测一种疗法

- B. 说明证据不足并停止确定推断

- C. 引用任意无关材料

- D. 为了完整回答编造研究

**答案：B。** 证据边界应优先于回答完整度，尤其不能从教学语料推导不存在的医疗证据。

## 小词典

- **Failure case**：输入、预期和实际行为被明确记录的失败样例。

- **Conflict review**：对可能不一致的证据进行标记与复核的过程。

- **Blind spot**：当前实现或评估没有覆盖到的情况。
