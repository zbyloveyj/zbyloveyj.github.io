## 01 · 理解概念

### 阶段作品要有一条完整路径

一个可演示的作品至少要接收问题、检索资料、形成报告并返回可检查的状态。先把这些步骤接通，再考虑美化界面。你的演示对象需要知道问题是什么、材料来自哪里、什么条件下会停止。

本课把前面练习的证据检索与检查组合起来，产出 report 和 gate。主线使用固定小型教学材料与规则回答；报告能说明流程，但不能充当对真实论文全文的系统综述。

### 质量门应阻止不合格产物继续流转

质量门不是在报告末尾加一句“请核实”，而是把验收结果作为程序中的判断依据。缺少必要引用时，gate.valid 应当为 false，并列出具体错误。

单独检查引用存在仍然不够：存在的引用可能与论断不匹配，来源也可能过时。本课先验证一个能执行的最低标准，把语义支持、研究设计与偏差评估保留给人工审阅和后续扩展。

### 故意破坏输出，才能检查防线

如果每次都只运行正确样例，就不知道质量门遇到缺陷时是否真的工作。remove_citations 是一个受控开关，用于把候选报告中的引用移除，制造可重复的失败。

实验只改这个开关，其他问题与材料保持一致。对比报告正文和 gate.errors，你应当能解释为什么内容看起来流畅，程序仍应拒绝通过。失败案例是作品交付的一部分。

### 演示要包含成功、失败与边界

用两分钟讲清楚正常结果，再展示缺失引用导致的拒绝，最后说明它只能处理当前材料与规则覆盖的情况。这样的演示能让使用者知道何时可以信任流程，何时需要接管。

第14课作品验证最小闭环，第21课再增加编排与质量门。不要为了让演示一直成功而隐藏失败状态；记录一次明确拒绝，比只展示漂亮的最终段落更能说明实现。

## 02 · 一步一步做

**为什么做：**先知道程序读什么，后面才能解释输出为何改变。

**预期结果：**终端显示本课配置；键名与文件中的内容一致。

### 2. 运行本课基线

**为什么做：**保持默认设置的一次运行，是后续比较的参照。

执行命令，打开新生成的 outputs/day21.json。先检查 day、mode 和 result，不急着修改代码。


**预期结果：**结果写入 outputs/day21.json；主线 mode 明确为 offline，代表规则教学流程。

### 3. 沿输出检查机制

**为什么做：**不能只看程序有没有报错，要检查它实际做了什么。

格式化阅读输出，重点检查report 与 gate.valid、gate.errors。把一个输入参数和一个输出字段用箭头对应起来。

```text

```

**预期结果：**能够定位report 与 gate.valid、gate.errors，并用自己的话解释该结果。

### 4. 改变一个条件并比较

**为什么做：**主动制造可解释的变化，才能验证自己理解的机制。

完成下面“改一改”实验。对比基线与新结果，记录哪些字段改变、哪些保持稳定；不要同时改模型、材料和参数。

**预期结果：**留下一组前后结果和一句解释；失败状态也可以是正确的实验产物。

### 改一改 · 去掉引用，检验质量门是否真的拒绝

- 先执行 python run.py day 21，将 outputs/day21.json 复制为自己的基线备份。

- 在 VS Code 打开 experiments.json，只修改 day21.remove_citations 为 true，保持其他键不变并保存。

- 执行 python -m json.tool experiments.json 检查语法，再执行 python run.py day 21。

- 对比两份结果，重点观察report 与 gate.valid、gate.errors；解释改变原因后恢复原设置或明确记录保留值。

**观察什么：**候选报告的引用被移除，gate.valid 变为 false，errors 指出引用缺失；程序仍应保存可检查的实验结果。

**机制解释：**这是对质量门的反例测试。报告能生成与报告满足交付要求，是两项不同的判断。

## 常见问题

### 修改配置后结果没有变化

原因：改了其他天的字段，或编辑后尚未保存。

处理：核对 experiments.json 中的 day21，保存后重新运行；检查实际执行目录。

### 把受控失败误当成程序坏了

原因：本课实验主动制造了边界条件。

处理：先对照 expected 和状态字段，区分设计内拒绝与未处理异常；保留错误信息再修复。

## 自测与解析

### 1. 质量门发现缺少引用后，最合理的行为是什么？

- A. 照常交付并隐藏错误

- B. 返回失败与具体缺口

- C. 自动捏造引用

- D. 只改报告标题

**答案：B。** 质量门要影响流转并给出可修复原因，不能只装饰输出。

### 2. 引用字段非空能够单独证明什么？

- A. 结论一定正确

- B. 论文没有偏差

- C. 只证明通过了引用存在性这一项检查

- D. 所有结论都得到来源支持

**答案：C。** 存在性检查的范围有限，语义支持与研究质量需要额外评价。

## 小词典

- **Quality gate**：决定产物能否进入下一步的明确检查。

- **Negative case**：故意不满足标准、用于验证系统拒绝行为的样例。

- **Traceability**：从结论追溯到材料、步骤与参数的能力。
