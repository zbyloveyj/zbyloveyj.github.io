# CurateMicrobiota 模型卡

## 模型身份

版本：1.0.0。目的：支持成长学院 14 天课程中的代码学习和可复现实验。项目包含两个独立模型和一个适配机制演示，不共用权重。

| 模块 | 输入 | 训练目标 | 输出 |
| --- | --- | --- | --- |
| TinyGPT | UTF-8 字节序列，固定 256 项词表 | 因果下一字节交叉熵 | 下一字节 logits 与采样文本 |
| MaskedMicrobiomeEncoder | 固定 taxon 词表的 log 相对丰度，人工掩码 | 仅被掩码特征的均方误差 | 每个特征的重建值、样本向量 |
| LoRALinear | 小型人工线性回归数据 | 冻结原权重，仅学习低秩增量 | 低秩适配器参数 |
| TinyGPT SFT / LoRA-SFT | 固定训练/验证的原创短 prompt-response 对 | 仅回答字节与换行终止符的 CE；prompt/padding 为 -100 | 完整微调检查点，LoRA 模式另存适配器 |
| DPO 公式演示 | 固定 policy/reference 的 chosen/rejected 序列 log probability | 检查偏好目标的损失与梯度符号 | JSON 机制实验报告，不训练模型 |

TinyGPT 默认 context=64、width=64、heads=4、layers=2；菌群编码器默认 width=48、heads=4、layers=2。具体参数总量由运行时代码计算并写入报告；菌群参数量随训练词表大小变化。

## 数据与科学含义

默认菌群数据为固定随机种子产生的 240 个合成样本、120 个受试者、6 个研究和 48 个匿名分类特征。标签效应、研究偏移、零值及重复采样都是人工设定。任何默认 AUROC、重建损失或图形都不能支持真实疾病或真实物种结论。

默认语言文本为原创教学段落。训练与验证使用不同段落；文本规模不足以训练可靠的科学问答或微生物知识能力。该模型的作用是让学习者理解计算图、目标函数、优化和推理。

SFT 另用 10 个训练对和 4 个验证对，均为原创合成教学示例。从真实已训练的 TinyGPT 检查点开始，全参数或 rank-2 qkv LoRA 更新均可执行。回答监督与基座冻结由独立测试检查，检查点仅按验证回答损失选择。该规模不能证明通用指令跟随或生物医学事实准确性。DPO 只运行固定标量的公式和梯度检查，与真实偏好优化训练严格区分。

真实数据可接入 curatedMetagenomicData 或符合相同 CSV 合同的其他资源；需记录数据版本、分类方法、单位、队列与受试者标识、任务定义和各数据源许可。软件包许可不能自动涵盖所有底层数据。

## 评价协议

整个研究属于一个固定分区，同一受试者不能跨分区。特征筛选、尺度和均值仅用训练研究拟合。编码器按验证重建误差选检查点。下游探针分别只用训练标签拟合，按验证受试者 AUROC 选择正则化参数，固定 0.5 阈值。测试研究在模型选择完成后评价。

对照包括训练均值插补、log 丰度逻辑回归及未预训练的随机编码器线性探针。主要分类指标按受试者聚合；多次采样平均预测概率。报告 AUROC、AP、macro-F1、balanced accuracy、Brier、log loss、ECE 和研究内受试者 bootstrap 区间。

## 可以支持的结论

成功运行可以证明：依赖可用；数据合同与分组隔离得到检查；模型能够反向传播、保存、加载和生成；合成数据上的给定实验可复现；指定的因果遮罩、掩码与 LoRA 冻结性质通过测试。

## 尚不能支持的结论

本工程没有证明跨国家、跨疾病、跨测序平台的迁移能力，没有证明预训练必然优于常规模型，也没有发现微生物因果机制。注意力权重不自动等于生物学作用、特征归因或因果证据。词表上限、相对丰度闭合、测量零值与技术缺失、标签构成和研究批次都需要专门研究。

## 研究升级的验收条件

1. 在新的、公开记录来源的数据版本中建立疾病平衡和协变量覆盖的研究级划分。
2. 在多个外部研究和多随机种子上复现相对于简单方法的增益，报告未获益的任务。
3. 对词表、掩码率、零值处理、prevalence、架构大小、预训练与随机初始化作消融。
4. 按研究而不只是按样本估计不确定性；建立模型选择与最终测试的隔离记录。
5. 评价校准、亚群表现与数据覆盖，明确不能外推到的样本类型和分类层级。

## 工程边界

当前所有训练默认 CPU；没有自动网络下载、远程推理或 API 调用。Python requirements 给出兼容范围，实际运行报告记录解释器及包版本。保存的 checkpoint 只包含本项目模型数据；加载使用 `weights_only=True`。实验报告和学习者自己的数据应与源码分开管理。
