## 每一列都属于一个测量体系

假设两个研究都有一列名为某个物种，不能只靠名称相同就把数值拼接。分类单元的定义、参考数据库、比对和标记基因流程可能已经改变；同一个名称可能经历合并或拆分，不同名称也可能指向相近对象。MetaPhlAn 4的原始研究将物种级基因组集合纳入其分类框架，这提醒我们：版本升级不仅是软件速度变化，也可能改变可识别的生物范围。

建立数据契约时至少记录分析软件版本、参考数据库标识、分类单元ID与完整谱系、输出层级、丰度单位和样本处理来源。不要把属、种和物种级基因组集合当成完全等价的列。若必须跨版本整合，优先从一致流程重新处理可用原始数据；若只能用既有表，就明确映射规则、无法映射的比例和可能的信息损失。课程不承诺一个通用名称替换表能解决所有版本差异。

## 对齐不是取交集后悄悄补零

训练词表一旦确定，验证与测试按同一身份顺序排列。外部输入多出的列可以明确排除并报告保留质量，缺少的训练列则需要区分原因。若整列从未测量、被另一版本合并或被上游过滤，它不等于该队列所有受试者都没有这个物种。直接补零会把测量流程差异伪装成生物差异；有时模型恰好借此识别研究身份，得到看似出色的结果。

下面的代码用NaN保留缺失列，同时记录可观测掩码，真实观测到的零仍为零。它是数据工程诊断，不是可以直接送入当前编码器的输入；现有工程对缺失训练列默认报错。若研究需要支持缺失特征，应另外设计缺失嵌入、训练中的缺失机制和评价协议。输出还记录输入中未使用的列，避免对齐完成后忘记模型只看到了原组成的一部分。

```python
import numpy as np
input_names = ["taxon_B", "taxon_A", "taxon_new"]
vocabulary = ["taxon_A", "taxon_B", "taxon_C"]
x = np.array([[0.20, 0.00, 0.10], [0.00, 0.40, 0.20]])
assert len(input_names) == len(set(input_names))
lookup = {name: j for j, name in enumerate(input_names)}
aligned = np.full((len(x), len(vocabulary)), np.nan)
for j, name in enumerate(vocabulary):
    if name in lookup:
        aligned[:, j] = x[:, lookup[name]]
observed = np.isfinite(aligned)
report = {"missing": [n for n in vocabulary if n not in lookup],
          "unused": [n for n in input_names if n not in vocabulary],
          "retained_input_fraction": (np.nansum(aligned, axis=1) / x.sum(axis=1)).tolist()}
assert aligned[0, 0] == 0.0 and observed[0, 0]
assert np.isnan(aligned[:, 2]).all() and not observed[:, 2].any()
print(aligned)
print(report)
# NaN是明确的未知测量状态；不要将此诊断数组直接传入现有训练接口。
```

## 零、缺失和筛选分别改变什么

观测零可以来自真实缺席、有限测序深度下没有观测到、分析阈值或上游筛选，仅凭一个零通常不能确定是哪种机制。整列缺失则表示特征没有进入当前测量表；缺失标签表示结局未知，也不能当作健康对照。应尽量从上游记录获取检测、过滤与缺失原因，而不是事后从预测结果反推。不同零机制适合的统计假设可能不同。

prevalence过滤应在训练分区拟合，并记录分母是样本、受试者还是研究；拥有多次访视的人可能影响样本级出现率。可比较按受试者汇总的筛选规则，但不能为了让外部研究表现更好而查看测试标签后筛选。对每个研究汇报零比例、缺失比例、保留质量与测序相关信息，能帮助定位问题。删除全零特征、填补缺失和改变检测阈值是三个不同动作，应分别留下记录。

## 相对丰度不能恢复绝对微生物负荷

相对丰度是组成：分量描述彼此的比例，总量被约束或归一化。两个样本可以有完全相同的比例，却具有不同的绝对微生物数量；单个分量比例上升也可能来自其他分量减少。观察到比例变化时，结论应写清相对参考关系，而不是直接说某个物种绝对扩增。若研究目标需要绝对负荷，需要相应的额外测量与校正设计。

cMD的returnSamples在counts=TRUE时，按已核验源码将资源中的百分数丰度除以100、乘以read depth后取整；counts=FALSE保留相对丰度，仍须按版本核验数值单位，见第10课的官方分析导读。这是换算数值，不能自动当作最初比对到某物种的原始读段计数。比例、百分数、归一化功能丰度和原始计数也不能混在同一损失里。课程默认比例输入，只对元素做log1p和训练集标准化；它保留了工程可检查性，但并不宣称从此解决所有组合统计问题。

## CLR与ILR：转换的是相对关系

对严格正的D维组成x，CLR把每个分量的对数减去全体对数均值，即与几何平均的对数比。其分量之和为零，因此D个坐标实际位于D−1维子空间，协方差具有相应秩约束。ILR进一步选用这个子空间的一组正交归一基，得到D−1个无冗余坐标；基向量正交不保证这些坐标在观测数据中统计独立或互不相关。不同合法基会给出不同坐标解释，但都可以保留同一组合几何结构。

下面以三个分量演示两个平衡坐标、CLR与ILR往返以及整体尺度不变性。基向量和特征顺序必须随模型保存；改了物种集合却继续使用旧基，会改变含义。ILR维度少一不代表它自动比其他表示预测更好，解释某个平衡也要说明分子与分母对应哪些分类单元。零不能直接取对数，例子后半部分专门展示加入不同伪计数后的敏感性。

```text
clr(x)_j = log x_j − (1/D)Σ_k log x_k；ilr(x)=clr(x)V，VᵀV=I且Vᵀ1=0
```

```python
import numpy as np
x = np.array([0.2, 0.3, 0.5])
V = np.array([[1/np.sqrt(2), 1/np.sqrt(6)],
              [-1/np.sqrt(2), 1/np.sqrt(6)], [0, -2/np.sqrt(6)]])
def clr(a):
    a = np.asarray(a, float)
    if np.any(a <= 0):
        raise ValueError("CLR requires positive parts")
    loga = np.log(a)
    return loga - loga.mean(axis=-1, keepdims=True)
z = clr(x); u = z @ V
assert np.allclose(V.T @ V, np.eye(2))
assert np.allclose(V.T @ np.ones(3), 0)
assert np.allclose(u @ V.T, z)
assert np.allclose(clr(17*x), z)
print({"CLR": z.tolist(), "ILR": u.tolist()})
zero_example = np.array([0.0, 0.25, 0.75])
for epsilon in [1e-6, 1e-3]:
    closed = (zero_example + epsilon) / (zero_example + epsilon).sum()
    print("epsilon", epsilon, "CLR", clr(closed).round(3).tolist())
```

## 伪计数的单位、敏感性与遮蔽泄漏

给所有计数加一，与给比例加一，产生的变化完全不同。即使都在比例尺度上，固定伪计数也可能大于低丰度特征的真实信号，从而控制它们的对数比。应说明加在哪里、加多少、是否随后闭合，以及参数如何在训练域选择。可以做若干预先指定的敏感性分析，检查结论是否依赖一个任意数值；不能观察测试结果后选择让模型获胜的伪计数。

CLR适合作为部分监督基线的候选，但在掩码重建任务中需要额外小心。如果先对完整样本做CLR，再遮住目标位置，其他可见位置的共同中心已经包含目标的信息；在固定维度下，所有CLR分量和为零也会构成捷径。课程的元素级log1p和训练均值缩放避免这类由当前样本中心引入的显式泄漏，但原始相对丰度仍有组成依赖。设计损失时应检验简单插补与可见信息推断基线。

## 计数模型与对数比模型回答不同问题

如果真正拥有计数矩阵，可以研究多项、负二项或其他观测模型，但必须匹配测量过程、分母与过度离散假设。测序深度不总等于目标微生物读段总和，技术效率和组成变化也可能影响计数。选择一个概率分布之前，先说明随机变量是什么、哪些总量被条件化、哪些参数可以从数据识别。把比例强制转为整数不会补回原始测量过程。

对数比模型通常关注组成中的相对变化，计数模型则可能显式建模深度与离散性；两者不是简单的高级与低级关系。对于预测任务，可在相同外测协议下比较；对于关联估计，还要说明效应所参照的量和假设。特别稀疏的表也可以考虑存在与否和正值丰度的两部分目标，但零来自多种机制时，存在概率的生物解释仍需谨慎。当前工程没有自动执行这些计数建模拓展。

## 批次校正不能创造不存在的可识别性

假设研究A全是病例，研究B全是对照，任何研究特征都可能成为诊断代理。即使将两批均值强行拉齐，也无法从这份设计单独识别哪些差异来自疾病、哪些来自技术或招募。需要具有交叉覆盖的数据、额外队列或更明确的假设。批次校正应由任务和测量设计决定，不应成为读表后固定执行的一行默认代码。

预测场景中的校正参数和协变量回归必须在训练域拟合，并说明如何处理新研究；有些方法需要目标批次的整批分布，属于使用未标注目标资料的适配，应与完全不接触目标域的外测分开报告。把训练和测试一起标准化、去批次再划分，会让测试信息进入流程。校正前后都要查看生物信号与技术信号是否被一并删除，不能只追求二维图上不同研究混在一起。

## 协变量与时间轴决定哪些输入合法

年龄、性别、药物、饮食、体重、采样批次和测序指标可以影响模型，但并非越多调整越正确。预测目标若是在采样时分类，只能使用该时点可获得的输入；若预测未来结局，结局发生后的药物与随访信息会产生时间泄漏。关联研究还需要区分混杂因素、中介和碰撞变量，机械加入所有变量可能改变研究问题或引入偏差。

先建立一张变量字典：含义、单位、获取时间、缺失原因、可见于哪个预测阶段，以及是否可能受结局影响。比较协变量单独、菌群单独与两者联合模型，能够检验菌群在当前设计中的增量信息。缺失值填补、类别编码和缩放也要在训练集拟合。用药既可能反映疾病过程也可能影响测量，不应只凭一张相关图决定删除；需要结合目标问题制定主要与敏感性分析。

## 交付能进入外测的数据，而不只是合并表

最终清单至少关联研究、全局受试者、样本、访视时间、技术重复和原始资源。对同一原始样本的重测、同一受试者的多次访视、同一公开数据的不同再分析，需要分别识别。研究ID不同并不保证受试者独立，受试者ID重名也不一定是同一人；应使用来源映射而不是只做字符串拼接。标签定义和诊断标准不同的研究也不能无说明直接合并。

真实cMD拓展应阅读项目REAL_DATA.md和导出脚本，在具备R环境与相应数据条件后执行，并记录实际包与资源版本。本课程环境没有完成真实cMD导出或真实多队列训练，因此本课的通过证据是人工数组实验、数据契约和明确的整合决策。下一课将根据这些输入性质选择模型表示，避免为了使用某种网络而先把测量含义改成它喜欢的格式。

### Extending and improving metagenomic taxonomic profiling with uncharacterized species using MetaPhlAn 4 (2023)

https://doi.org/10.1038/s41587-023-01688-w

理解参考资源和分类定义变化为何会改变丰度表，不把版本升级当作纯软件细节。

- 读方法中物种级基因组集合与标记基因框架的说明。
- 记录其分类对象和你手中表格的层级是否一致。
- 把版本变化可能造成的一对多、多对一与不可映射情况写成数据检查。

**阅读问题：** 两个版本都输出物种名，是否意味着同名列可直接互换？

**参考思路：** 不一定。参考基因组集合、标记、分类边界与可识别范围可能变化，需要版本和ID映射核查；仅凭名称不能证明测量等价。

**阅读问题：** 论文方法进步是否意味着所有旧队列应直接替换列名？

**参考思路：** 不能。理想情况是统一处理可用原始资料；只有旧丰度表时应说明映射限制与信息损失，不能用名称替换模拟重新测量。

### Isometric Logratio Transformations for Compositional Data Analysis (2003)

https://doi.org/10.1023/A:1023818214614

从原始方法理解D维组成与D−1维正交坐标的关系，避免把ILR当作任意降维。

- 先理解单纯形中相对信息与正交坐标的目的。
- 对照本课三分量基矩阵检查正交性与零和条件。
- 讨论换基如何改变坐标解释，以及为何零值仍需单独处理。

**阅读问题：** ILR为什么有D−1个坐标？

**参考思路：** 固定总量的组成只有D−1个自由度；CLR位于零和子空间，ILR选择该子空间的正交归一基进行坐标表达。

**阅读问题：** 不同ILR基是否导致模型输入完全相同？

**参考思路：** 不是。它们保留相应几何关系但坐标值和解释不同。训练与推理必须使用同一个基与特征顺序，稀疏约束等方法还可能受坐标选择影响。

### curatedMetagenomicData：returnSamples官方接口说明 (2026)

https://waldronlab.io/curatedMetagenomicData/reference/returnSamples.html

核对实际参数和数据单位；这是官方资料导读，年份表示课程核验时间，不是论文发表年。

- 定位counts、rownames和dataType参数的定义。
- 阅读按研究资源获取数据的限制，估计少量样本选择仍可能触发较大下载。
- 对照自己的资源版本与导出脚本，记录真实运行状态。

**阅读问题：** counts=TRUE是否自动返回原始物种读段数？

**参考思路：** 不是。官方说明是相对丰度乘read depth再取整，不能未经验证当成最初测得的物种计数。

**阅读问题：** 选择少量样本是否保证只下载这些样本？

**参考思路：** 不保证。资源以研究为单位提供，函数可能需要取得完整研究资源后再筛选，应查看官方说明与实际日志。

## 练习与完整参考解答

### 练习 1. 外部表没有taxon_C列，但训练表中它占有一定丰度。分别给出三种可能原因与处理。

提示：不要把列缺失与个体未检出混为一谈。

参考解答：可能是新版本将其合并或改名，应核查分类映射；可能是该测量流程不覆盖它，应保留未知并评估不兼容；也可能是上游删掉全零或低出现率列，需要取得原始过滤规则后判断是否能恢复明确零。原因未知时默认补零不成立，当前工程应报错而非悄悄继续。

### 练习 2. 为什么对比例加1与对计数加1再转比例不同？

提示：写出每个样本的原始总深度N。

参考解答：比例加1会让每个原本不超过1的分量都获得很大的相同增量；计数加1后比例为(c_j+1)/(N+D)，相当于与深度相关的平滑。两者单位与强度不同。应记录加法发生的尺度，并在训练域分析对低丰度结果的敏感性。

### 练习 3. 研究A只有病例、B只有对照，去批次后AUC仍很高，可以声称排除了研究混杂吗？

提示：考虑疾病与研究变量是否可分辨。

参考解答：不能。两者完全重合，观测数据无法单独辨认疾病与研究差异。数值校正和高AUC不能创造识别信息，应增加交叉覆盖的研究、明确额外假设并在独立资料检验；现有结果应保留混杂限制。

### 练习 4. 先对完整样本CLR，再遮蔽一个坐标进行重建，会出现什么捷径？

提示：利用CLR分量之和为零。

参考解答：可见坐标已经通过共同中心包含目标信息，若只遮蔽一个CLR坐标，其值还能由其余坐标负和确定。应该重新设计只依赖可见信息的输入转换或使用元素级转换与固定训练统计，并比较简单插补基线；多遮几个位置也不等于所有组成依赖都消失。

## 验收自测

### 1. 跨MetaPhlAn版本拼接最先核对什么？

A. 文件是否都叫abundance.csv
B. 列名长度是否相同
C. 模型能否接受浮点数
D. 参考数据库、分类ID与层级、单位和流程

参考答案：D。输入语义由测量体系决定，格式一致不代表特征等价。

### 2. ILR的D−1维坐标需要随模型保存什么？

A. 所有测试标签
B. 任意一个物种名称
C. 基矩阵与匹配的特征顺序
D. 只保存随机种子即可

参考答案：C。不同基和顺序改变坐标含义，推理必须保持与训练一致。

### 3. 整列未测量最准确的编码含义是什么？

A. 小于均值的丰度
B. 未知或不兼容测量状态，需要核查
C. 所有个体必然为生物学零
D. 健康标签

参考答案：B。未测量不是观测零；当前工程默认拒绝缺失训练列。

### 4. 无标签测试数据参与整批去批次应怎样报告？

A. 明确为使用目标域资料的适配，并与纯外测区分
B. 因为无标签所以完全没有使用测试信息
C. 把过程隐去以简化方法
D. 重新称为训练集独立预处理

参考答案：A。目标分布信息仍进入处理，评价范围与纯归纳式外测不同。

### 5. 真实cMD接口尚未在本机执行时，应写什么？

A. 已完成真实疾病模型
B. 合成数组就是cMD样本
C. 默认下载一定成功
D. 接口与方案已核验，真实导出和训练尚未执行

参考答案：D。课程应区分方法核验、接口准备与真实运行，保留可检查的完成状态。
