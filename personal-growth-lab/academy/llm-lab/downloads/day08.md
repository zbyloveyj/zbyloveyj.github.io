## 先分清：知识、行为与参数更新

昨天的小型语言模型学会了根据前文预测后文。今天要解决的问题变成：给定一项任务，它能否按要求输出合适的答案？预训练、领域继续预训练、监督指令微调和偏好优化改变模型的方式不同。预训练从大量文本学习统计结构；领域继续预训练仍可使用下一词预测目标，只是语料转向某一领域；监督微调给出任务与示范答案；偏好优化利用同一问题下回答优劣的比较。把微生物论文放入语料，并不自动获得可靠的研究助手。

在CurateMicrobiota中，语言侧用于练习文本建模、答案监督与证据整理，微生物编码器用于丰度表表示学习。本课先运行低秩线性映射实验，再可选地对已经训练的TinyGPT执行全量SFT和LoRA-SFT，真实检查哪些参数改变。它们仍是小型教学任务，不等同于经过独立评价的微生物研究助手。你需要判断一个需求是在补知识来源、纠正输出格式，还是改变样本表示；这个判断决定使用检索、微调或新的预测模型。

## 把指令样本写成可以核验的数据

一个指令样本至少包括任务、输入材料、示范回答和来源。任务应具体，例如“从给定摘要提取研究设计、受试者、微生物检测方式和关联方向”。输入材料是模型作答的证据范围，示范回答遵守统一字段规范。缺失字段使用明确的空值与缺失原因，不能凭领域常识补齐。原文只报告横断面相关时，答案不能写成因果效应；只有体外实验时，不能提升为人群治疗结论。这些约束需要落实到样本，而不仅写在提示词中。

整理数据时先按论文或独立研究划分训练、验证和测试，再对各自文档切片。来自同一论文的摘要、方法片段、问答改写不能分散到不同集合。逐条记录 DOI、样本来源、文档版本、整理者与核验状态。合成指令可以用来验证格式流程，但它的正确性和多样性需要人工检查，也不能充当独立测试的事实依据。今天先手工做五条高质量样本：两条完整提取、两条字段缺失、一条证据不足；每条保留一段能支撑答案的原始材料。

## 只在答案位置计算损失

指令微调通常把提示和回答连接成同一条序列。模型仍进行因果预测，但优化目标可以只覆盖回答部分：提示词参与注意力计算，作为回答的条件；提示位置的标签设为忽略标记，使它们不贡献目标损失。需要仔细区分“预测发生的位置”和“被预测 token 的位置”。预测第一枚答案 token 的 logits 来自前一个位置，若掩码没有与右移标签同步，就可能把第一枚答案漏掉，或者错误训练提示末尾。

下面的独立短实验不依赖项目内部类，可以在 VS Code 新建 Python 文件运行。前两枚 token 表示提示，后两枚表示回答。右移后的目标中，仍属于提示的标签设为 -100。验收时逐个打印目标 token、位置和是否计分。多轮对话还需要精确标识每个 assistant 片段；截断、padding、打包多条样本都可能改变边界。某个批次没有有效答案 token 时应跳过或报错，不能让除以零产生的异常悄悄进入训练。

```python
import torch
import torch.nn.functional as F
torch.manual_seed(8)
ids = torch.tensor([[2, 3, 4, 5]])
answer = torch.tensor([[False, False, True, True]])
logits = torch.randn(1, 4, 8, requires_grad=True)
target = ids[:, 1:].clone()
target[~answer[:, 1:]] = -100
loss = F.cross_entropy(logits[:, :-1].reshape(-1, 8), target.reshape(-1), ignore_index=-100)
loss.backward()
print("shifted labels:", target.tolist())
print("scored answer tokens:", int((target != -100).sum()))
print("loss:", float(loss.detach()))
assert target.tolist() == [[-100, 4, 5]]
assert logits.grad[:, 0].abs().sum().item() == 0
assert logits.grad[:, 1:3].abs().sum().item() > 0
```

## LoRA：学习权重改变量的低秩分解

设一层线性变换的权重 W 有 d_out 行、d_in 列。全量微调直接修改这 d_out×d_in 个元素。LoRA 冻结 W，另外学习 A 与 B，使权重改变量写成缩放后的 BA。A 把输入投影到较低的 r 维，B 再映射回输出维度。这样新增的可训练参数为 r×(d_in+d_out)，当 r 远小于输入和输出维度时，可以大幅减少优化器需要维护的状态。低秩约束是对改变量的结构假设，并不是声称原权重本身只有很低的秩。

以输入输出均为 64、秩为 4 的线性层为例，不含偏置的全量权重有 4096 个参数，LoRA 两个矩阵合计 512 个。实际显存还包含底座、梯度、优化器状态和中间激活，不能把可训练参数缩小八倍直接解释为总显存缩小八倍。常见初始化让一个矩阵随机、另一个为零，使初始增量为零。若 A 和 B 同时设为零，两者的梯度可能同时为零而无法启动学习；这个细节非常适合作为本课的故障实验。

```text
W_eff = W_0 + (alpha / r) B A；A ∈ R^(r×d_in)，B ∈ R^(d_out×r)
```

## 看懂本地 LoRA 实验到底证明了什么

运行项目提供的 lora-demo，记录冻结参数量、可训练参数量、初始损失、最终损失和输出位置。先确认优化器只接收需要更新的参数，再比较运行前后的底座权重。正确实验应同时满足：底座没有改变，至少一部分低秩参数改变，损失计算和反向传播能够完成。损失下降只是说明该实验目标可以被拟合，不代表模型已经获得微生物研究知识，更不能据此给出问答准确率。

读代码时沿着“建立底座—冻结—插入低秩分支—创建优化器—反向传播—保存结果”的顺序做标注。然后改变秩或学习率做一次受控比较，其余数据、随机种子和训练步数保持一致。若当前命令没有开放这些参数，直接在复制出的练习代码中修改对应配置，并记录改动，不要凭空添加不存在的命令行选项。合并低秩权重用于推理前，还应在同一输入上比较合并前后输出，允许浮点误差范围内的差异。

## 对已经训练的TinyGPT执行答案监督

项目提供finetuning.py和原创教学问答，固定划分十条训练、四条验证。finetune必须读取真实TinyGPT底座检查点；程序把提示与回答拼接，只对回答字节和结尾换行计分，提示与右侧padding标签为-100。若提示有P个字节，第一枚答案的监督位置是P-1；超过上下文的样本会报错，避免静默截断改变任务。报告保留每条样本的字节长度与首个监督位置，便于逐项核对。

先对同一底座运行全量SFT，再在独立目录使用--lora。LoRA只在两个注意力qkv线性映射中加入rank=2适配器，底座全部冻结；默认模型新增1024个可训练参数，总参数137984。保存结果包括完整可加载检查点，LoRA另外保存adapter.pt及底座校验值，适配器不能脱离匹配底座随意加载。验证损失选择最优状态，若没有改善也可能保留初始状态。

附带实际三十步报告中，全量SFT验证答案CE从3.31626降至2.74298，LoRA从3.31626降至3.24998且底座张量完全未变。这证明两种语言微调路径确实运行，不证明四条验证题足以测量一般指令能力。两种默认学习率不同，也不能据此宣称全量方法普遍优胜；你的底座训练步数不同，数值也可能不同。QLoRA、完整偏好模型训练和大规模领域SFT仍为拓展。

```bash

python -m curatemicrobiota finetune --checkpoint runs/lm/model.pt --out runs/sft-lora --steps 30 --lora
```

## 选择全量微调、冻结探针还是低秩微调

当数据很少时，先冻结已有编码器，只训练一个简单的预测头，是识别表示价值的便宜办法。若冻结表示无法适应目标分布，可尝试逐层解冻、全量微调或低秩更新。它们的比较必须使用同一训练和验证划分、同一评价任务以及清楚的预算。模型参数更少不必然泛化更好，更新参数更多也不必然带来收益。小样本下训练损失持续改善而验证性能下降，往往意味着需要更早停止或更强的约束。

微生物丰度编码器和语言模型可以使用相同的参数高效思想，但输入、任务头与损失不同。不要把语言模型常用的目标层名称直接复制到另一个网络而不检查模块结构。当前语言模型已经提供SFT与LoRA-SFT；后续丰度工程实现的是直接数值基线和冻结编码器探针。从零监督、全量菌群微调和菌群LoRA仍是研究拓展，需使用严格外测比较，才能区分表示本身有用与重新训练后有用。

## QLoRA 与量化：存储精度不等于计算精度

量化用较少比特表示权重，通常还需要缩放因子或码本。QLoRA 将量化后冻结的底座与可训练低秩适配器结合；参与矩阵乘法时的计算精度、适配器精度和权重存储精度可以不同。理解这三个层面，才能避免“所有参数与梯度都在四比特里训练”这样的错误表述。低比特表示节省的主要是部分存储开销，激活和优化器仍会占用内存，长上下文也可能成为显存瓶颈。

这一节是进阶阅读，不作为普通 CPU 环境的安装必选项。真正运行量化微调之前，需要核对硬件、软件支持、底座许可证、目标模块和训练精度；然后与未量化的小规模参考运行比较输出和任务指标。当前课程的 LoRA 演示不依赖下载大权重，也不包含已经验证的 QLoRA 训练结果。你应在学习记录中画出“量化底座—高精度低秩分支—任务损失”的关系，并说明哪部分冻结、哪部分更新、哪部分在推理时保存。

## RLHF 与 DPO：偏好数据如何改变回答

监督微调告诉模型怎样回答，偏好优化比较同一问题下哪份回答更符合评价标准。典型 RLHF 路线会先学习偏好相关的奖励模型，再优化语言模型的策略，同时限制它偏离参考策略过远。DPO 使用成对偏好和参考模型概率构造直接优化目标，通常不需要另行执行同一套在线强化学习采样与奖励模型训练流程。二者都依赖偏好数据的质量；标注者喜欢一个答案，不代表其中每个科学事实都正确。

为CurateMicrobiota写一对偏好示例：好答案准确指出样本、设计和证据局限；差答案把横断面关联写成治疗效果。比较时尽量避免把更长或术语更多当成好答案的代理标准。alignment-demo在固定合成序列对数概率上真实计算DPO损失和梯度，使用回答词元对数概率之和而非默认按长度平均，参考项冻结；它没有更新真实语言模型、训练奖励模型或执行完整RLHF。

附带公式实验初始损失约0.6664，提高chosen相对rejected的优势后变为0.64715。chosen对数概率的梯度为负、rejected为正，因此梯度下降会朝相应偏好方向推动这组变量。理解这一计算有助于检查实际DPO实现，但把两个标量方向改对，不等于模型已经学会正确科研回答。真正偏好训练还需要独立数据、参考模型与任务评价。

```text
L_DPO = -log sigmoid(beta × [(log πθ(y+|x) - log πθ(y−|x)) - (log πref(y+|x) - log πref(y−|x))])
```

```bash
python -m curatemicrobiota alignment-demo --out runs/alignment
```

## 怎样证明微调真的改善了任务

建立三组独立测试：结构化提取是否匹配人工核验字段、来源证据是否支持答案、材料缺失时是否能够保持空值或说明未知。模型输出是否符合 JSON 格式，只覆盖了语法层面的正确性；字段内容是否准确、是否引用正确研究，是另外两层。报告每层的分母，列出失败案例，并按文档、研究类型或任务类别分组。一个平均分不能说明模型在所有子任务上都可靠。

必须保留微调前的底座输出作为对照，并控制提示词、检索材料与生成参数。若同时更换底座、增加文献库和微调，性能变化不能归因于单一因素。测试材料不得出现在监督样本、生成指令的示例库或人工调参循环中。对于非常小的测试集，结论写成“在该批任务上的观察”，并同时报告原始正确数。当天至少检查一条模型变好的例子和一条变差的例子，练习分析遗忘、格式过拟合与不适当自信。

## 练习与完整参考解答

### 练习 1. 一个512×256的线性层使用rank=8的LoRA，不考虑偏置，新增多少可训练参数？

提示：分别写出A和B形状，再相加。

参考解答：A为8×256，B为512×8，总数为8×(256+512)=6144。原始权重为131072。比较可训练参数时可以算比例，但还需说明底座与激活仍占内存。

### 练习 2. 同一论文生成十条问答，随机拆成八条训练和两条测试，为什么不能检验跨文档泛化？

提示：寻找这些问答共享的事实和措辞。

参考解答：同源问答可能共享事实、实体、表达和答案模板，模型可能通过记住训练内容完成测试。应先按论文或独立研究分组划分，再在每组内部生成问答，并检查重复研究的多个版本。

### 练习 3. 模型输出了合法JSON，但把动物实验写成临床试验。应记为什么错误？如何修正？

提示：区分语法、字段语义和证据支持。

参考解答：这是语义与证据归属错误，不能因为格式合法而判正确。修订数据字段和核验规则，加入动物与人群对照样本；在独立集分别报告格式通过率、字段准确率与证据支持率。

### 练习 4. 只在答案处计损失，是否表示提示词不影响参数更新？

提示：注意计算图中答案位置能够关注的输入。

参考解答：不是。提示作为条件影响答案位置的隐藏状态，因此答案损失仍可沿相关计算路径传播；忽略提示标签只是不要求模型复述提示的预测目标。

## 验收自测

### 1. 对仅答案损失最准确的描述是？

A. 提示提供条件，答案目标计入交叉熵
B. 提示完全不进入模型
C. 所有提示token都被删除
D. 模型不再使用因果注意力

参考答案：A。输入可包含完整提示，标签掩码决定哪些预测目标贡献损失。

### 2. LoRA中两个矩阵都初始化为零的主要风险是？

A. 自动完成预训练
B. 词表被扩大
C. 必然占用更多显存
D. 乘积结构可能使两者梯度都为零

参考答案：D。增量为BA，对某个矩阵的导数依赖另一个矩阵，两者都为零可能阻止开始学习。

### 3. QLoRA的四比特通常主要指？

A. 所有文本只剩四个token
B. 模型只训练四步
C. 冻结底座的量化存储方式
D. 所有激活和梯度一律四比特

参考答案：C。存储、计算和适配器精度需要分别说明。

### 4. 偏好数据最合适的比较单位是？

A. 训练集和测试集的文件大小
B. 同一任务下的不同回答
C. 不同论文的样本数
D. 任意两段无关文本长度

参考答案：B。成对偏好需要有共同任务条件和明确评价标准。

### 5. 本课小型LoRA实验完成后，可以支持哪项结论？

A. 低秩分支可被训练且底座可保持冻结
B. 已训练完成临床微生物专家模型
C. 任何任务都优于全量微调
D. 无需测试集就能证明泛化

参考答案：A。机制实验支持参数更新流程，不能替代领域任务与外部泛化评估。
