## 把张量运算还原成线性映射

矩阵W∈R^{m×n}把n维向量映射到m维。采用列向量记号时y=Wx，采用批量行向量代码时常写Y=XWᵀ。两者表达同一映射，转置来自记号约定。真正重要的是输入、输出维度与每个轴的意义，而不是死记公式里W放在哪边。

列空间描述输出能到达的方向，零空间描述哪些输入变化会被映射抹掉。若两个输入相差一个零空间向量，线性层给出的输出相同。多个线性层连续相乘仍是线性映射；加入非线性后，模型才可以根据输入区域采用不同的局部变换。残差则把原表示与新变换共同保留。

在菌群表里，物种数可以远多于独立样本数，特征又受组成约束和共线性影响。参数矩阵很大不代表数据提供了同样多的独立信息。理解有效维度与可识别性，有助于解释为什么简单线性基线、正则化和低秩方法在小数据上可能更可靠。

## SVD、秩与低秩近似

奇异值分解把W写为UΣVᵀ。奇异值按大小排序，描述不同输入方向经过映射后的尺度。保留前r项得到秩不超过r的近似；在通常的Frobenius范数意义下，截断SVD给出最优秩r重建，平方误差等于被舍弃奇异值平方和。这是线性代数结论，不代表它对任意下游任务都最优。

对对角矩阵diag(5,2,0.1)，秩一近似保留5，重建误差平方为4.01；秩二时误差平方为0.01。若小奇异方向恰好携带标签信息，重建误差很小仍可能损害预测。因此“保留99%能量”应和独立任务评价并列报告，不能直接当作科学信息保留率。

LoRA把更新写成BA，秩最多为r，但原始W本身可以满秩。它约束的是适配更新，不是把整个模型强制变成秩r。低秩能减少可训练参数，却不保证每个任务所需的变化都恰好落在这个容量里。

```python
import torch
W = torch.diag(torch.tensor([5., 2., 0.1], dtype=torch.float64))
U, S, Vh = torch.linalg.svd(W, full_matrices=False)
for r in [1, 2, 3]:
    Wr = (U[:, :r] * S[:r]) @ Vh[:r]
    error2 = (W - Wr).square().sum()
    assert torch.allclose(error2, S[r:].square().sum(), atol=1e-12)
    print(r, float(error2))
```

## 条件概率与后验：先看分母

条件概率P(A|B)=P(A,B)/P(B)，描述已知B后对A的分布。P(A|B)与P(B|A)通常不相同。贝叶斯公式通过先验和似然把两者联系起来，分母汇总所有可能产生观察的情况。一个高分模型输出究竟是经校准概率、排序分数还是相似度，必须在解释前确认。

用纯教学事件举例：P(A)=0.2，P(B|A)=0.6，P(B|非A)=0.1。则P(B)=0.2×0.6+0.8×0.1=0.2，P(A|B)=0.6。即便条件观察相同，更换先验也会改变后验。跨队列类别比例变化时，概率校准可能变化，AUROC保持也不能自动保证概率仍可直接解释。

语言模型的P(token|prefix)来自对语料分布的拟合，不是一个科学命题在现实中成立的后验概率。句子生成概率高可能仅因表达常见。把“模型说得很确定”和“证据支持程度高”分开，是后面理解奖励模型、检索证据和风险校准的基础。

## 概率链式法则与最大似然

联合序列概率可以分解为P(x₁,…,xT)=∏P(x_t|x_<t)。这个概率链式法则无需假设token相互独立；每一项可以依赖完整前缀。模型的有限上下文则是实际实现采用的限制。对数把连乘变为求和，避免极小序列概率直接相乘带来的下溢，也让训练目标按位置分解。

最大似然在固定训练观察下选择参数，使数据概率更大；等价地最小化负对数似然。若训练样本按经验分布平均，得到常见的交叉熵目标。参数是优化变量，观察数据在这次计算中视为给定，这与固定参数后对未知变量求后验的视角不同。

对独立来源文档进行平均也需要定义权重。按token平均会让长文档贡献更多，按文档平均则改变目标分布。对菌群重复访视同样如此：按样本平均可能给访视多的人更大权重。损失的分母不仅是实现细节，也在定义你想拟合的总体。

## 熵、交叉熵与KL的关系

熵H(p)=−Σp log p刻画目标分布自身的不确定性；交叉熵H(p,q)=−Σp log q刻画用q预测来自p的结果所需的平均负对数分数；KL(p‖q)=Σp log(p/q)表示额外差距，满足H(p,q)=H(p)+KL(p‖q)。固定p时，最小交叉熵等价于最小该方向KL。

KL不是对称距离，通常KL(p‖q)不等于KL(q‖p)，也不满足所有距离公理。如果p在某位置为正而q为零，前向KL可能无穷大；随意加epsilon改变了比较对象，应记录处理。数值例子采用全正概率，避免将边界处理与基本恒等式混在一起。

在偏好学习中，策略与参考模型间的KL常用于限制策略偏移；在表征模型里，某个潜变量分布也可能出现KL项。它们共享数学形式，但p、q及期望采样分布不同。看见KL时先写出两个分布、方向和权重，不要只把它理解成“越小越好”。

```python
import torch
p = torch.tensor([0.6, 0.3, 0.1], dtype=torch.float64)
q = torch.tensor([0.4, 0.4, 0.2], dtype=torch.float64)
H = -(p * p.log()).sum()
CE = -(p * q.log()).sum()
KL = (p * (p.log() - q.log())).sum()
reverse = (q * (q.log() - p.log())).sum()
assert torch.allclose(CE, H + KL)
assert KL >= 0
print(float(H), float(CE), float(KL), float(reverse))
```

## softmax交叉熵的梯度为何是概率减目标

设logits为z，softmax为p，目标one-hot为y。损失L=−Σy_i log p_i，把log p_i写成z_i−logΣexp(z_j)，求导得到∂L/∂z_i=p_i−y_i。正确类别若概率不足，梯度为负，梯度下降会提高它的logit；其他类别梯度为正，更新会压低其相对分数。

这个结果解释了交叉熵为什么必须接收正确的未归一化分数，也说明一个类别的更新与其他类别耦合。概率已经很接近one-hot时，局部梯度变小；标签若错误，模型仍被目标推动向错误方向。优化正确执行不等于数据标签正确。

对soft label，y可以是总和为一的分布，公式仍成立；label smoothing改变了目标分布，因此不仅是“数值稳定技巧”。类别加权、焦点损失和掩码平均也改变梯度。比较实验要写清目标，不把同名loss的不同实现混作一致条件。

## 链式法则与向量反向传播

若h=f(θ)、L=g(h)，梯度由局部导数沿图传回。对向量函数，完整Jacobian可能很大，反向自动求导通常计算向量—Jacobian积，避免显式构造所有偏导。标量loss特别适合这一方向：从一个标量输出出发，可以高效获得大量参数的梯度。

detach、转NumPy再重建张量、某些原位修改可能中断或改变图关系。requires_grad=True只说明可以追踪，不保证参数真的进入目标或被optimizer更新。参数共享时，不同路径的梯度会相加；这正是输入输出共享embedding或多任务学习需要关注的地方。

设计一个自定义操作时，不应该只检查forward数值。用小尺寸、双精度输入比较自动梯度与有限差分，可以抓到转置、符号和归约错误。通过一次梯度核对不证明所有边界都正确，但能建立比“loss下降了”更直接的局部证据。

## 有限差分：用数值独立核对梯度

中心差分用[f(θ+h)−f(θ−h)]/(2h)近似导数。h太大，截断误差明显；h太小，两个几乎相等的浮点数相减会放大舍入误差。因此不是步长越小越好。先用float64与光滑函数，再扫描几个h，观察误差呈现的趋势。

例子检查logsumexp与二次项组成的标量目标，选择它因为既包含稳定概率运算，也有容易理解的局部曲率。有限差分的函数调用不需要追踪梯度，解析路径由autograd得到。用同一段autograd公式再次计算所谓“数值梯度”不能形成独立检验。

ReLU拐点、离散采样或排序边界不光滑，数值核对需要额外判断。若测试刚好落在边界，失败不一定表示反向实现错；换一个非边界输入，或明确该点采用的次梯度约定。

```python
import torch
z = torch.tensor([0.2, -0.4, 0.7], dtype=torch.float64, requires_grad=True)
def f(v):
    return torch.logsumexp(v, dim=0) + 0.2 * v.square().sum()
f(z).backward()
h = 1e-5
num = torch.zeros_like(z)
with torch.no_grad():
    for i in range(z.numel()):
        e = torch.zeros_like(z); e[i] = h
        num[i] = (f(z + e) - f(z - e)) / (2*h)
assert torch.allclose(z.grad, num, atol=1e-8, rtol=1e-6)
print(z.grad, num)
```

## 浮点误差、稳定计算与损失单位

浮点数用有限位数表示有效数字与指数，因此加法并不在所有情况下严格满足结合律。大量小数加到很大数上，某些增量可能被舍入；直接exp大logits会溢出；把极小概率先算出来再log可能得到负无穷。logsumexp通过平移最大值等方式稳定计算，不改变数学目标。

FP16与BF16同是16位，但指数范围和尾数精度不同。较大动态范围不等于更高局部精度，混合精度也不意味着所有操作都用同一低精度。先建立float32或float64参考，再比较低精度误差；不把数值误差和随机种子变化混在一起。

日志里的loss必须注明归约和单位。nats与bits相差ln2；token、byte、样本、受试者的平均也不同。一个loss降低十倍可能来自改变分母，而非模型变好。复现实验先核对数值定义，再讨论优化收益。

## 曲率、条件数与学习率

对二次目标L=½θᵀHθ，若H正定，梯度下降沿每个特征方向按1−ηλ_i缩放。稳定条件需要0<η<2/λ_max。H的特征值跨度大时，大步长在陡峭方向震荡，小步长在平缓方向推进慢，这就是条件数影响优化的直观来源。

自适应优化器、预处理、归一化与良好参数化能改善部分尺度问题，但不会消除所有非凸困难。梯度裁剪限制一次更新使用的梯度范数，也不等于修复错误曲率或标签。先观察梯度范数与更新相对参数的比例，可以区分“几乎没动”与“步长过猛”。

最终把数学落回CurateMicrobiota：说明菌群重建目标按哪些位置平均、线性探针如何正则化、LoRA的r约束什么、类别概率如何校准。能写清这些关系，才有能力判断替换一个损失或模块究竟改变了哪个研究问题。

## 练习与完整参考解答

### 练习 1. 对diag(4,3,1)，最佳秩一近似的平方Frobenius误差是多少？

提示：舍弃两个奇异值。

参考解答：奇异值为4、3、1。保留最大奇异值的秩一近似可取diag(4,0,0)，残差为diag(0,3,1)，平方Frobenius范数是3²+1²=10，范数为√10。若保留秩二，平方误差为1。这里优化的是矩阵元素重建；若最小奇异方向携带某个罕见任务信号，较小重建误差仍可能损伤该任务。

### 练习 2. P(A)=0.1，P(B|A)=0.8，P(B|非A)=0.2，求P(A|B)。

提示：先算P(B)。

参考解答：由全概率公式，P(B)=P(B|A)P(A)+P(B|非A)P(非A)=0.8×0.1+0.2×0.9=0.26。再用贝叶斯公式得P(A|B)=0.08/0.26≈0.3077。用一万次合成事件检验直觉：A中约800次出现B，非A中约1800次出现B，所以观察到B的2600次中约800次属于A。0.8是另一个方向的条件概率。

### 练习 3. p=(0.5,0.5)，q=(0.9,0.1)，交叉熵与KL关系如何？

提示：先求H(p)=ln2。

参考解答：H(p)=−2×0.5ln0.5=ln2≈0.6931。CE(p,q)=−0.5ln0.9−0.5ln0.1≈1.2040。KL(p||q)=Σp_i ln(p_i/q_i)≈0.5108，因此CE=H+KL。三个量采用自然对数，单位是nats；q过度偏向第一类，对真实第二类赋予低概率，增加了平均负log概率。

### 练习 4. 二次目标最大曲率100，η=0.03为何不稳定？

提示：检查1−ηλ。

参考解答：沿最大曲率特征方向，误差更新为e_(t+1)=(1−ηλ)e_t。代入η=0.03与λ=100得到系数−2，若该方向有非零误差，就会翻转符号并每步放大两倍。收敛需要|1−ηλ|<1，即0<η<0.02；η=0.02是边界振荡而非严格收敛。这个结论针对固定曲率二次目标，不能直接当作复杂神经网络的通用学习率。

## 验收自测

### 1. LoRA的秩约束主要施加在哪里？

A. 原模型所有权重
B. 新增更新矩阵
C. 输入样本数
D. 词表大小

参考答案：B。ΔW=BA的秩至多r，原W可以满秩。

### 2. 概率链式分解是否要求token独立？

A. 要求完全独立
B. 要求同分布
C. 不要求独立
D. 只对两token成立

参考答案：C。每项条件概率可依赖全部前缀。

### 3. 固定p时最小交叉熵等价于？

A. 最小KL(p‖q)
B. 最大H(p)
C. 最小反向KL必然等价
D. 让q均匀

参考答案：A。H(p)固定，CE=H(p)+KL(p‖q)。

### 4. 中心差分h越小会怎样？

A. 一定更准
B. 一定不准
C. 不影响结果
D. 可能受舍入消去影响

参考答案：D。截断误差和舍入误差需平衡。

### 5. softmax CE对logit梯度是？

A. y−p
B. p−y
C. p×y
D. 恒为1

参考答案：B。目标类别通常获得提高其logit的更新方向。
