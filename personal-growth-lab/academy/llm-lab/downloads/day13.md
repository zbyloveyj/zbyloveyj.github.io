## 先区分三个不同层次的解释

“模型使用了某个特征”“这个特征与结局相关”“改变这个特征会改变结局”是三个不同命题。归因方法描述当前模型如何利用输入；统计关联描述观察到的共同变化；因果结论涉及干预和反事实，还依赖研究设计与识别假设。即使三者都出现同一个物种名称，也不能从第一层直接跳到第三层。解释图应该说明它解释的是哪个模型、哪个输出、哪一批数据。

在CurateMicrobiota中，demo_taxon_001等名称是合成特征编号，并不对应真实生物。你可以检查模型是否捕捉模拟器设定的人工变化，却不能据此编写疾病机制或给出菌种干预建议。真实队列还会受到用药、饮食、地理、技术流程和样本选择影响。今天的目标是让模型输出更容易检查，同时清楚标注哪些结论仍需要独立数据或更强研究设计。

## 注意力是一种计算权重，不是因果证据

注意力权重说明某一层某个头如何混合当前表示，但最终预测还经过值向量、残差、前馈网络、其他层和分类器。同一个较大权重可能对应很小的实际贡献；不同头之间也没有天然统一的“重要物种”刻度。因此展示热图时要注明层、头、输入条件和聚合规则，并与预测变化的检查相互参照。不能只挑最符合已有故事的一张热图。

Jain与Wallace的研究在其自然语言实验设置中检验了注意力作为解释的局限。它为我们提供了应当验证解释的理由，并不直接证明所有微生物注意力图都无用。本项目当前编码器没有提供成套注意力解释报告；若要加入可视化，需要实际暴露权重、检查对应样本，并设计对照。即使热图在不同种子下稳定，也只能支持一种稳定的模型行为，不能单凭它建立微生物之间的生态作用方向。

> 把“该头在该输入上分配较高权重”写成观察；把“该菌导致疾病”视为尚未被这项模型分析识别的命题。

## 归因应说明背景分布与扰动方式

逻辑回归系数看起来直接，但它对应的是经过特征转换、标准化和正则化的条件关系；相关特征可能互相分担系数，符号也不能自动解释为单独增加某个菌的效果。梯度描述局部输入变化对输出的敏感度，置换重要性描述按某种打乱规则破坏特征后性能的变化。不同方法回答不同问题，结果不一致时应检查问题定义，而不是选择最漂亮的一种作为唯一解释。

相对丰度具有总量约束。把一个分量单独增加而保持其他分量不变，可能形成不在原始数据支持范围内的向量；重新归一化又同时改变了所有分量。跨人独立打乱某个菌也会破坏菌群相关结构。研究扩展可以比较相关特征成组置换、对数比对照或条件扰动，但每个方案都有额外假设。必须记录扰动单位、是否保持组成约束、使用哪个数据域，以及是否重新训练模型。

## 两类置换实验不能混为一谈

标签置换用于检查整个学习流程是否能在没有原有标签关系的条件下产生过好的结果。存在重复访视时，应先以受试者为单位置换标签，再把同一标签映射回该人的所有记录；通常还要在研究内保留合适的交换结构。若要进行完整的流程检验，每次置换都应重新执行相关的监督拟合和验证选择，而不是只打乱最终测试标签后继续使用原来的显著性解释。

特征置换则用于测量已拟合模型对某类输入信息的依赖，通常不重新训练，两者目的不同。研究与结局严重混杂、某研究仅有一个类别或纵向标签变化时，简单的研究内标签置换未必提供有效的检验，需要先明确可交换性假设。课程当前CLI没有执行置换显著性检验；今天交付的是明确实验单位与重跑范围的设计，不能把计划中的置换次数写成已经获得的统计证据。

## 先检查输入兼容，再讨论分布外检测

新的输入可能与训练数据根本不兼容：物种层级不同、数据库版本变更、百分比被误当比例、训练词表中某列完全缺失，或体位与测量平台不同。此时先检查数据契约和来源，再计算模型分数。当前预处理器对缺失的训练列默认报错，未知输入列会排除并记录保留丰度质量。缺失整列不等于每个样本中这个物种都为生物学零。

分布外输入是相对于训练分布和预期任务而言的，不是一个永远固定的标签。新的研究可能在丰度、测量缺失、患病比例或输入与标签关系上发生变化。距离检查只覆盖其中一部分；输入看起来相似也可能出现结局关系改变。工程报告里的词表匹配率、保留质量和来源检查应与数值诊断一起查看。不要把通过格式校验或低重建误差解释为已经证明模型能跨人群使用。

## 一个可运行的训练参考距离诊断

下面代码使用已经冻结的预处理器，将每个样本表示为训练均值和尺度下的对数丰度，再计算各维平方平均的平方根。它是容易解释的描述性距离，忽略特征间协方差，也没有提供可靠的疾病风险或分布外概率。阈值取训练样本距离的百分之九十五分位，仅用于教学观察；因为阈值来自训练样本，在验证数据上的标记比例不保证恰好为百分之五。

代码只报告训练与验证域，让你在最终测试前确定检查规则。正式扩展可比较独立校准集、稳健协方差距离或表示距离，但要限制调参并检查不同研究的误报。如果根据最后的测试诊断继续修改模型，这批测试数据已经参与开发，后续正式评价需要新的外测安排。距离变大说明应当调查来源与输入差异，不直接说明样本异常、更不说明患者患病。

```python
import numpy as np
from curatemicrobiota.data import load_cohort, Preprocessor
cohort = load_cohort("data/demo")
split = cohort.indices()
prep = Preprocessor.load("runs/microbiome/preprocessor.json")
z, alignment = prep.transform(cohort.values, cohort.taxa)
score = np.sqrt(np.mean(z.astype(float) ** 2, axis=1))
threshold = float(np.quantile(score[split["train"]], 0.95))
print({"teaching_threshold": threshold, "alignment": alignment})
for name in ("train", "val"):
    distance = score[split[name]]
    print(name, {"n": len(distance), "mean_distance": float(distance.mean()),
                 "flag_fraction": float(np.mean(distance > threshold))})
# 描述性诊断，不是经过校准的OOD概率；没有使用测试数据调阈值。
```

## 不确定性需要对应你想知道的对象

预测概率接近零或一，表示模型给出的输出集中，并不保证预测正确。第12天的校准讨论检验概率与观察频率；受试者bootstrap描述固定模型在当前测试队列抽样下的指标变化；不同训练种子或模型集成反映部分训练不稳定性。它们不是同一种不确定性，不能把其中一种图统一命名为“模型可信度”。当前程序只实现部分评价统计，没有完整的逐样本不确定性系统。

研究扩展可以在验证域规定拒绝预测的规则，并同时报告保留样本比例和保留样本上的错误，防止只挑容易样本造成表面改善。保形预测等方法也依赖交换性或相应修正条件，在跨研究偏移下不能自动照搬覆盖保证。任何需要标定的阈值都应在测试前固定。若目标是解释真实人群中的疾病风险，还需要代表目标人群的校准与评价数据，合成平衡样本不能提供这种保证。

## 数据增强要写出保留了什么假设

自然语言中替换词语不一定保留含义，微生物数据增强同样如此。对丰度加噪声、丢弃部分特征、混合两个样本或重新抽样，都可能改变标签相关信息。下面的乘性扰动在非负和总和约束下生成一个附近组成，并保持原来的零位置；它只演示数学约束，不证明得到的样本是生物学合理的，也不证明疾病标签不变。增强只应作用于训练数据，验证和测试用于评价原任务。

如果有真实计数和测序深度，可以在明确测量模型后研究下采样，但相对丰度乘一个任意深度并不等于恢复原始测序读段。对比学习还需要慎选正负配对：同一个受试者的两次访视可能有真实状态变化，不同受试者也可能很相似。先规定增强强度、目标不变性与失效情形，再做有无增强的同预算比较；不要只根据测试分数不断选择扰动幅度。

```python
import numpy as np
rng = np.random.default_rng(13)
p = np.array([0.2, 0.3, 0.5, 0.0])
q = p * np.exp(rng.normal(0.0, 0.05, size=p.shape))
q = q / q.sum()
assert np.all(q >= 0) and np.isclose(q.sum(), 1.0)
assert np.array_equal(p == 0, q == 0)
print({"original": p.tolist(), "augmented": q.tolist()})
# 这是训练增强候选；保持组成约束并不证明标签保持或生物真实性。
```

## 跨模态学习首先是样本对齐问题

宏基因组功能谱、代谢组、临床信息和文献可以提供互补信息，但必须先明确它们是否来自同一受试者、相近时间和匹配的样本处理过程。把一个研究的平均功能谱与每个患者复制配对，可能只让模型学习研究身份；把结局之后得到的信息放进预测时点之前，也会产生时间泄漏。多模态项目的第一张表应该是样本、时间、模态、缺失原因与许可的对应关系。

实现上可以先做各模态单独的强基线，再比较简单拼接或后期融合，最后考虑跨模态注意力与对比目标。缺失模态需要显式策略，并评价现实缺失模式，而不只是所有模态齐全的便利子集。训练与测试继续以受试者和研究隔离；同一个人的不同模态不能分到不同集合。当前CurateMicrobiota只训练丰度表示，证据检索独立提供文献来源，没有执行跨模态联合预训练。

## 丰度模型与DNA模型的任务边界

丰度表的一行描述某个样本中不同分类单元的相对构成，DNA序列描述按碱基位置排列的遗传信息，文本描述研究者写下的概念和观察。三者的词元、顺序、长度、噪声和监督目标不同。给物种名称加入身份嵌入，不会自动让模型学会这个物种的完整基因组；检索到论文也不会自动为样本提供分子层面的功能验证。你必须先选定输入与目标，才能讨论适合的大模型路线。

Evo的原始研究展示了以基因组序列为核心的建模路线，采用的架构也不应简单写成课程小型Transformer的放大版。本课阅读它，是为了比较序列模型与队列丰度表示的研究对象。若下一阶段研究DNA表示，可先采用公开且适用的预训练表示做明确的预测基准，并按序列同源性、物种或群体关系设计划分。它属于另一个数据工程与验证问题，当前项目没有训练DNA模型。

| 模态 | 输入单位 | 适合的任务 | 当前课程状态 |

## 用稳定性与替代解释收束今天的分析

提交解释报告时，至少记录模型检查点、预处理版本、数据域、输出定义、归因或扰动方法与随机种子。先说明观察，再提出可能解释，最后给出能区分解释的实验。例如某些特征的重要性跨研究变化，可能来自测量差异、群体构成或模型不稳定；下一步可以在训练域比较研究分层结果和特征质量，而不是立刻写成不同地区存在相反的生物机制。

今天不要求你把所有高级方法都实现，而是完成一个可运行的偏移诊断，并为一个解释问题制定可检验方案。课程快速结果中，预训练探针尚未优于简单基线，进一步解释这个探针时尤其应该保留它的性能背景。解释一个表现不佳的模型可以帮助调试，但无法替代有效预测证据。把尚未支持的结论明确列出，明天模型卡就能准确交代项目现阶段的能力与下一步研究重点。

## 论文导读

### Attention is not Explanation (2019)

https://aclanthology.org/N19-1357/

学习如何检验一种解释方法是否与模型输出的实际行为一致；论文实验对象是自然语言模型，迁移到菌群问题时需要重新验证。

- 先读摘要与研究问题，区分作者检验的注意力机制和你自己的模型结构。
- 重点看注意力与其他解释指标、预测变化之间如何比较，记录作者实际操作了什么。
- 最后阅读限制，提出一个适用于丰度编码器、可以推翻自己解释的对照。

**阅读问题：** 论文标题能否直接推出所有微生物注意力图没有价值？

**参考思路：** 不能。论文结论有其模型与实验范围；它提示我们不能未经检验就将注意力当成忠实解释。微生物模型仍应检查具体结构、预测变化与跨设置稳定性，任何因果解释还需要额外研究设计。

**阅读问题：** 为什么只画一张注意力热图不够？

**参考思路：** 热图只描述一种中间计算量。需要说明层、头和聚合方式，并检查它与输出敏感度、扰动结果和稳定性的关系；即便一致，也是在解释模型行为而非识别生物因果机制。

### Sequence modeling and design from molecular to genome scale with Evo (2024)

https://doi.org/10.1126/science.ado9336

通过原始研究认识基因组序列基础模型，明确它与样本丰度表示在输入、顺序、架构和验证单位上的差别。

- 读摘要和总体结构，确定其原始输入属于基因组序列，而不是人群丰度表。
- 选择一个预测基准，检查训练资料、划分方法、对照与评价对象，不必扩展到生物构建实验。
- 把论文路线与本课集合式丰度编码器比较，写出至少三项不能直接迁移的假设。

**阅读问题：** 为什么课程物种身份嵌入不能替代DNA模型？

**参考思路：** 身份嵌入表示训练词表中的离散分类标签，没有提供该类群内部的碱基序列与变异信息。DNA模型学习有顺序的序列规律，两者的数据、目标与评价单位都不同。

**阅读问题：** 阅读大型序列模型时，最适合本项目的收获是什么？

**参考思路：** 学习先定义模态、任务和泛化单位，再讨论规模。可以提出未来采用序列表征的预测研究，但不能宣称现有丰度模型已经获得基因组建模能力，也不能直接复制论文性能到当前任务。

## 练习与完整参考解答

### 练习 1. 某个注意力头经常关注A菌，同时A菌的LR系数为正。能否写“A菌促进疾病”？请改写结论并设计下一步。

提示：分别写计算权重、条件关联与干预命题，考虑混杂。

参考解答：不能直接这样写。可写“在指定模型和数据处理下，该头对A特征分配较高权重，LR中A的标准化对数丰度系数为正”。这仍可能受共线性、药物或研究偏移影响。下一步在训练域检查分研究稳定性、相关特征成组扰动及协变量对照；若要讨论机制，需要相应的独立生物证据或因果研究设计。

### 练习 2. 一名受试者有三次访视。为了做标签置换，你随机打乱全部记录的标签，产生三种不同标签。问题在哪里？

提示：比较独立单位与程序的受试者聚合假设。

参考解答：原任务假设受试者标签固定，记录并非独立。逐行打乱破坏受试者内结构，也不符合现有聚合接口。应以受试者为单位在适当交换组内置换，再映射回所有访视，并按预设流程重新拟合监督模型和验证选择。若真实标签随时间变化，则先重新定义纵向任务，不能套用固定标签方案。

### 练习 3. 外部数据少了一列训练物种，你填零后模型仍输出0.99；你能据此认为输入可靠且结论确定吗？

提示：区分测量缺失、兼容性、校准与输入分布。

参考解答：不能。缺失列可能来自数据库或测量流程差异，填零引入了未经验证的生物零假设。极端概率不代表输入兼容、校准良好或跨域可靠。先核查层级、版本与单位，保留缺失报告并按冻结规则处理；再用适当独立资料评价偏移与校准。当前接口默认报错正是为防止悄悄混淆这些情况。

### 练习 4. 把丰度向量乘上小幅随机噪声并重新归一化后总和仍为一。为什么这不足以证明增强有效？

提示：数学约束与任务不变性是两个条件。

参考解答：非负与总和约束只保证得到一个组成向量，不保证它符合测量过程、真实生态联合分布或保持原标签。归一化还同时改变多个分量。应明确噪声假设，在训练域限定强度，并用同预算有无增强对照和独立验证检验收益；不能将增强样本当作新增独立受试者。

## 验收自测

### 1. 注意力热图最直接描述什么？

A. 被证明的微生物干预效应
B. 真实人群中的患病概率
C. 任何模型通用的生物重要性排名
D. 特定计算层与输入条件下的表示混合权重

参考答案：D。注意力首先是模型内部计算量；归因忠实性需要检查，因果解释需要其他证据。

### 2. 现有训练词表某列在新数据中完全缺失，默认应该怎样处理？

A. 用测试标签推测这一列
B. 把剩余列重新命名顶替缺失列
C. 触发兼容性检查并核实缺失原因
D. 无记录地补零并继续发布结果

参考答案：C。整列测量缺失与每个样本的真实零不同。当前预处理器默认拒绝缺失训练列，避免静默改变输入含义。

### 3. 在当前训练参考距离示例中，95%分位阈值意味着什么？

A. 超过阈值的样本必然无效
B. 一个来自训练距离的教学性参照，不保证外部误报率
C. 已经获得95%疾病诊断准确率
D. 所有研究的分布外概率都准确校准

参考答案：B。描述性距离忽略不少分布变化，阈值的外部行为需要独立校准与验证。

### 4. 对重复访视任务做标签置换时，首先需要确定什么？

A. 独立单位和允许交换的结构
B. 哪种打乱能让新模型分数最高
C. 如何保证每条记录都有不同标签
D. 怎样把全部研究合并成随机切分

参考答案：A。有效置换依赖可交换性；固定受试者标签的任务应保持同一人的所有访视一致，并考虑研究结构。

### 5. 当前课程的丰度编码器已经具备哪项能力？

A. 从物种名称恢复完整基因组
B. 生成经过验证的生物机制
C. 自动进行丰度与DNA的联合预训练
D. 对固定分类单元丰度学习小型样本表示

参考答案：D。课程实现的是丰度输入的自监督编码器；文献检索与DNA模型是不同组件或研究路线，不能自动等同。
