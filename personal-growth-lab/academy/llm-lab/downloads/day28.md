## 同样叫生物大模型，随机变量可能完全不同

菌群丰度模型处理样本中各分类单元的构成，DNA模型处理有顺序的碱基，蛋白模型处理氨基酸序列，功能谱处理基因家族或通路的量，文本模型处理研究描述。把它们统一叫词元，并没有消除生物与测量差异。物种ID没有包含该物种所有菌株的基因组，DNA序列也没有直接告诉你它在某个受试者中有多丰富。

选择模型时先写一张输入输出表：预测基因级功能、样本级表型还是文献证据？标签来自测量还是注释？独立单位是序列簇、基因组还是受试者？如果目标仍是跨队列表型预测，序列表示只是潜在的额外信息源，需要与现有丰度和功能强基线比较。当前CurateMicrobiota已经实现的是丰度模型和文本教学组件，下面讨论的序列训练与多模态联合训练属于明确拓展。

| 模态 | 自然单位 | 关键结构 | 不能自动推出 |
| --- | --- | --- | --- |
| 丰度 | 样本×分类单元 | 组成与群落上下文 | 菌株序列和绝对负荷 |
| DNA | 碱基序列 | 位置、链方向与同源 | 样本丰度或实际功能效应 |
| 蛋白 | 氨基酸序列 | 序列与结构约束 | 体内表达或群落因果机制 |
| 功能谱 | 样本×功能特征 | 注释、分层与单位 | 代谢通量和脑内浓度 |
| 文献 | 段落与来源 | 语义与证据关系 | 未经验证的个体诊断 |

## k-mer与单碱基词元的取舍

单碱基词元保留精细位置，却让序列较长；k-mer把连续k个碱基合成词元，词表规模和词元数量随k及步长变化。重叠窗口能覆盖不同起点，但会增加冗余；不重叠窗口较短，却更依赖切分起点。某些模型使用其他分词策略，不能把课程语言模型的字节词表直接换成四个字符就认为复现了论文。特殊符号、未知碱基、截断与位置映射都需与检查点一致。

对掩码k-mer训练还要考虑重叠带来的目标可见性：被遮词元中的碱基可能出现在相邻未遮词元中，设计目标与解释损失时要检查。评估序列长度时明确单位是碱基还是词元，不能把六碱基词元的上下文数当成同样数量的碱基。Nucleotide Transformer是原始研究参照，具体分词和支持范围应核对所用模型版本的官方文档。

## 反向互补不变性要服从任务含义

双链DNA的反向互补关系可以帮助设计增强或不变表示，但不是所有任务都应抹去方向。若标签与特定链、转录方向或位置有关，反向互补后标签或坐标可能也需要转换。下面用人工序列演示一种无方向的canonical k-mer计数：每个k-mer与其反向互补取字典序较小者。它能让整段序列翻转后计数保持相同，却丢弃方向和长程顺序。

代码对包含N的窗口跳过，并报告有效窗口数。这只是透明的教学选择，不是所有DNA模型的通用规则。真实模型可能有未知词元或不同处理方式，应遵从其分词器。跨数据划分还要把同一序列及反向互补视为相关资料，不能随机分到训练和测试后宣称模型识别了新序列。数学不变性与下游任务有效性依然需要分别验证。

```python
from collections import Counter
complement = str.maketrans("ACGTN", "TGCAN")
def rc(sequence):
    return sequence.upper().translate(complement)[::-1]
def canonical_kmers(sequence, k=3):
    sequence = sequence.upper()
    counts = Counter()
    for i in range(len(sequence)-k+1):
        token = sequence[i:i+k]
        if set(token) <= set("ACGT"):
            counts[min(token, rc(token))] += 1
    return counts
sequence = "ACGTTNCAACGT"  # 人工字符串，不对应具体生物目标
a = canonical_kmers(sequence); b = canonical_kmers(rc(sequence))
assert rc(rc(sequence)) == sequence
assert a == b
print({"forward": sequence, "reverse_complement": rc(sequence),
       "valid_windows": sum(a.values()), "canonical_counts": dict(sorted(a.items()))})
# 无方向的计数不保留长程次序；链特异任务不应未经判断采用这种不变性。
```

## 长上下文需要同时处理边界与资源

长序列模型可以利用更远处的信息，但输入长度、计算成本与可学习结构并非同一概念。将基因组切成窗口时，边界可能切断相关区域；重叠窗口又可能让相同片段反复出现。池化多个窗口能得到基因或基因组表示，但应记录窗口长度、重叠、覆盖率和汇聚规则。训练与测试必须先按来源或同源组隔离，再切窗口，而不是切完后随机拆分。

Evo的原始研究使用以单碱基为单位的长序列自回归路线，并采用StripedHyena混合架构；不能把它直接称为把课程普通Transformer加大。学习它的价值是看到分词粒度、架构和计算预算需要共同设计。课程不运行该大模型，也不以其生成能力作为菌群分类效果的证据。研究扩展可以从适合任务的冻结表示开始，先验证数据与评价，再决定是否需要更长上下文。

## 蛋白语言模型与结构预测组件的区别

蛋白语言模型从氨基酸序列学习上下文表示，可以用于残基级或序列级任务；如何池化、选哪层、是否包含特殊词元都会影响结果。DNA翻译到蛋白还需要正确的编码区、方向与阅读框，不能把任意DNA片段简单三字一组就保证得到生物学有效蛋白。不同菌株的序列变异也可能被只用参考物种代表序列的方案忽略。

ESM-2提供蛋白语言表示，ESMFold则在相关表示基础上构建结构预测系统，两者输出和评价对象不同。结构预测较可信也不自动说明蛋白在某群落中表达、参与某疾病或具有特定体内作用。若本项目使用蛋白嵌入，先建立明确的功能或表型预测基准，并与简单序列特征及功能注释比较。不要把结构图的精细程度当作样本级预测已经有效的证据。

## 同源泄漏比完全重复更隐蔽

只删除完全相同序列仍可能留下高度相似的同源序列、同一基因组相邻窗口或同一蛋白家族的近重复。随机序列拆分可能主要测试识别熟悉家族，而非迁移到新的生物范围。划分应匹配目标：预测新样本、新物种、新家族或新功能分别需要不同隔离层级。聚类或相似性阈值依赖任务、比对覆盖与序列长度，没有适用于所有研究的一刀切数字。

预训练语料也需要纳入来源核查。若使用公开基础模型，某个下游测试序列可能已经出现在无标签预训练中；这不必然使所有使用无效，但要说明评价是在已见序列上学习新标签，还是未见来源的泛化。物种层面的隔离也不自动阻止共享基因家族。保留序列哈希、父级来源、家族簇、注释版本与训练阶段，才能准确表达模型到底遇到了什么新信息。

## 从基因表示到群落需要显式权重

序列模型通常输出基因、片段或蛋白表示，而目标标签可能位于受试者层面。需要定义聚合映射，例如将每个基因表示按样本中的对应丰度加权，再得到群落向量。这里的权重必须来自可解释的测量或映射，不能把物种丰度直接当作每条基因的丰度而忽略拷贝数、菌株差异与比对歧义。若只做近似，应明确说明并与无需该假设的基线比较。

下面用人工向量展示一种加权平均，并把缺少序列表示的基因排除后报告覆盖质量。分母是实际参与聚合的权重和，因此输出表示有条件于已覆盖部分；缺失部分不应被悄悄解释成零信息。同步重排基因顺序和权重后结果不变，验证映射关系正确。这个例子只演示聚合机制，不是在预测真实基因功能，也不能把平均向量解释成完整的群落代谢机制。

```text
h_s = Σ_(g∈observed) a_sg e_g / Σ_(g∈observed) a_sg；coverage_s = 已覆盖权重 / 全部输入权重
```

```python
import numpy as np
E = np.array([[1.,0.], [0.,1.], [1.,1.], [np.nan,np.nan]])
A = np.array([[2.,0.,1.,1.], [0.,3.,1.,0.]])
def pool(abundance, embeddings):
    known = np.isfinite(embeddings).all(axis=1)
    mass = abundance[:, known].sum(axis=1)
    if np.any(mass <= 0):
        raise ValueError("No covered sequence representation for a sample")
    h = abundance[:, known] @ embeddings[known] / mass[:,None]
    coverage = mass / abundance.sum(axis=1)
    return h, coverage
h, coverage = pool(A,E)
order = np.array([2,0,3,1])
h2, c2 = pool(A[:,order],E[order])
assert np.allclose(h,h2) and np.allclose(coverage,c2)
assert np.allclose(coverage,[0.75,1.0])
print({"sample_embeddings": h.tolist(), "covered_mass_fraction": coverage.tolist()})
# 向量和权重全部人工构造，真实研究需验证基因映射与权重单位。
```

## 功能潜力、表达与代谢物不能相互替代

宏基因组基因家族或通路丰度可以描述功能潜力，转录组更接近某一时刻的表达，代谢组测到特定分子浓度，而浓度还受产生、消耗、吸收和宿主过程影响。它们之间存在关系，但不能在缺少测量时直接互相替代。尤其在肠脑研究中，粪便中的某功能预测不等于血液或脑内同一分子的变化，更不能直接推出精神症状因果机制。

跨模态模型可以把这些资料分别编码并学习关联，但输出的意义受训练标签和配对数据限制。先问是否来自同一受试者、采样间隔是否合理、处理批次是否对应，再讨论复杂融合。若功能谱来自与丰度相同的原始测序资料，两者共享技术噪声，预测增益也不一定代表新增独立生物信息。报告应区分新的测量、派生特征和外部先验三种来源。

## 多模态融合需要先建立简单参照

第一组比较是丰度、序列表征、功能谱分别建模；第二组是训练域标准化后的简单拼接或预测后期融合；第三组才是跨模态注意力、共享潜空间或对比配对。若复杂融合只优于弱单模态而未超过简单拼接，就不能将收益全部归因于复杂交互。不同模态维度和缺失比例也会影响模型，使用同一受试者划分、标签预算和调参范围才能解释差异。

缺失模态可能与研究、症状或就诊流程相关，不只是随机丢一半向量。训练中模态dropout可以作为候选策略，但要检验现实缺失模式下的表现，并报告只在完整病例子集评价可能带来的选择偏差。无配对的数据可以支持各自预训练，却不能通过按行凑数变成同一个人的多模态样本。共同文本描述也不能自动解决受试者级配对和时间对齐问题。

## 从冻结表征基准开始，而不是直接重训一切

一个可行的研究扩展是固定序列来源与去重规则，使用适用的公开模型提取冻结表示，再在训练域选择池化和简单预测头。缓存应记录序列哈希、检查点、分词器、层、精度和池化方式，避免更新某个组件后沿用不兼容向量。随后再比较适配器或全量微调，并与相同监督预算的基线对照，只有证据支持时才扩大计算。

本课验收是两段可运行的表示实验与一份完整基准方案，没有完成DNA模型训练、蛋白嵌入提取或真实多模态预测。你应能指出从当前丰度项目到序列模态缺少哪张映射表、哪项测量和哪种独立验证。下一课将把这些要求放入精神疾病与脑影像的具体研究情境，重点处理配对、时间和共享/特异解释，而不把跨模态网络名称当作结论。

## 动手实验 · 搭建从人工序列到样本表示的透明原型

### 1. 明确任务与模态

选择基因级预测或受试者级表型之一，写出每种输入的自然单位与标签来源；仅使用一般科研情境。

检查什么：知道哪些是新测量、哪些是派生特征，不能把物种名当作序列。

### 2. 运行k-mer与反向互补

执行第3节，检查canonical计数一致与有效窗口数；说明这种表示丢失方向和长程顺序。

检查什么：两项断言通过，并能说出一个不适合方向不变性的任务。

### 3. 运行带覆盖率的群落聚合

执行第7节，检查同步排列不变性和0.75、1.0覆盖率。解释未知向量为何不能默默补零。

检查什么：表示和覆盖率均可复算，缺失样本范围明确。

### 4. 制定同源与来源划分

为每条人工记录规划sequence_id、genome_id、family_cluster、subject_id和study。说明先分组后切窗口，以及公开模型预训练重叠的报告方式。

检查什么：重复、反向互补、近同源、同一基因组窗口和同一人不会被不加区分地随机拆分。

### 5. 设计冻结多模态基准

列出单模态、简单拼接、复杂融合三组比较，规定缺失模式与池化配置。实际未提取公开模型嵌入时，保持待执行状态。

检查什么：研究方案有数据映射、预算、对照与外测单位，而不是只列模型名称。

https://doi.org/10.1126/science.ado9336

### Evolutionary-scale prediction of atomic-level protein structure with a language model (2023)

https://doi.org/10.1126/science.ade2574

**阅读问题：** 有蛋白结构预测，是否已经知道它在样本中表达？

**参考思路：** 不是。结构、表达量、环境与体内作用是不同层面的信息，需要相应测量。

**参考思路：** 起止与padding通常不代表实际残基，是否包含会改变池化数值；应使用与任务一致的掩码并记录规则。

## 练习与完整参考解答

### 练习 1. 将一条基因组切成重叠窗口后随机分训练与测试，会出现什么问题？

提示：考虑共享片段、来源和任务泛化单位。

参考解答：不同集合可能含完全重叠片段或同源相邻区域，模型可能识别已见来源而非新基因组。应先按基因组、序列簇或目标需要的更高层级划分，再在各分区内部切窗口，保留原始坐标与来源映射。

### 练习 2. canonical k-mer在反向互补后不变，为什么不一定适合所有任务？

提示：考虑链方向和相对位置是否属于标签信息。

参考解答：它丢弃方向与长程顺序。若标签具有链特异或位置方向语义，强制不变可能删除必要信号；需同步转换标签坐标或选择保留方向的模型，并通过对应任务验证。

### 练习 3. 只有75%的基因权重有可用嵌入，平均向量该如何报告？

提示：分母决定它代表全部群落还是覆盖部分。

参考解答：报告已覆盖权重、缺失原因和对覆盖部分归一化的规则，明确表示条件于这75%。可比较覆盖率作为诊断或筛选条件，但不能无说明把缺失向量当真实零，也不能声称已表示全部功能。

### 练习 4. 序列嵌入加丰度的模型优于丰度单独，但不优于简单拼接，该怎样解释？

提示：分清新增信息与复杂融合结构的贡献。

参考解答：结果可能支持新增模态在该任务的增量，但尚未支持复杂融合优于简单整合。继续检查预算、缺失样本与外测稳定性，不能把全部收益归因于跨模态注意力或新的生物机制。

## 验收自测

### 1. 物种身份嵌入能直接提供什么？

A. 训练词表中该身份的学习向量
B. 该物种所有菌株的完整DNA
C. 真实受试者中的表达量
D. 已验证的疾病因果效应

参考答案：A。身份向量与序列、表达和因果证据属于不同数据层次。

### 2. 长序列训练与测试应在什么时候划分来源组？

A. 窗口随机打乱之后
B. 看到测试AUC之后
C. 合并所有近同源序列之后不再检查
D. 切窗口之前

参考答案：D。先按来源或同源组隔离能防止相同和重叠片段跨集合。

### 3. 两条不同ID的蛋白序列高度相似意味着什么？

A. 只要不是完全重复就安全
B. 可以把一条放测试增加样本数
C. 仍需考虑同源泄漏，ID不同不足以证明独立
D. 一定是两个独立任务

参考答案：C。序列相关性比文件身份更重要，划分应匹配新家族或新来源的目标。

### 4. 宏基因组功能潜力能直接等同哪项？

A. 必然等于精神症状病因
B. 不能直接等同表达、通量或脑内代谢物浓度
C. 必然等于当时转录量
D. 必然等于血液浓度

参考答案：B。不同模态测量不同对象，跨层推断需要额外资料与验证。

### 5. 本课实际完成的序列相关计算是什么？

A. 人工k-mer与覆盖率聚合机制实验
B. 从零训练Evo
C. 真实多模态临床验证
D. 从物种名生成真实基因组

参考答案：A。独立代码验证表示规则；大型序列模型与真实融合仍为明确扩展。
