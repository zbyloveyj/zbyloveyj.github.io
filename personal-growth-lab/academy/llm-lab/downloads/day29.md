## 先把共享与特异变成不同检验

MDD指重性抑郁障碍，SZ指精神分裂症，BD指双相障碍。把三类患者合并与健康对照分类，检验的是该合并任务的预测关系，不自动证明三种疾病具有同一个微生物机制。疾病之间区分、各疾病对共同对照、跨诊断症状维度和未来结局预测，是不同研究问题，需要相应标签、样本范围和评价单位。诊断标准、病程与招募方式也要记录。

若某特征在MDD显著而在SZ不显著，不能据此认定它具有MDD特异性；“显著与不显著”本身不等于效应差异显著。应直接比较效应差、交互或独立外测中的区分能力，并检查用药、年龄和研究背景。共享对照可以提高设计一致性，但同一人的多次使用会让结果相关。这里提出的是一般方法框架，不宣称某种具体菌已被证明解释这些诊断。

## 配对表比融合网络先完成

每个模态记录都应关联全局受试者、样本或影像ID、采集时间、数据可用时间、研究和处理批次。粪便、血液、影像与症状量表未必同一天取得，允许时间窗需要依据问题预先规定。以第零天输入预测未来结局时，第两天影像即使离得很近，也可能在预测时不可用。不能因为它与目标相关，就事后扩大窗口把未来资料纳入。

下例为四名人工受试者匹配第零天前七天内最近的影像，明确排除未来资料；一个人只有第两天影像，所以被标记为缺失。它演示的是输入可用性而不是临床最佳采样间隔。对回顾性同期关联，可以定义不同规则，但应改写任务与时间合同。缺失配对后还要比较留下与排除人群的组成，避免只在完整病例子集得到便利而偏倚的结论。

```python
microbiome = [{"subject": s, "prediction_day": 0} for s in ("toy_A","toy_B","toy_C","toy_D")]
images = [{"subject":"toy_A","available_day":-1}, {"subject":"toy_A","available_day":30},
          {"subject":"toy_B","available_day":2}, {"subject":"toy_C","available_day":-3},
          {"subject":"toy_D","available_day":-2}]
split = {"train":{"toy_A","toy_B"}, "test":{"toy_C","toy_D"}}
assert not split["train"] & split["test"]
paired, missing = [], []
for row in microbiome:
    cutoff = row["prediction_day"]
    valid = [r for r in images if r["subject"] == row["subject"] and cutoff-7 <= r["available_day"] <= cutoff]
    if valid:
        chosen = max(valid, key=lambda r:r["available_day"])
        paired.append((row["subject"],chosen["available_day"]))
    else:
        missing.append(row["subject"])
assert missing == ["toy_B"]
assert all(day <= 0 for _,day in paired)
print({"paired": paired, "missing_at_prediction": missing})
# available_day表示预测时实际可获得数据的日期，不能只看采集日期。
```

## 影像特征与时间片段不等于新受试者

结构影像、功能连接和任务反应具有不同预处理与误差来源。图谱、区域定义、质量控制、头动、扫描设备和参数需要记录；数据驱动的区域选择或降维若利用了全体受试者，也可能泄漏。将一人的功能时间序列切成许多窗口，并没有创造很多独立人；训练测试仍应保持受试者与目标外测层级一致，评价时说明窗口如何汇聚。

协变量处理同样要服务于问题。头动与疾病、年龄或症状可能关联，删除高头动个体会改变样本构成，回归也依赖模型假设。固定的单样本预处理与从全队列估计的校正不是同一回事，应分别记录。若研究目标是未来预后，随访后获得的影像质量或治疗变化不能成为基线预测输入。一个整洁的矩阵并不意味着它已经满足时间和独立性要求。

## cVAE的背景对比不是同义于疾病因果分解

这里的cVAE专指contrastive variational autoencoder，即对比变分自编码器，不是泛指conditional VAE。原始方法用目标组和背景组学习共同潜变量z及在目标组更突出的潜变量s；背景生成过程将s设为缺席或最小贡献。两组个体不需要一对一配对，但需要有理由认为背景代表了希望排除的变化。用不同医院的健康人作背景时，潜变量可能吸收医院差异。

把s命名为“疾病特异”不会自动赋予它生物解释。重建、先验正则和潜变量独立约束只能落实模型假设，不能保证唯一可识别的机制。用于多诊断时应预先规定共享与各诊断特异结构、背景构成及外测任务，并与普通VAE、线性方法和协变量对照比较。当前课程不训练cVAE；它的价值是提供可检验的建模假设，而不是把无监督坐标直接当成病因。

```text
目标组：x ∼ pθ(x|z,s)；背景组：b ∼ pθ(b|z,0)。共同与突出的语义取决于背景设计和模型假设。
```

## sCCA与PLS的目标并不相同

CCA寻找两组变量的线性投影，使投影相关最大；sCCA在此类框架中加入稀疏约束，便于高维和变量选择。PLS则侧重投影的共同协方差或预测关系，不同算法与缩放会影响具体解。稀疏权重不等于稳定生物标志物，训练相关高也不代表外部相关高。特征数远大于受试者数时，正则化、分量数和筛选必须在训练域内选择。

两模态应来自对应受试者和符合定义的时间窗，不能随意按文件行号配对。共同年龄或研究因素可能制造跨模态关联，因此应在明确假设下比较调整前后与协变量模型。Witten等原始研究提供了惩罚矩阵分解与稀疏关联的方法基础；PLS的影像原始应用可阅读McIntosh等1996年研究，DOI为10.1006/nimg.1996.0016。两类方法都不能仅凭相关方向识别肠道到大脑的因果方向。

```text
CCA关注corr(Xu,Yv)，典型约束为投影方差归一；PLS关注共同协方差或预测结构，缩放与算法定义必须写明。
```

## 实跑：训练域残差化后的PLS关联

下面生成一组人工菌群特征与人工影像特征，两者含共同潜变量、年龄和研究效应。先只用训练受试者拟合各模态对协变量的线性关系，再把固定系数应用到留出资料，随后在训练残差上拟合一个PLS分量。留出相关用于检查该学习关系是否可延续；打乱留出配对只作直观对照，不是完整置换检验。所有数值都来自模拟，没有任何真实诊断结论。

这段代码展示了处理顺序，不宣称线性残差化总能消除混杂，也没有执行严格的跨新研究外测。真实研究还需要检查非线性、交互、测量误差和外推，分量数若要选择应增加内层验证。若正式使用置换检验，需要依据可交换性设计置换单位并重跑相关选择流程。不能只计算一次训练相关或挑一张漂亮的PLS散点图，就声称发现了肠脑联系。

```python
import numpy as np
from sklearn.cross_decomposition import PLSRegression
rng = np.random.default_rng(29)
n = 120
age = rng.uniform(18,65,n); site = rng.integers(0,2,n)
C = np.column_stack([np.ones(n),(age-40)/10,site])
latent = rng.normal(size=(n,1))
X = latent @ np.array([[1.,0.8,-0.6,0.4]]) + C @ rng.normal(size=(3,4)) + rng.normal(0,0.35,(n,4))
Y = latent @ np.array([[0.9,-0.7,0.5]]) + C @ rng.normal(size=(3,3)) + rng.normal(0,0.35,(n,3))
train = np.arange(80); test = np.arange(80,n)
Bx = np.linalg.lstsq(C[train],X[train],rcond=None)[0]
By = np.linalg.lstsq(C[train],Y[train],rcond=None)[0]
Rx = X-C@Bx; Ry = Y-C@By
model = PLSRegression(n_components=1,scale=True).fit(Rx[train],Ry[train])
tx,ty = model.transform(Rx[test],Ry[test])
correlation = np.corrcoef(tx[:,0],ty[:,0])[0,1]
shuffled = np.corrcoef(tx[:,0],ty[rng.permutation(len(test)),0])[0,1]
assert np.isfinite([correlation,shuffled]).all()
print({"heldout_paired_correlation": float(correlation), "one_shuffled_control": float(shuffled)})
# 单次打乱不是显著性检验；该合成PLS例子不是sCCA、cVAE或真实肠脑模型。
```

## 规范模型估计个体偏离，而不是直接分类

规范模型用参考资料估计生物特征在年龄、性别或其他条件下的分布，再描述一个个体相对于该条件分布的位置。它可以揭示同一诊断内部不同的偏离模式，但偏离不等于病理，更不等于某种疾病的确定诊断。参考人群、条件变量、预测不确定性与外部校准决定了偏离是否有意义；在未覆盖年龄或设备上的外推尤其需要说明。

下例是简化的线性同方差高斯情形，用训练残差方差和均值估计杠杆项计算预测残差的尺度。它并未复现Marquand等原始高斯过程规范模型，也不能把输出直接叫临床异常分数。有限样本下标准化预测残差不必精确服从标准正态；真实规范建模还要检验分布、异方差、校准及多脑区重复比较。例子中的高年龄点会被明确标为训练范围外。

```text
r* = [y − μ̂(c)] / sqrt[σ̂²_noise + σ̂²_mean(c)]；偏离解释依赖参考分布、模型假设和校准。
```

```python
import numpy as np
rng = np.random.default_rng(2907)
age = rng.uniform(18,60,70)
C = np.column_stack([np.ones(len(age)),(age-40)/10])
y = 2.0-0.3*(age-40)/10+rng.normal(0,0.4,len(age))
beta = np.linalg.lstsq(C,y,rcond=None)[0]
sigma2 = np.sum((y-C@beta)**2)/(len(y)-C.shape[1])
new_age = np.array([25.,45.,80.])
new_C = np.column_stack([np.ones(3),(new_age-40)/10])
observed = 2.0-0.3*(new_age-40)/10+np.array([0.,0.8,-0.8])
mean = new_C@beta
leverage = np.einsum("ij,jk,ik->i",new_C,np.linalg.inv(C.T@C),new_C)
standardized = (observed-mean)/np.sqrt(sigma2*(1+leverage))
outside = (new_age<age.min()) | (new_age>age.max())
assert outside.tolist() == [False,False,True]
assert np.isfinite(standardized).all()
print({"standardized_predictive_residuals": standardized.tolist(), "outside_training_age": outside.tolist()})
# 合成线性参考模型；不是疾病诊断，也不保证精确标准正态校准。
```

## 纵向目标要规定预测时点与随访窗口

横断面分类、个体内变化、未来症状预测和首次事件风险是不同任务。预测未来结局时，要定义基线时点、输入历史窗口、结局窗口与可用时间；只在完成随访的人群上训练可能引入选择偏差。没有记录到事件并不自动等于没有事件，失访和随访长度需要单独处理。把未来诊断、治疗反应或事后整理的病程变量输入基线模型，会直接泄漏。

纵向分析还要区分人与人差异和同一个人的变化。一个人长期处于较高某特征，未必说明该特征短期增加就对应症状加重。混合效应、个体内中心化或时间序列方法可以帮助表达层级结构，但不能仅靠时间先后消除所有混杂。所有访视的划分应服务于目标：预测新个体通常整体留出受试者，预测同一个体未来则必须严格限制历史可见信息。

## 缺失模态和药物是研究设计问题

影像缺失可能与症状、配合程度或就诊流程有关；菌群缺失可能与样本采集和处理相关。只保留全模态个体会改变研究对象，训练时随机遮掉模态也未必模拟这种实际缺失。应记录缺失模式、比较完整与不完整人群，并分别评价可用模态组合。插补值不是新测量，不能在报告里增加真实配对人数。

药物、饮食和病程可能同时影响症状及测量，但“全部回归掉”不一定对应你想问的问题。若目标是在现实用药人群中预测，就要说明预测时可用变量；若研究未治疗状态的关联，可能需要不同纳入设计或敏感性分析。背景组和目标组若来自不同站点，cVAE、sCCA或深度融合都可能学到站点差异。复杂模型不能弥补关键组间没有交叉覆盖。

## 用三项可被推翻的假设组织研究

假设一：菌群在临床协变量之外能增加未来症状预测信息；对照是协变量单独、菌群单独和联合模型，外测按研究与时间定义。假设二：某组跨模态关联可以在新研究保持方向和预测关系；对照包括独立配对、协变量处理和保留交换结构的置换。假设三：一个对比潜变量反映跨诊断共享变化；需要在各诊断与独立背景中检查，而不是只看合并患者分类。

每项假设都提前写下会让你降低信心的结果，例如联合模型没有超过协变量，关联只存在于单站点，或潜变量主要预测扫描设备。预先确定任务、主要指标和分析范围，避免把任意探索结果改写成既定机制。若需要讨论中介或因果方向，还必须另行说明识别假设与研究设计；相关模型和生成模型本身不提供这些条件。

## 产出一份克制而具体的多模态研究说明

最终说明先写任务与人群，再写配对时间、模态处理、协变量、模型与评价。图表可以展示样本流转、时间轴、留出关联和个体偏离分布，但要同时标明样本数、研究数、缺失和训练范围。所有人工例子标为合成，真实资料未运行时只列接口与待执行计划。

## 论文导读

### Contrastive Variational Autoencoder Enhances Salient Features (2019)

https://arxiv.org/abs/1902.04601

阅读对比VAE原始预印本，理解目标/背景共享与突出变化的生成假设；不将其描述成已证实的疾病因果分离。

- 看目标由z和s生成、背景由z生成的模型图。
- 区分组间不配对与同一人的跨模态配对，两者解决不同问题。
- 构造一个目标/背景站点完全不同的反例，解释s为何可能吸收站点。

**阅读问题：** cVAE的突出潜变量是否天然代表疾病机制？

**参考思路：** 不是。语义来自背景选择、模型约束与验证；技术、年龄或招募差异也可能进入该空间，必须有对照和独立检验。

**阅读问题：** 背景组个体需要与目标组逐人配对吗？

**参考思路：** 原始对比VAE不要求两组逐人配对，但需要合理的背景分布假设；这不允许把两模态中不同人按行伪配对。

### A penalized matrix decomposition, with applications to sparse principal components and canonical correlation analysis (2009)

https://doi.org/10.1093/biostatistics/kxp008

从原始方法理解稀疏线性关联和惩罚约束，避免把高训练相关当作可泛化生物关系。

- 阅读交叉乘积矩阵上的惩罚分解及其与CCA的联系。
- 对照训练域内选择稀疏程度、特征缩放与留出评价。
- PLS影像方法补充阅读原始研究https://doi.org/10.1006/nimg.1996.0016，比较目标和解释。

**阅读问题：** 得到少量非零权重为什么还不够？

**参考思路：** 稀疏性是优化约束，不能保证选择稳定或因果有效。需要独立配对资料、稳定性与适当的混杂对照。

**阅读问题：** 为什么必须保留受试者配对？

**参考思路：** CCA或PLS描述同一观察单位两组变量的共同变化；错位配对改变了统计问题，可能使结果失去含义。

### Understanding Heterogeneity in Clinical Cohorts Using Normative Models: Beyond Case-Control Studies (2016)

https://doi.org/10.1016/j.biopsych.2015.12.023

理解根据条件参考分布描述个体偏离的原始框架；课程线性例子只演示其中的预测残差思想。

- 区分组平均差异与个体相对于条件分布的位置。
- 查看原研究如何用高斯过程估计预测及其不确定性。
- 列出参考人群、训练范围、校准和多变量重复比较对你的任务的影响。

**阅读问题：** 规范模型中的偏离是否等于诊断？

**参考思路：** 不等于。偏离依赖参考分布、测量与模型，可能来自正常变异、外推或技术因素，需要与实际任务和独立证据联系。

**阅读问题：** 年龄超出训练范围还能机械解释相同分数吗？

**参考思路：** 不应。外推依赖未验证假设，预测不确定性也可能失准，应标记范围并获取适用参考资料。

## 练习与完整参考解答

### 练习 1. 某菌在MDD组p<0.05而SZ组p>0.05，研究者说它只与MDD有关。如何修正？

提示：两次显著性判断并不是效应差的直接检验。

参考解答：应直接比较效应差、交互或独立任务表现，并报告不确定性、样本构成与多重比较。SZ未达显著可能来自精度不足，不能当作零效应证据。结论可先写为当前两个分析的观察差异，不能立即称疾病特异机制。

### 练习 2. 要预测基线后六个月症状，用一周后的影像和半年后的用药变化作输入有何问题？

提示：区分接近基线与预测时已经可获得。

参考解答：若预测时点固定为基线，这些信息尚不可用，尤其未来用药可能受结局过程影响，构成时间或预后泄漏。应只用时点前已可获得资料，或重新定义预测时点与目标窗口，并在对应协议下评价。

### 练习 3. 患者来自站点A，健康背景来自站点B，cVAE分离出漂亮潜空间。可以称疾病特异空间吗？

提示：模型看到的组差异并不只有疾病。

参考解答：不能。突出空间可能反映设备、流程、人口或招募差异。需要交叉覆盖、站点与协变量对照、独立研究验证及稳定性分析。给潜变量起名不能消除完全混杂，漂亮可视化也不提供因果识别。

### 练习 4. 合成PLS留出相关较高，是否证明菌群影响大脑？规范残差较大又说明什么？

提示：分别解释关联与条件偏离的估计对象。

参考解答：PLS只展示该人工生成关系可在留出数据延续，真实关联也可能受共同因素影响，不能确定方向或因果。规范残差表示相对于所拟合条件参考的偏离，其意义依赖校准、参考范围和测量质量，不能直接作为疾病诊断。

## 验收自测

### 1. 本课cVAE中的c指什么？

A. 所有情形下都指conditional
B. clinical，自动临床验证
C. causal，已经识别因果
D. contrastive，对比目标组与背景变化

参考答案：D。这里明确采用Abid与Zou的contrastive VAE，不应混用同缩写的方法。

### 2. 第零天做预测，第两天才可获得的影像应如何处理？

A. 用测试效果决定是否纳入
B. 当作第零天的真实测量
C. 按当前时点标为不可用，或明确重定义预测时点
D. 因为只晚两天就直接使用

参考答案：C。输入合法性取决于预测时可用时间，接近基线不等于已经可用。

### 3. sCCA或PLS训练相关很高首先还需要什么？

A. 把每个影像窗口算成独立人
B. 留出配对评价、选择控制和混杂检查
C. 直接写成肠脑因果通路
D. 删除不配合故事的受试者

参考答案：B。高维方法容易过拟合，配对、单位和独立验证是解释前提。

### 4. 规范模型最直接描述什么？

A. 相对于条件参考分布的个体位置或偏离
B. 某种精神疾病的确定诊断
C. 肠道微生物的治疗靶点
D. 不依赖人群的通用异常值

参考答案：A。规范偏离依赖参考、条件和校准，不能自动升级为病理或诊断结论。

### 5. 一个模态被插补出来，可以怎样计入数据说明？

A. 增加一名真实配对受试者
B. 写成新获得的实际影像
C. 无需报告缺失机制
D. 记录为派生估计并保留原始缺失状态

参考答案：D。插补不增加真实测量或独立人，缺失模式与估计不确定性仍需保留。
