## 先画测量链：模型只能看见测量过程留下的信号

CurateMicrobiota 的默认入口是样本×特征矩阵；它省去了测序处理，并没有消除这些处理对数值的影响。一个完整记录应能追溯到原始样本、建库、测序批次、文件清单、质量处理、参考数据库、定量方法和合并规则。模型学到的差异可能来自生态，也可能来自提取效率、测序深度、宿主比例或参考覆盖。只有先说明矩阵每列如何产生，后面的预训练目标才有科学含义。

准备两条路线：有原始 reads 时，在合适权限内统一处理并记录计算资源；只有公开处理表时，保留原作者的软件、数据库和单位，明确哪些环节不能重做。不能为了让流程看起来统一而把未知版本写成当前版本，也不能将已处理丰度反推成真实 FASTQ。对本项目，先用 curatedMetagenomicData 的可追溯表完成建模闭环，再把原始数据路线作为独立的扩展实验。

| 分支 | 直接得到 | 还不能推出 |
| --- | --- | --- |
| 参考谱分析 | 参考定义下的分类/功能估计 | 所有未入库物种都不存在 |
| 组装与分箱 | 样本支持的 contig、bin、MAG | 每个 MAG 都是完整、单一菌株 |

## 样本清单与质控：先统一计数单位，再谈阈值

FASTQ 中一条 read 有序列与质量值，双端测序的一对 reads 通常来自同一片段。read、read pair、碱基数不能放进同一个留存率分母。Phred 质量值 Q=-10log10(p_error)，是测序错误概率的编码；对质量分数取平均后再换算概率，并不等于直接平均每个碱基的错误概率。实际质控还涉及接头、长度、低复杂度、配对保留与去重策略，应记录所选工具版本和显式参数。

本课不规定适合所有项目的质量或深度阈值。先依据研究平台、质控目的与盲于测试结果的规则预设排除标准，再分别统计每个 study、病例组、时间点的流失。若病组原本宿主比例更高，过滤可能改变研究人群构成；若按测试表现反复调整深度阈值，评估已经受到选择影响。质量列可以用于技术诊断，但是否作为预测输入还要考虑真实使用时能否获得及其与中心的关系。

## 独立实验一：让过滤日志在数量上说得通

下面只演示一条明确的顺序过滤：先质量处理，再从剩余 reads 中去除宿主，最后得到分析 reads。这个顺序要求 raw≥qc_pass，且 analysis=qc_pass−host_removed。不同工具可能分别报告成对保留、单端保留、多个参考匹配或累计去除，必须先转换到统一合同；不能把本例等式不加判断地用于全部日志。

除验证正常记录外，代码故意制造一个无法守恒的样本并要求程序拒绝。这种负例比仅打印一张质控图更有帮助。真实项目还应验证原始文件配对、校验和、重复 sample_id、缺失处理结果以及被排除样本的原因。当前打印的是人工日志的检查结果，并不是任何真实队列的留存率。

```python
from copy import deepcopy
# 合成日志；所有数量都是单条 read，不是 read pair，也不是碱基数。
records = [
    {"sample_id": "S1", "unit": "reads", "raw": 10000,
     "qc_pass": 9000, "host_removed": 1000, "analysis": 8000},
    {"sample_id": "S2", "unit": "reads", "raw": 12000,
     "qc_pass": 11000, "host_removed": 3000, "analysis": 8000},
]
def audit(records):
    ids = [r["sample_id"] for r in records]
    if len(ids) != len(set(ids)):
        raise ValueError("Duplicate sample_id")
    rows = []
    for r in records:
        if r["unit"] != "reads":
            raise ValueError("Do not mix reads and pairs")
        vals = [r[k] for k in ("raw", "qc_pass", "host_removed", "analysis")]
        if any(type(v) is not int or v < 0 for v in vals):
            raise ValueError("Counts must be nonnegative integers")
        if not (r["raw"] > 0 and r["qc_pass"] <= r["raw"]
                and r["analysis"] == r["qc_pass"] - r["host_removed"]):
            raise ValueError("Sequential count contract violated")
        rows.append({"sample_id": r["sample_id"],
                     "retained_fraction": r["analysis"] / r["raw"]})
    return rows
summary = audit(records)
assert summary[0]["retained_fraction"] == 0.8
bad = deepcopy(records); bad[1]["analysis"] += 1
try:
    audit(bad)
except ValueError:
    print("Expected rejection: inconsistent stage counts")
else:
    raise AssertionError("Invalid counts must be rejected")
print(summary)
# 此合同只适用于这里声明的顺序过滤日志；真实工具须先解析其计数定义。

```

## 宿主去除与污染控制：参考覆盖决定可解释范围

宿主去除以给定宿主参考和比对规则识别相关 reads；过滤后仍需审查残留与异常样本，不能把“运行过程序”视作零残留的证明。双端处理应保留成对与失配单端的明确去向，后续工具需要何种输入就使用对应规则。KneadData 官方说明列出了双端质量处理可能产生的不同输出；实际执行时以固定版本的帮助信息和日志定义为准。

技术污染与宿主序列是两类问题。阴性对照、提取批次、建库批次及样本生物量有助于发现技术来源；相对丰度较低也不等于污染，较高也不保证是真实定植。原始宿主相关资料可能含个人信息，课程公开演示只发布合成材料、汇总质控与授权的非识别结果。记录的数据来源和使用范围应与 D10 的数据说明一致，不能因为是分析副产物就省略这些信息。

## 物种谱与数据库：SGB 是分组单位，不是永久不变的名字

MetaPhlAn 4 原始研究采用物种级基因组分组 SGB，并通过相应标记序列估计群落组成。这与把全部 reads 按任意分类标签简单计数不是同一操作。参考覆盖、标记选择及估计规则会影响检出与丰度；输出的百分比要按具体资源说明转换，不能默认它就是测序 reads 的直接百分比。不同工具估计的对象也未必完全相同。

跨数据库版本时，旧编号可能被合并、拆分或重新命名。建立带来源和版本的 crosswalk，并区分一对一映射、只能升到共同祖先的映射以及无法可靠映射。把一对多关系随意复制成多个非零特征会凭空增加质量；把无法映射全部补零会把“未知”改写为“不存在”。学习目标是说清可比较的分辨率，再决定统一重跑、限制共同特征或分层分析。

## 功能表有层级：基因家族、分层贡献与通路不是同一种量

HUMAnN 的参考路线通过核酸与翻译搜索等步骤得到基因家族信息，并进一步归并功能与估计通路。默认基因家族输出常用 RPK 表示长度归一化后的量，它本身没有消除样本测序深度差异。跨样本分析应明示后续归一化方式、保留的特征集合、未映射类别以及总量分母。不要把 RPK 直接交给假定原始计数的模型，再解释成严格的测序抽样似然。

同一基因家族的未分层总量与按物种分层的贡献是两种视图；在贡献齐全且单位相同时，贡献可核对总量，不能把两种视图拼接后再作为互不重叠类别归一化。通路则是从反应/基因关系推断的高层结果，通路覆盖与通路丰度也各有含义。不同物种可能共同支持群落通路，因此不能将基因家族层面的简单守恒规则无条件移植到推断通路。

## 独立实验二：抓住功能总量与物种贡献的重复计数

人工表有 GF_A 和 GF_B 两个家族，每个家族的总量只出现一次，带竖线的行表示其分类贡献。先在家族内部核对分层量，再单独选择未分层层级计算相对值。代码保留 unclassified，避免只加已知物种却误报总量不一致。把全部行相加将得到三十，而真正的两个家族总量是十五。

这个例子是在完整人工基因家族层级上的代数检查。真实表可能经筛选、重分组、单位转换、舍入或不完整导出；必须把这些步骤放进合同后再选择容差和比较范围。归一化得到的比例只针对本例保留的两个家族，并不代表所有微生物功能。若把比例送入模型，应同步保存特征集合和归一化分母，避免不同队列得到看似同名却语义不同的列。

```python
import math
# 人工基因家族表：同一单位、同一层级，所有物种贡献（含未分类）均保留。
rows = {"GF_A": 10.0, "GF_A|taxon_1": 6.0, "GF_A|taxon_2": 3.0,
        "GF_A|unclassified": 1.0, "GF_B": 5.0,
        "GF_B|taxon_1": 2.0, "GF_B|unclassified": 3.0}
total = {k:v for k,v in rows.items() if "|" not in k}
for family, amount in total.items():
    parts = [v for k,v in rows.items() if k.startswith(family+"|")]
    assert math.isclose(sum(parts), amount, rel_tol=1e-9, abs_tol=1e-9)
assert sum(total.values()) == 15.0
assert sum(rows.values()) == 30.0
fractions = {k: v/sum(total.values()) for k,v in total.items()}
assert math.isclose(sum(fractions.values()), 1.0)
print({"unstratified_total": sum(total.values()),
       "incorrect_double_count": sum(rows.values()),
       "fractions_for_this_retained_feature_set": fractions})
# 这是基因家族的守恒例子；推断出的通路总量不必等于物种通路量之和。

```

## 组装、分箱与 MAG：缺少基因可能只是没有恢复出来

组装将 reads 支持的信息连接成 contig，分箱再按组成、覆盖及其他线索整理出候选基因组。MAG 是重建对象，不保证与单个完整菌株一一对应。高相似菌株、重复区、覆盖不均和不同样本组合策略都会影响恢复；评估应记录组装、分箱、去冗余和质量估计流程。MIMAG 给出了报告组装质量、完整度、污染等信息的标准框架，不能只报一个 N50 就宣称样本中所有功能已被恢复。

若用 MAG 基因缺失做模型输入，需同时考虑完整度和覆盖。没有恢复到某基因不等于该生物真正缺失该基因；污染也可能制造不属于该基因组的功能。把完整度加入敏感性分析、核查比对支持，并与参考谱基线比较，比让网络自行“理解不完整”更可检验。SGB 聚类、物种注释和 MAG 质量是不同坐标，不要把分到一个熟悉物种名当作质量已合格。

## 菌株与变异：SNV 的观察范围必须随覆盖一起保存

物种丰度与菌株差异回答不同问题。一个物种可能在多个样本中丰度相近，却含不同的序列变异；同一样本也可能存在混合菌株。基于参考比对的变异调用受深度、比对唯一性、等位基因比例、可比位点与参考选择影响。没有足够覆盖的位置应标为未观测，不能编码为与参考一致，更不能直接将所有未调用位点填成零差异。

做跨受试者距离或模型训练时，保存可比较位点的分母和筛选规则，并检查深度是否与疾病或中心关联。同一人的纵向菌株资料仍属于同一个分组单位，不能因为位点很多就把有效样本量扩大成位点数。组装、SNV、功能注释可以给生态模型增加信息，但在尚无配对数据时只能作为预先定义的扩展，不能从现有物种丰度表推断已经测到了菌株替换。

## 把测量证据接回训练：冻结特征之后再划定学习步骤

整理一张运行清单：sample_id、subject_id、study、采样时间、原始文件校验和、软件和数据库版本、质控计数、输出单位、映射版本、失败原因。模型使用的流行度筛选、缩放、缺失填补及学习得到的特征映射仍需在训练域内拟合；使用统一的固定测量参考不意味着允许把测试队列分布送进所有预处理。若研究有无标签测试域适配，应单独声明设定并另设最终外部测试。

本课可以立即完成的是两项表格合同实验和测量链设计。真实 reads 处理需要相应数据、数据库、存储与计算时间，课程不把人工日志标成实际处理记录。毕业交付应能回答每个数字来自哪里、哪一步丢了多少样本、哪些特征不可比较，以及这些限制如何影响研究结论。下一课再讨论把系统发育、图结构和概率生成目标加入模型时，如何让先验与证据各自可检查。

- 为 MAG 特征设计覆盖与质量敏感性分析，记录评估版本。

**阅读问题：** 高 N50 是否足以证明 MAG 高质量？

**参考思路：** 不能。连续性、完整度、污染及其他必要信息应分别评估，N50 只反映其中一方面。

## 练习与完整参考解答

### 练习 1. 日志写原始500万 pairs、过滤后800万 reads，能否直接说留存160%？

提示：先定义两边的计数对象，并检查孤立单端。

参考解答：不能。成对片段数与单条 reads 不是同一单位。若确为每对两条且输入齐全，原始为1000万 reads；但后续是否含单端、重复或不同阶段累计仍需查日志，只有对齐口径后才能计算留存率。

### 练习 2. GF_A 总量10，已知物种贡献6和3，未分类贡献1；怎样构建家族丰度特征？

提示：总量层与分层层表达同一份信息。

参考解答：在总量分析中只使用10。物种贡献分析保留6、3和1并声明分层对象；不能把10、6、3、1当作互斥类别归一化。删除未分类后剩9也不能称完整贡献分解。

### 练习 3. 两个版本把旧物种拆为两个 SGB，如何合并跨队列表？

提示：问有没有可靠的一对多丰度分配信息。

参考解答：没有分配信息时，不能将旧丰度复制到两个新列。可统一重处理，或在已核实的共同上级单位聚合；否则保留不可比和未知状态，报告映射覆盖并做限制性分析。

### 练习 4. 病例组 MAG 更不完整，某代谢基因检出率也更低，应怎样继续？

提示：测量缺失与真实缺失可能产生同样的表。

参考解答：先比较覆盖、完整度、组装策略与中心分布，核对基因比对支持，在质量可比子集中做敏感性分析。未恢复基因应与真实缺失区分，不能直接据此断言病例功能缺失，更不能把网络拟合当作偏差已被修复。

## 验收自测

### 1. MetaPhlAn 物种丰度与原始 reads 的简单类别比例有什么关系？

A. 永远完全相同
B. 前者受标记和估计规则定义，不能无条件视为直接 read 比例
C. 只要都写百分号就相同
D. 与参考数据库无关

参考答案：B。相同显示单位不代表相同估计对象。

### 2. HUMAnN 基因家族总量与同一家族分层行同时相加通常会怎样？

A. 提高样本量
B. 自动消除测序深度
C. 把同一量重复计算
D. 证明跨物种互作

参考答案：C。分层量是总量的贡献分解，应选择明确层级。

### 3. 低覆盖位置没有检出 SNV，应默认编码成什么？

A. 未观测状态，并保留可比位点范围
B. 必为参考等位基因
C. 必为突变等位基因
D. 物种消失

参考答案：A。无足够观察证据与观察到参考状态不同。

### 4. 仅有公开处理表时，最可靠的接入说明是哪项？

A. 默认自己重新质控过
B. 未知数据库年份补成当前年份
C. 反推 FASTQ 后称统一处理
D. 保留原版本与单位，说明不能重跑的环节

参考答案：D。可追溯性包括诚实记录无法重新执行的环节。

### 5. 本课实际执行的是什么？

A. 真实队列宿主过滤
B. 全部样本 MAG 组装
C. 人工日志与功能表的合同实验
D. 临床菌株替换验证

参考答案：C。代码只验证数据合同机制，不产生真实队列处理证据。
