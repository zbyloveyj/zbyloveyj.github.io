## 先写清图边是什么：关系不能由箭头外观决定

分类树组织命名层级，系统发育树表达特定序列和推断方法支持的演化关系，共现图表达特定资料和统计方法下的关联，文献知识图谱则把实体与关系声明连接起来。它们都能写成节点与边，却不是同一种证据。两种微生物在样本中共同变化，不意味着存在直接互作；文献同时提及物种与疾病，也不等于作者证明了因果关系。

选结构先验时先明确假说：相近演化位置是否帮助共享有限标签？已知功能关系是否减少稀疏特征的估计方差？若先验并不对应目标，图会把无关信号混在一起。对每条边保留类型、方向、权重、来源和版本；未注明证据级别的知识图谱不适合直接进入可信证据助手。学习者应能把一张图还原成可以审查的表，而不是用网络图的复杂程度代替科学理由。

## 先验图与数据估计图：哪一步有机会看到测试域

外部固定的分类关系可以作为预先定义的输入先验，但仍需记录版本和节点映射。由丰度相关性、偏相关或监督标签估计出来的图，是模型拟合的一部分，必须在每个训练折内重新估计，阈值和正则化由训练/验证资料选择。即使没有使用测试标签，用所有队列丰度估图也已经引入测试域分布；若这样做，应明确称作跨域适配或传导设定，并保留另一个独立评估范围。

菌群组合性可能制造表观相关，测序中心和药物也可能产生共同变化，因此图估计方法需要与 D25 的测量假设一致。参考图遗漏边、错误边或低覆盖节点并不罕见；为这些情况安排随机删边、节点未见、不同图版本和无图基线。数据图与外部知识图还可能共享原研究来源，应检查是否把测试研究的结论提前作为标签相关知识输入。

## 独立实验一：消息传递应跟随节点身份一起重排

图卷积的一种常见形式是先添加自环，再用两侧的度归一化调整邻居贡献，随后进行线性变换与非线性映射。它把局部邻接关系加入了特征传播，不会自动赋予边以生态意义。下面四个匿名节点只用来说明计算；代码处理的是非负无向邻接，不应直接塞入带符号、定向或多关系图而不修改归一化定义。

如果同时重排邻接矩阵的两轴和节点特征，节点输出也应按同样顺序重排，这叫置换等变；对节点做对称池化后，样本输出应保持不变。如果只重排丰度而没有重排节点身份或图，模型读到的对象已经变了。代码包含这个错误对照。真实图模型还要检查节点映射、缺少节点及批次样本的图布局；此处没有执行图训练或证明预测提升。

```text
A_tilde=A+I；S=D_tilde^(-1/2) A_tilde D_tilde^(-1/2)；H_next=ReLU(SHW)
```

```python
import numpy as np
# 四个匿名分类单元构成的人工无向图，不代表真实生态互作。
A = np.array([[0.,1.,0.,0.],[1.,0.,1.,0.],
              [0.,1.,0.,1.],[0.,0.,1.,0.]])
H = np.array([[1.,0.],[0.,1.],[1.,1.],[0.2,0.7]])
W = np.array([[0.5,-0.2],[0.3,0.8]])
def layer(A, H):
    if not np.allclose(A,A.T) or np.any(A < 0):
        raise ValueError("This lesson assumes nonnegative undirected adjacency")
    At = A + np.eye(len(A))
    inv = 1.0 / np.sqrt(At.sum(axis=1))
    norm = inv[:,None]*At*inv[None,:]
    return np.maximum(norm @ H @ W, 0.0)
Z = layer(A,H)
p = np.array([2,0,3,1])
Zp = layer(A[np.ix_(p,p)], H[p])
assert np.allclose(Zp,Z[p])
assert np.allclose(Zp.mean(axis=0),Z.mean(axis=0))
wrong = layer(A,H[p])  # 只重排特征，图没有同步重排。
assert not np.allclose(wrong,Z[p])
print({"node_embeddings": Z.tolist(),
       "pooled_embedding": Z.mean(axis=0).tolist(),
       "permutation_equivariance": True})

```

## 图越深不一定越好：平滑、瓶颈与解释

消息传递让多个邻域的信息混合。层数增多可能使表示越来越难区分，也可能在狭窄连接处把很多远处信息压到有限维度；这两类问题分别涉及过度平滑和信息压缩瓶颈，不能靠一个更大的嵌入维数自动消除。残差、跳连、层数、边权和图的稀疏程度都属于待比较的设计选择。先比较无图 MLP、集合式编码器和少层图模型，避免只报告最复杂网络。

图注意力权重仍是模型用于计算的权重，不是因果效应。删掉一个节点再预测，可以测试在该模型与背景下的依赖，但在组合丰度中删除后重归一化会同时改变其他相对值。应写清扰动是在观测坐标、对数比坐标还是预先定义的平衡上进行，并评估不同背景的稳定性。模型图、统计关联图和真实生态作用网络可以相关，但只有额外的研究设计才能连接到机制主张。

## 先决定观测分布，再决定生成模型名字

有原始计数时，可讨论条件于测序总量的多项式或带额外变异的计数模型；有相对丰度时，需要尊重非负和闭合约束；在 ILR 坐标中建模则是在非冗余对数比空间描述连续分布。三者的目标、单位和对零值的处理不同。把归一化比例当整数计数会虚构精度，把未测量特征当结构零会改变生成分布。选择似然之前先给每个值写下测量含义。

掩码模型学习给定可见部分如何预测隐藏部分，自回归模型按顺序分解联合概率，VAE 用潜变量与近似后验连接编码和生成，扩散通过有定义的噪声过程学习恢复方向。掩码重建误差低不自动给出一个一致的任意条件生成器，也不直接提供完整联合似然。群落是集合时，随意指定自回归排序会引入顺序假设；需要说明排序依据及其改变对结果的影响。

## 独立实验二：把 VAE 损失分成观测项与潜变量项

VAE 通过 q_phi(z|x) 近似潜变量后验，用 p_theta(x|z) 描述观测，并给 z 一个先验。标准 ELBO 包含期望对数似然减去后验与先验的 KL；训练常最小化它的相反数。重参数化将采样写成 mu+sigma×epsilon，让随机性由 epsilon 提供，梯度仍可传到 mu 和 sigma。下面用两个人工连续坐标与单位方差高斯观测核对目标和梯度，不把它当成计数模型。

代码在特征维求和、样本维平均，并将闭式 KL 与 PyTorch 分布实现对照。省略维度分母或随意把两项分别平均，会改变它们的相对权重。加入 beta 权重是另一种训练选择，应报告其定义；beta 不等于一时不再是这里原模型的标准 ELBO。单次随机估计通过断言，只证明公式实现可检查；尚未训练编码器、验证生成质量或识别潜在生态机制。

```text
ELBO(x)=E_q[log p_theta(x|z)]−KL(q_phi(z|x)||p(z))；KL(N(mu,diag(sigma²))||N(0,I))=0.5 Σ(mu²+sigma²−1−log sigma²)
```

```python
import math
import torch
from torch.distributions import Normal, kl_divergence
torch.manual_seed(38)
# 两个样本的人工连续坐标；不是原始计数或真实受试者。
x = torch.tensor([[0.6,-0.4],[-0.2,0.8]], dtype=torch.float64)
mu = torch.tensor([[0.2,-0.1],[0.4,0.3]],dtype=torch.float64,requires_grad=True)
logvar = torch.tensor([[0.1,-0.2],[0.0,0.2]],dtype=torch.float64,requires_grad=True)
std = (0.5*logvar).exp()
z = mu + std * torch.randn_like(mu)
W = torch.tensor([[0.7,0.2],[-0.1,0.6]],dtype=torch.float64)
recon = z @ W
# 单位方差的高斯观测模型；按特征求和，再按样本平均。
nll = 0.5*((x-recon)**2).sum(-1) + 0.5*x.shape[1]*math.log(2*math.pi)
kl = 0.5*(mu.square()+logvar.exp()-1-logvar).sum(-1)
reference = kl_divergence(Normal(mu,std), Normal(torch.zeros_like(mu),torch.ones_like(std))).sum(-1)
assert torch.allclose(kl,reference)
loss = (nll+kl).mean()  # 一次重参数采样给出的负ELBO蒙特卡洛估计。
loss.backward()
assert torch.isfinite(mu.grad).all() and torch.isfinite(logvar.grad).all()
print({"mean_nll": float(nll.detach().mean()),"mean_kl":float(kl.detach().mean()),
       "negative_elbo_estimate":float(loss.detach()),"finite_gradients":True})
# 运行一次损失与梯度核验不等于训练完成，更不等于验证了群落生成质量。

```

## 潜变量的名字不是识别证明，条件模型也不是反事实模型

把一个潜变量命名为“疾病轴”、另一个命名为“共享轴”，不会让优化器自动恢复该生物学分解。潜空间可能存在旋转、缩放或其他等价表示；后验塌缩时，解码器还可能几乎不使用潜变量。应检查潜变量使用、重构与先验采样差异、跨种子稳定性及与技术变量的关系。不同模型能得到近似预测却给出不同潜变量解释时，需要降低解释强度。

conditional VAE 中的条件变量是生成分布的输入，D29 的 contrastive VAE 则是利用背景对比的特定设计，二者缩写可能相同但含义不同。以疾病标签为条件生成一组丰度，描述的是模型学到的条件分布；把同一潜变量下条件改成健康，不足以解释成这个人的干预后反事实。因果反事实还需要结构假设、识别条件及适当资料，不能从生成器接口中的一个标签切换推出。

## 独立实验三：在合适坐标加噪，并诚实区分已知噪声与学会去噪

在连续扩散的一种常见参数化中，某时刻的噪声样本是原信号和标准高斯噪声的加权和。训练网络可以预测噪声或等价参数，再用相应的反向采样过程产生样本。对组合数据直接逐元素加高斯噪声会出现负数和不闭合；本例先在 ILR 坐标演示加噪，再经固定基与 softmax 回到正组成。这样保证的是数值约束，并未处理真实零值或保证生态合理。

例子保留了实际加入的噪声，因此能代数恢复原坐标。这是“已知噪声的恒等式”，不是训练出来的去噪器；真实采样时并不知道该噪声，必须从训练数据学习并检验误差。ILR 基、零值策略和尺度需在训练方案中固定，使用组成输出也不提供绝对微生物负荷。DDPM 原始研究是图像生成方法来源，迁移到微生物组属于需要单独评价的研究设计。

```text
z_t=sqrt(alpha_bar_t) z_0+sqrt(1−alpha_bar_t) epsilon；a=softmax(Vz)，其中 V 为固定 ILR 正交基
```

```python
import numpy as np
rng = np.random.default_rng(38)
# 三分类单元组成的二维ILR坐标；V的列正交且与全1向量正交。
V = np.array([[1/np.sqrt(2),1/np.sqrt(6)],
              [-1/np.sqrt(2),1/np.sqrt(6)], [0.,-2/np.sqrt(6)]])
assert np.allclose(V.T@V,np.eye(2)) and np.allclose(V.sum(axis=0),0)
z0 = np.array([0.5,-0.2]); noise = rng.normal(size=2); abar = 0.7
zt = np.sqrt(abar)*z0+np.sqrt(1-abar)*noise
oracle_recovery = (zt-np.sqrt(1-abar)*noise)/np.sqrt(abar)
assert np.allclose(oracle_recovery,z0)
def to_composition(z):
    logits = z@V.T
    exp = np.exp(logits-logits.max())
    return exp/exp.sum()
a = to_composition(z0); noisy = to_composition(zt)
assert np.all(a>0) and np.isclose(a.sum(),1)
assert np.all(noisy>0) and np.isclose(noisy.sum(),1)
print({"composition":a.tolist(),"noisy_composition":noisy.tolist(),
       "oracle_coordinate_error":float(np.max(np.abs(oracle_recovery-z0)))})
# noise在例子中已知；真实扩散模型必须学习预测噪声，不能把本恒等式叫作已学会去噪。

```

## 怎样评价合成群落：边际像，不等于联合关系对

只比较每个物种的均值和方差，无法证明模型保留了物种之间、物种与功能之间以及与临床标签之间的关系。安排训练外真实资料的边际与联合诊断，比较多样性、对数比协方差、稀疏模式和条件分布；还要检查生成样本是否只是记住了训练样本。对新研究有效的下游任务、校准与跨队列稳定性是另外一层证据，不应被一张二维嵌入重叠图替代。

用于数据增强时，生成器只能在允许的训练资料上拟合，分类器和生成器的选择都不能接触最终测试标签。与不增强、简单噪声、重采样及朴素分布生成基线比较，并保证标签预算一致。生成了更多行并不增加真实独立受试者数量，置信区间不能把合成行当新的观测。合成资料也不自动匿名；若原模型记忆训练样本，需要检查披露风险并遵守原资料的使用范围。

## 把复杂模型变成一组能被否定的设计选择

本项目的下一步不是同时加入图、VAE、扩散和多模态，而是写一个主假说。例如“固定演化关系可在标签稀缺时改善新队列预测”，相应对照应包含无图、随机图、真实先验图、同预算调参以及按训练内重建的估计图。若收益只有在某一图版本出现，要把稳定性和映射覆盖放进结论。每增加一个结构，都应该能指出它在哪个输入条件下预计有效、在哪个条件下可能失败。

本课三项实验验证计算关系、概率目标和坐标约束，没有训练真实生态生成模型。完成学习的标志是能发现图与特征错位、解释 ELBO 两项的单位、指出已知噪声恢复的局限，并给真实数据实验写出最低限度对照。D39 将继续检查新队列中的患病率、缺失机制、预测集合与因果识别，确保再复杂的模型也有明确的适用范围。

- 说明本课的连续高斯观测不适用于未说明的原始计数。

**阅读问题：** 重构误差小是否足以证明潜变量是疾病机制？

**参考思路：** 不能。潜变量识别、混杂和模型非唯一性需要额外假设与证据；优化目标并未自动赋予机制含义。

### Denoising Diffusion Probabilistic Models (2020)

https://arxiv.org/abs/2006.11239

理解加噪与学习反向过程的关系，避免把随机扰动直接叫作生成模型。

- 定位前向噪声过程与噪声预测目标。
- 区分已知加入噪声的代数恢复和模型在未知噪声时的预测。
- 列出迁移到组成、零值与相对丰度时需要重新验证的假设。

**阅读问题：** 能从已知 epsilon 恢复 z0，是否证明网络会生成真实群落？

**参考思路：** 没有。恒等式未学习去噪函数、反向采样或生物分布，真实生成质量仍未验证。

## 练习与完整参考解答

### 练习 1. 先用全部队列估计共现图，再做留一队列外测是否属于严格未见域评价？

提示：无标签信息也可能进入训练过程。

参考解答：不是严格的完全未见域设定，因为图使用了测试域分布。可在每个训练折内重估图，或明确声明传导/无标签适配，并保留另一个真正独立的外部测试。

### 练习 2. 重排物种丰度后，图模型输出改变是否一定说明不满足置换等变？

提示：检查图、节点身份与特征是否同步排列。

参考解答：不一定。必须同步重排图的行列、节点特征及身份索引；只重排丰度改变了变量的对应关系，输出理应可能变化。对称池化前的节点输出应等变，池化后的样本输出才应不变。

### 练习 3. VAE 中重构项按所有维平均，KL 按潜变量求和，潜维增加后结果变化如何解释？

提示：两个项的尺度取决于 reduction 与维度。

参考解答：可能改变了隐含正则化强度。先固定清楚每样本重构与 KL 的求和范围，再报告批次平均和 beta；不能把不同 reduction 下的损失数值直接比较为模型优劣。

### 练习 4. 用病例条件生成器把同一个潜变量的标签改为健康，是否得到个体治疗后状态？

提示：条件分布和干预分布有不同识别要求。

参考解答：不能。条件标签切换没有定义治疗、时间、混杂和结构因果关系，也未证明潜变量保持了该人的全部背景。只能解释为所拟合条件生成器的输出，反事实主张需要额外设计和验证。

## 验收自测

### 1. 哪种图最需要在每个训练折重新估计？

A. 已冻结的外部分类表
B. 训练资料拟合的丰度关联图
C. 预先指定的匿名示例图
D. 固定且无测试来源的参考树

参考答案：B。数据估计图属于学习步骤，不能默许看到测试域。

### 2. 标准 VAE 的训练目标主要包含什么？

A. 只有样本标签准确率
B. 只有节点度
C. 期望负对数似然和后验至先验的 KL
D. 只需随机生成噪声

参考答案：C。标准负 ELBO 包含观测项与潜变量分布项，具体分母必须清楚。

### 3. 本课 ILR 扩散实验可以证明哪项？

A. 训练了真实扩散模型
B. 所有零值已自然解决
C. 生成者具备因果干预能力
D. 指定坐标下加噪与已知噪声恢复的代数关系

参考答案：D。实验是数值机制检查，未训练未知噪声预测器。

### 4. 向原始相对丰度直接加高斯噪声有哪些问题？

A. 可能产生负数并破坏闭合，需要明确定义坐标与约束
B. 自动得到绝对丰度
C. 保证每个群落生态合理
D. 不影响数值范围

参考答案：A。数学约束与生物有效性都需要单独设计。

### 5. 生成一万行训练样本后，研究独立受试者数怎样变化？

A. 自动增加一万
B. 翻倍
C. 真实独立受试者数不因此增加
D. 由模型参数量决定

参考答案：C。合成样本依赖训练资料，不是新增独立观察。
