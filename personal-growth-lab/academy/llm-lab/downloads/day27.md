## 先定义你要对谁泛化

“未见样本”可以指同一人的新访视、同一研究的新受试者、新医院或新测量流程，难度和可支持的结论不同。应先明确目标人群、预测时点、标签和独立单位，再选择划分。研究外测通常更接近跨队列使用，但如果研究之间共享人或原始样本，仅按study拆分仍会泄漏。样本、受试者与研究数量应同时记录。

小样本时反复随机拆分看起来能产生很多分数，却没有增加新受试者或新研究。每次拆分的训练资料重叠，分数也相关。需要把数据抽样、训练随机性、选参过程和研究偏移分别考虑，而不是用所有分数的标准误制造很窄的区间。Varoquaux的原始研究正是提醒交叉验证误差条可能被低估；它不是说交叉验证没有价值，而是要求准确解释其不确定性。

## 嵌套验证把选择与最终评价隔开

外层留出一个研究用于评价，在其余研究内部选择超参数；内层每次拟合的缩放、筛选和模型都只能看到该内层训练部分。选定配置后，可以按照事先规定的流程在全部外层训练研究重新拟合，再预测外层留出研究。外层测试标签不能用于选C、早停、伪计数或决定报告哪个模型。无标签编码器也属于拟合流程，不能事先在所有外层研究上训练一个共享模型。

下面代码真正运行六个外层折、每个外层训练集合内的留一研究选择，使用人工数据和逻辑回归。每人只有一条记录，所以无需再聚合访视；实际重复测量应额外按受试者分组和评价。例子刻意把标准化放进Pipeline，让每次fit重新估计训练统计。它比只生成一个划分清单更完整，但没有训练菌群Transformer，也不能把它的分数当作真实疾病结果。

```python
import numpy as np
from sklearn.model_selection import LeaveOneGroupOut
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import roc_auc_score
rng = np.random.default_rng(27)
group = np.repeat(np.arange(6), 12)
y = np.tile([0, 1], 36)
X = rng.normal(size=(72, 5))
X[:, 0] += 0.8*y
X += rng.normal(0, 0.25, size=(6,5))[group]
Cs = [0.1, 1.0, 10.0]
def make_model(c):
    return make_pipeline(StandardScaler(), LogisticRegression(C=c, max_iter=500))
rows = []
for train, test in LeaveOneGroupOut().split(X, y, group):
    assert not set(group[train]) & set(group[test])
    scores = []
    for c in Cs:
        inner = []
        for a, b in LeaveOneGroupOut().split(X[train], y[train], group[train]):
            model = make_model(c).fit(X[train[a]], y[train[a]])
            inner.append(roc_auc_score(y[train[b]], model.predict_proba(X[train[b]])[:,1]))
        scores.append(float(np.mean(inner)))
    best_c = Cs[int(np.argmax(scores))]
    final = make_model(best_c).fit(X[train], y[train])
    auc = roc_auc_score(y[test], final.predict_proba(X[test])[:,1])
    rows.append({"study": int(group[test][0]), "C": best_c, "test_auc": float(auc)})
assert len(rows) == 6
print(rows)
print("macro study AUROC", np.mean([r["test_auc"] for r in rows]))
```

微调比从零监督平均高0.0125，只能描述这次设定的观察，不能据此宣布显著改进；两个种子不是两份独立临床资料，六个研究也全部来自人工生成。预训练模型依然低于逻辑回归，说明当前目标、预算和架构没有展示超越简单基线的价值。合理下一步是在训练域检查表示、目标和预算，而不是根据这份外层测试表继续调参直到结果翻转。

## 多种子与标签效率各有独立问题

多种子检查初始化、抽样和优化的变化，但同一队列反复训练不会增加独立受试者数。先在每个研究内部汇总种子，再展示跨研究结果，比把所有fold×seed当独立观测更合适。还应区分“各种子指标平均”与“概率先集成再算指标”：两者数学上不同，前者描述训练稳定性，后者评价一个新的集成预测器。

标签效率实验固定外层协议，在训练受试者层面按类别抽取20%、50%或全部标签。各方法使用相同标签子集，最好用嵌套子集减少无关波动，并记录实际人数。工程的--label-fraction 0.5让未选受试者仍提供训练输入进行自监督，是半监督条件，而不是只看到一半数据。验证标签预算也应报告；如果内层选择依赖大量标签，不能只突出最终拟合使用的少量标签。

## 研究宏平均、汇总AUC与患病比例

宏平均给每个研究相同权重，更接近“一个新研究”的平均表现；按人数加权更偏向大研究。将所有研究预测直接合在一起计算AUROC又是另一件事，因为它还包含跨研究正负配对，研究之间的概率尺度和基线风险可能影响结果。先规定主汇总，再补充其他视角，不应根据哪个更高来选择标题分数。某研究只有一个类别时，AUROC没有定义，要说明缺失与覆盖范围。

AP及精确率与阳性比例相关，病例对照人为平衡的测试不能直接代表真实筛查场景。课程报告AP，须区别于梯形积分的PR曲线面积。阈值相关的敏感度、特异度、F1与混淆矩阵则反映具体决策规则。任何汇总都应该能回到受试者预测和逐研究分母；存在不同诊断定义时，即使指标计算正确，也需要重新判断这些研究是否测量同一个任务。

```text
macro AUC = (1/S) Σ_s [(1/K_s) Σ_k AUC_(study s, seed k)]；它不等于对合并预测重新计算AUC
```

## 配对与层级bootstrap需要说明条件

比较两模型时，对同一组受试者同时重采样两份预测，保留配对关系。多个研究可以先抽研究，再在抽中的研究内抽受试者；若固定各类人数，则获得的是给定类别构成的分层重采样。下面用四个完全人工研究演示这个过程，输出的是固定预测下的宏平均AUROC差值区间。代码不是在重新训练模型，也不表示已经获得所有不确定性的精确覆盖。

研究数量很少时，研究层重采样本身很粗糙；外层折的训练集还互相重叠，不能自动视为独立实验。训练随机性、预处理选择和超参数搜索的不确定性不包含在一次固定预测的bootstrap里。真实报告应写明抽样单位、分层规则、有效重复次数、是否重训以及所条件化的模型。工程内的配对区间针对单个留出研究；下面的层级示例是额外统计教学，不能混称为自动完成的整体显著性检验。

```python
import numpy as np
from sklearn.metrics import roc_auc_score
rng = np.random.default_rng(2707)
cohorts = []
for study in range(4):
    y = np.tile([0,1], 6)
    shared = 0.9*y + rng.normal(size=len(y))
    pa = 1/(1+np.exp(-shared))
    pb = 1/(1+np.exp(-(shared + 0.15*y + rng.normal(0,0.15,len(y)))))
    cohorts.append((y,pa,pb))
point = np.mean([roc_auc_score(y,b)-roc_auc_score(y,a) for y,a,b in cohorts])
boot = []
for _ in range(500):
    differences = []
    for s in rng.choice(len(cohorts), len(cohorts), replace=True):
        y,a,b = cohorts[s]
        index = np.concatenate([rng.choice(np.flatnonzero(y==c), (y==c).sum(), replace=True) for c in (0,1)])
        differences.append(roc_auc_score(y[index],b[index])-roc_auc_score(y[index],a[index]))
    boot.append(np.mean(differences))
assert len(boot) == 500 and np.isfinite(boot).all()
print({"macro_auc_difference_B_minus_A": float(point),
       "illustrative_interval": np.quantile(boot,[0.025,0.975]).tolist(),
       "scope": "fixed synthetic predictions; studies then class-stratified subjects; no retraining"})
```

## 校准与阈值应该在测试前冻结

AUROC保持不变时，概率仍可能过高或过低。校准关注预测概率与观察频率的匹配，可报告Brier、校准曲线与适当的校准参数。温度缩放等方法需要独立校准资料或训练域内交叉拟合；在测试标签上校准再评价同一批测试，会让结果过于乐观。只有很少受试者时，等宽分箱的曲线可能由几个人决定，应同时显示每箱人数。

阈值选择需要任务目标，例如在验证资料上达到预先指定的敏感度，再冻结后检查外部表现。若验证样本不足，目标本身就有很大不确定性。不同研究患病比例与招募机制变化时，概率校准也可能改变，不能把一个全局阈值的好表现当成普遍保证。课程合成任务中的阈值和校准用于学习统计流程，没有构成真实临床决策工具。

## 跨表型和跨队列混杂要分别检查

模型可能区分疾病，也可能区分用药、采样流程或某研究中特定对照人群。应报告协变量单独、菌群单独和联合模型，检查研究与标签的交叉分布。跨疾病评价还要避免把“患者对健康”表现好误写成疾病特异性；若模型把其他疾病患者也判为阳性，可能主要捕捉共享状态、治疗或非特异改变。它仍可能具有研究价值，但结论需要换成实际检验的问题。

可以设置留一疾病、疾病之间区分或共同对照的预设实验，但同一批健康对照在多个任务重复使用会造成结果相关，需要在划分和统计中保留身份。发现模型能预测研究身份是一种诊断信号，却不能单独证明主任务完全无效；关键是研究信息与结局是否混杂，以及独立队列能否保持任务表现。不要凭一次投影图或一个混杂指标就完成全部判断。

## 最终外部测试是资源，不是无限调参接口

外部数据的选择标准应在查看结果前固定，包括人群、表型、单位、排除条件和失败处理。如果不断在同一外部研究上挑词表、调整阈值与更换模型，这个研究已经参与开发，后续确认需要新的未使用资料或诚实标记为探索性分析。无标签目标域适配可以作为独立研究问题，但应明确使用了哪些目标资料，不与完全冻结外测混在一起。

真正的新增队列还可能具有缺失模态、未见分类单元、不同病程与时间范围，应该保留输入契约失败、指标未定义和无法评估的情况。不能只报告兼容且分数高的研究。外部验证的价值在于揭示模型能否适应实际变化，即使结果较差也能指导下一阶段收集何种数据，而不是为最终展示提供一个较高数字。

## 把结果写成有估计对象的结论

一个完整结论包括任务、数据来源、外层单位、方法选择、主指标、差值和不确定性范围。例如可以写“在六个人工研究的固定轮转验证条件下，预训练微调较从零监督的研究宏平均AUROC高0.0125，但仍低于逻辑回归，当前结果属于教学性描述”。这句话没有把两个种子当新数据，也没有把差值自动升级为统计显著性。

结论后接一项具体决定：若要研究标签效率，就预先固定子集和验证预算；若要研究目标质量，就保留当前外测结果并在训练域设计新的掩码比较；若目标是现实使用，就先完成真实数据契约与独立队列。你应能清楚回答区间包含了什么变化、遗漏了什么变化，以及哪一份未来数据能够检验当前假设。

## 论文导读

### Microbiome meta-analysis and cross-disease comparison enabled by the SIAMCAT machine learning toolbox (2021)

https://doi.org/10.1186/s13059-021-02306-1

学习跨研究泛化与疾病特异性为何需要专门评价，而不是只做随机样本交叉验证。

- 查看作者如何区分同研究与跨研究任务。
- 对照来源、混杂和训练资料构成对结果的影响。
- 通过官方https://siamcat.embl.de/的pitfalls与holdout文档核查预处理顺序。

**阅读问题：** 一个疾病对健康的模型分数高，为什么还要跨疾病比较？

**参考思路：** 它可能识别共享疾病状态、治疗或对照招募差异，而非特定疾病信息。不同任务需要相应对照和独立评价，不能仅靠病例对照AUC声称特异性。

**阅读问题：** 预处理为什么要跟随每个训练折重新拟合？

**参考思路：** 特征筛选、尺度与其他统计会使用数据分布；在全体资料上拟合后再划分，会将测试信息带入流程。

### Cross-validation failure: Small sample sizes lead to large error bars (2018)

https://doi.org/10.1016/j.neuroimage.2017.06.061

理解小样本预测评价的误差范围，以及折间标准误为何不能直接代表真实不确定性。

- 原始作者预印本https://arxiv.org/abs/1706.07581可用于阅读方法与例子。
- 区分一次数据集、多次拆分和新增独立受试者。
- 将论文问题对应到多研究、多访视、多种子的课程设计，不照搬其示例数值。

**阅读问题：** 把同一数据随机拆分一百次，是否获得一百份独立证据？

**参考思路：** 没有。训练和测试资料大量重叠，结果相关，受试者与研究数量未增加；重复拆分主要观察部分划分变化。

**阅读问题：** 论文是否主张停止使用交叉验证？

**参考思路：** 不是。它强调评估误差条与样本规模的限制，要求合理设计和解释，而非用很多相关折制造过窄区间。

### On Calibration of Modern Neural Networks (2017)

https://proceedings.mlr.press/v70/guo17a.html

建立排序表现与概率校准的区别，学习后处理方法需要独立选择资料。

- 理解预测置信度与观察正确率的比较。
- 看温度缩放的参数与拟合目标，再写出你将使用的校准集。
- 讨论从原论文图像和文本任务迁移到小型跨队列病例对照任务时的限制。

**阅读问题：** 温度缩放后AUROC没变，校准是否可能变化？

**参考思路：** 可能。单调概率变换可以保持排序而改变概率大小，AUROC不评价这种概率准确性。

**阅读问题：** 能否在测试集上调温度并报告同一测试集的改善？

**参考思路：** 不能作为独立测试结论。温度已使用测试标签选择，应采用训练域内独立校准或交叉拟合，再在未使用测试评价。

## 练习与完整参考解答

### 练习 1. 六研究、两个种子产生十二个AUC，为什么不应按n=12独立样本做普通检验？

提示：考虑种子、研究与外层训练重叠。

参考解答：同研究的种子共享所有受试者与测量；不同外层折训练集也重叠。十二个数不是十二份独立队列。应逐研究汇总并展示种子变化，选择与研究和配对结构匹配的统计方案，说明训练与选择不确定性是否被考虑。

### 练习 2. 宏平均AUC提高0.0125，能否写“显著提高且适合临床”？

提示：差值、显著性与使用场景是三个层次。

参考解答：不能。差值只是该数据和配置下的估计，还需匹配的统计与独立证据；当前资料完全合成，也无法支持真实临床用途。应报告五方法对照、研究间差异和预算，并写明没有证明显著或生物效能。

### 练习 3. 只保留半数训练标签但继续使用全部训练丰度预训练，应怎样命名？

提示：区分标签数量与输入数量。

参考解答：这是训练域内的半监督标签效率设定。各方法应获得相同输入与标签预算，报告实际有标签受试者及验证标签数量，不能写成只使用半数数据。

### 练习 4. 研究A样本远多于B，合并预测AUC高而逐研究宏平均低，应先检查什么？

提示：合并AUC包含跨研究配对。

参考解答：先核对各研究类别比例、概率尺度、逐研究指标与预设汇总目标。合并分数既受大研究影响，也包含跨研究正负配对，可能利用研究差异。应保留预设宏平均与逐研究结果，不因某个汇总较高就更换主指标。

## 验收自测

### 1. 完整嵌套验证中外层测试标签能用于什么？

A. 调整早停直到获胜
B. 冻结选择后的最终评价
C. 选择最好的C
D. 选择伪计数

参考答案：B。内层负责选择，外层负责评价；无标签预处理也必须遵守各折拟合范围。

### 2. 同一研究的两个随机种子代表什么？

A. 部分训练随机性，不是新增研究或受试者
B. 两次独立临床试验
C. 两个人群样本量翻倍
D. 可忽略研究偏移的证据

参考答案：A。数据身份未改变，重复训练不能增加独立生物学样本量。

### 3. 配对bootstrap比较两模型时应怎样抽样？

A. 分别打乱两个模型的受试者顺序
B. 只抽表现较好的模型
C. 把重复访视当独立人抽样
D. 对同一受试者同时取出两模型预测

参考答案：D。保留受试者配对才能反映同一资料上模型差值的抽样变化。

### 4. 当前benchmark的--max-folds 2结果可称为什么？

A. 所有研究均通过外测
B. 已经完成完整嵌套调参
C. 两折流程检查或局部外测结果
D. 完整六研究LOSO

参考答案：C。执行了多少折就报告多少折，smoke运行不能替代完整评价覆盖。

### 5. 标签效率实验还必须报告哪项信息？

A. 把测试标签加入预算但不说明
B. 未标注输入与验证标签的使用范围
C. 只报告训练标签百分比即可
D. 只写最好的种子

参考答案：B。半监督输入和选择阶段标签也是资源，完整预算才能解释样本效率。
