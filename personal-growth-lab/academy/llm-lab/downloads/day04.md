## 为什么仅有 embedding 还不够

上一课的最小预测器只根据当前位置 token 和位置给下一 token 打分，不能读取更早内容。设文本出现“研究 A”“研究 B”，之后都接“发现”，当前位置相同，应该引用哪项结果却依赖前文。注意力提供一种按当前需求汇集其他位置信息的方法，而不是把所有前缀简单平均。

每个位置先从当前表示产生三个向量：查询 Q 表示这次要匹配的特征，键 K 表示可被匹配的特征，值 V 表示匹配后实际传递的内容。这些是便于理解的角色描述，真实含义由训练决定，不能把每个头预先命名为“语法头”或“疾病头”。Q、K、V 都是可学习线性变换的输出。

一个位置将自身 Q 与允许范围内各位置 K 比较，得到分数；softmax 把分数变成权重；用这些权重对 V 求加权和。查询者决定读什么，键参与决定读谁，值提供被读取内容。三者可以来自同一序列，也可以来自不同序列；本课实现自注意力，全部由同一输入产生。

## 先写形状，再写公式

设单头输入 X 为 [B,T,D]，查询与键维度为 d，值维度为 dv。三个权重分别把 D 映射到 d、d 和 dv，得到 Q=[B,T,d]、K=[B,T,d]、V=[B,T,dv]。Q 乘 K 在最后两轴的转置，得到 [B,T,T] 的分数矩阵。

分数矩阵的行表示“哪个位置正在查询”，列表示“哪个位置作为候选被读取”。因此 softmax 沿最后一轴，也就是候选键的位置轴进行。每一行在有效候选上形成分布，再乘 V，得到 [B,T,dv]。如果沿查询轴归一化，代码仍能运行，却回答了不同的问题。

这里的 QK 转置只交换最后两个维度，不能把 batch 一起转走。使用 transpose(-2,-1) 可以明确表达这个意图。后面增加多头时会多出一个头轴，主要矩阵关系仍然不变。每遇到一个新维度，都先给它起科学或计算含义明确的名字。

```text
Q=XWQ，K=XWK，V=XWV；A=softmax(QKᵀ/√d+M)；O=AV
```

| 对象 | 形状 | 最后两轴含义 |
| --- | --- | --- |
| Q、K | [B,T,d] | 位置×查询/键特征 |
| V | [B,T,dv] | 位置×值特征 |
| 分数与权重 | [B,T,T] | 查询位置×候选位置 |
| 输出 | [B,T,dv] | 位置×汇聚特征 |

## 两位置例子：把一次注意力算完

取查询 q=[1,0]，两个键 k1=[1,0]、k2=[0,1]，两个值 v1=[2,0]、v2=[0,4]。原始点积为 [1,0]，键维度 d=2，缩放后分数为 [1/√2,0]。softmax 给出约 [0.670,0.330]，输出为 0.670×[2,0]+0.330×[0,4]，约 [1.34,1.32]。

这个输出通常不是某个原始值向量的直接拷贝，而是按上下文需要得到的混合。改变 K 会改变权重，改变 V 会改变被传递的内容；如果只看最终输出，无法唯一判断变化发生在哪条路径。这也提醒我们，注意力图只能观察计算的一部分。

现在把第二个键改为 [2,0]，预测第二个权重会增大，再运行核对。然后保持 Q、K 不变，只把 v2 改为 [0,8]，权重应该不变，输出第二维增加。两步实验分别隔离“选信息”和“传信息”，比一次同时修改所有矩阵更能建立理解。

```python
import math
import torch
q = torch.tensor([[1., 0.]])
k = torch.tensor([[1., 0.], [0., 1.]])
v = torch.tensor([[2., 0.], [0., 4.]])
a = torch.softmax(q @ k.T / math.sqrt(2), dim=-1)
out = a @ v
assert torch.allclose(a.sum(-1), torch.ones(1))
print(a, out)
```

## 为什么除以维度平方根

点积把 d 个乘积项相加。若为了直观分析，假设各维查询与键近似独立、均值为零且方差为一，那么点积方差会随 d 增长，尺度约随 √d 增长。维度较大时，分数容易过大，softmax 变得非常尖锐，一些梯度可能变得不利于学习。除以 √d 是控制初始分数尺度的办法。

这些独立和方差假设是解释缩放动机的近似，不是训练后网络必须满足的事实。实际数值还受初始化、归一化和数据分布影响，因此仍应检查分数范围与注意力熵。缩放不是保证训练稳定的唯一条件，也不能修复错误目标或数据泄漏。

做一个小实验：分别生成 d=8、32、128 的随机查询键，比较未缩放点积的标准差与缩放后的标准差。使用足够多重复样本观察趋势，不要求每一次抽样完全相同。实验目标是理解量级，而不是把随机结果拟合成新的科学规律。

额外核对时，分清键维度与整个模型维度。多头结构中每个头只拥有一部分查询和键特征，缩放通常使用该头的键维度。若误用总维度，分数会被额外压小，注意力分布可能更平；程序不一定报错，但已经改变了模型。把缩放分母也列入你的形状检查表。

## 稳定 softmax 与负无穷遮罩

softmax 的分子是指数，直接对很大的分数取 exp 可能溢出。对一行分数统一减去该行最大值不会改变归一化结果，因为分子分母都乘了同一个常数。实际训练通常使用框架提供的稳定实现，但你应知道它为什么可以平移分数。

遮罩可以把禁止位置的分数设置为负无穷，再进行 softmax，这些位置的概率就为零。把禁止位置简单乘零是不对的：如果其他有效分数为负，零反而可能得到更大权重。也不要把已经归一化的概率直接删掉后不重新归一化，除非你明确定义的是另一种操作。

一行必须至少有一个有效候选，否则全为负无穷时可能出现非有限结果。因果自注意力通常保留当前位置自身，所以第一行仍有对角线位置可用。若后来组合 padding 遮罩，需再次检查是否制造了空有效行。注意力 dropout 之后行和不一定为一，归一化断言应作用在 dropout 之前。

```python
import torch
scores = torch.tensor([[1000., 1001., 999.]])
shifted = scores - scores.max(dim=-1, keepdim=True).values
manual = shifted.exp() / shifted.exp().sum(dim=-1, keepdim=True)
assert torch.allclose(manual, torch.softmax(scores, dim=-1))
forbidden = torch.tensor([[False, True, False]])
a = torch.softmax(scores.masked_fill(forbidden, float('-inf')), dim=-1)
assert a[0, 1].item() == 0.0
assert torch.isfinite(a).all()
```

## 因果遮罩：允许看到自身，禁止偷看未来

下一 token 目标在位置 t 使用输入 0 到 t 预测原序列 t+1，因此允许看当前位置输入，禁止看输入 t+1 以及之后。遮罩应去掉严格上三角，保留下三角与对角线。若误把对角线也去掉，第一行没有有效候选；若方向写反，则模型能看未来却看不到前文。

不要混淆训练时并行与信息泄漏。虽然所有位置一起计算，但每一行独立遵守自己的可见前缀，因果目标仍成立。生成时当前序列末端没有真实未来 token，所以模型依次追加预测。训练可以并行计算位置损失，生成的新增 token 通常有顺序依赖。

不同框架 API 对布尔 mask 的含义可能相反：有的 True 表示禁止，有的表示允许。课程手写实现明确规定 forbidden=True 表示禁止，再使用 masked_fill。换成高效内核前应阅读对应 API 并跑同样因果测试，而不是照搬布尔张量。

## 实现单头注意力

下面的函数直接接收 Q、K、V，便于独立验证，使用固定的因果遮罩。广播让 [T,T] 的禁止矩阵作用到每个 batch。结果先计算注意力权重，再混合值向量，整个过程不读取训练目标。函数中把长度、键维度和输出形状写清，未来增加多头时才不会盲目 reshape。

运行随机示例后检查三个性质：输出形状符合预期；每一行概率和为一；严格上三角概率全为零。第一行只有自身可用，注意力应为 [1,0,…]。这些检查证明矩阵操作的局部规则正确，但还不能保证完整模型不存在其他未来信息通路。

因此下一节还要直接扰动未来输入，检查更早输出是否改变。测试应与风险对应：形状测试捕捉接口错误，概率测试捕捉归一化错误，扰动测试捕捉信息流错误。只写“模型可以前向”远远不够。

```python
import math
import torch
def attention(q, k, v):
    T, d = q.shape[-2:]
    scores = q @ k.transpose(-2, -1) / math.sqrt(d)
    forbidden = torch.triu(torch.ones(T, T, dtype=torch.bool, device=q.device), diagonal=1)
    a = torch.softmax(scores.masked_fill(forbidden, float('-inf')), dim=-1)
    return a @ v, a
torch.manual_seed(7)
q = torch.randn(2, 4, 6); k = torch.randn(2, 4, 6); v = torch.randn(2, 4, 5)
out, a = attention(q, k, v)
assert out.shape == (2, 4, 5)
assert torch.allclose(a.sum(-1), torch.ones(2, 4))
assert torch.count_nonzero(torch.triu(a, diagonal=1)) == 0
```

## 用未来扰动，检验真正的因果性

创建一份输入 X，再复制为 X2，只修改后两个位置。用相同权重计算两个输出，比较前两个位置。只要信息流严格因果，前缀输出应该保持不变；后面输出可以改变，因为它们有权看到被修改的位置。这个测试比肉眼看遮罩图更直接。

完整模型也应该做类似测试，处于 eval 模式、关闭 dropout，固定输入与参数。不要因为训练模式中的随机 dropout 导致输出不同，就误判为泄漏。先排除随机干扰，再做有控制的扰动；必要时使用容差比较，考虑浮点计算的误差。

若测试失败，检查是否有跨全部时间位置的归一化、在前向中使用完整序列汇总、目标被拼到输入或 mask 广播错误。逐层记录第一个出现前缀差异的位置，可以定位非法信息通路。科学建模里检验“模型是否用了不该知道的信息”，也是同样的思路。

```python
torch.manual_seed(11)
x = torch.randn(1, 4, 6)
x2 = x.clone(); x2[:, 2:] += 100
Wq, Wk, Wv = [torch.randn(6, 6) for _ in range(3)]
def forward(z):
    return attention(z @ Wq, z @ Wk, z @ Wv)[0]
y1, y2 = forward(x), forward(x2)
assert torch.allclose(y1[:, :2], y2[:, :2], atol=1e-6)
print('future perturbation passed')
```

## 注意力图显示了什么，没有显示什么

某个位置给某个词较高权重，表示这条计算路径在当前参数和输入下更多混合了它的值向量。它不直接等于该词对最终回答的总贡献，更不等于生物因果作用。残差路径、其他头、其他层和后续非线性都可能改变最终输出。

微生物模型中也一样：两个物种 token 之间注意力大，不足以证明共生、代谢互作或水平基因转移。丰度共变、组成约束、测序批次和共同环境都可能影响表示。若要研究模型利用什么信息，可以结合扰动、消融、稳定性分析和独立生物知识，但每种方法也有自己的假设。

本课可把注意力矩阵画成热图帮助检查遮罩，标题应写“模型注意力权重示例”，不能写“发现微生物相互作用网络”。把计算机制与科学解释分清，反而让最终项目更有研究价值，因为用户知道哪些图能用于调试、哪些结论还需要验证。

## 序列长度为什么很贵，优化内核解决什么

单头注意力矩阵有 B×T×T 个元素，多头后还乘头数 H。T 从 32 变成 64，矩阵元素变为四倍；从 64 变为 256，则变为十六倍。值投影和前馈层也有开销，但序列增加带来的平方项尤其需要预算。微生物 token 数上千时，同样应先估计规模。

FlashAttention 等方法通过分块与减少内存读写，避免以朴素方式物化完整注意力中间结果，并保持标准注意力计算的数学目标；它不是把所有两两关系神奇地变成线性复杂度。实际速度还取决于设备、形状、精度和内核支持，不能照搬某论文的加速倍率。

本课先保留可读手写实现，之后若替换高效算子，要求相同输入输出在容差内一致，并再次通过因果扰动测试。优化应保持已确认的语义。先把事情做对，再通过证据判断哪里最值得加速。

## 练习与完整参考解答

### 练习 1. 若有效分数全为负，禁止位置只乘零会怎样？

提示：比较零与负数在 softmax 中的权重。

参考解答：禁止位置可能得到较高概率。应在 softmax 前用明确掩码赋负无穷，并保留有效候选。

### 练习 2. B=2、H=4、T=64 的注意力矩阵有多少元素？T 加倍后呢？

提示：计算 BHT²。

参考解答：32768 个；T=128 时为131072，四倍。

### 练习 3. 修改未来输入后前缀输出不同，第一步一定是修改 mask 吗？

提示：考虑 dropout 与模型模式。

参考解答：先排除随机性并检查 eval；再逐层定位，可能是 mask、跨时间汇总或其他信息通路。

### 练习 4. 两个菌 token 注意力大，可以称为互作吗？

提示：区分计算路径与生物机制。

参考解答：不能。需要独立统计、扰动和生物验证，注意力权重本身只描述模型的信息混合。

### 1. 注意力 softmax 沿哪个轴？

B. query位置

参考答案：C。每个查询应在候选键上形成分布。

### 2. 因果下一 token 注意力通常允许看当前位置吗？

### 3. 除以 √d 的主要目的是什么？

A. 增加词表
B. 控制点积分数尺度
C. 实现数据划分
D. 消除所有随机性

参考答案：B。避免维度增长使初始分数过大。

### 4. 在 QK 固定时仅改变 V 会怎样？

A. 权重必变
B. 词表变大
C. 权重不变，输出可能变

参考答案：C。权重由QK及mask决定，V决定传递内容。

B. 数据标签
