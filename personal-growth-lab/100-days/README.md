# 日有寸进 · 100 Days of Becoming

> 给普通日子一套可反复使用的成长系统。用真实行动和可回看的证据推进，而非为了连续打卡。

**课程首页：** <https://zbyloveyj.github.io/personal-growth-lab/100-days/>  
**源码目录：** <https://github.com/zbyloveyj/zbyloveyj.github.io/tree/main/personal-growth-lab/100-days>  
**前一套课程：** [21天口才与表达训练](https://zbyloveyj.github.io/personal-growth-lab/)

## 这是一套什么样的工具

100天分为五个阶段，覆盖睡眠与作息、营养饮食、身体活动、阅读学习、专注思考、情绪觉察、沟通关系和系统复盘八个领域。每天不机械重复同一套打卡项目：**100个不同的主题和预期成果，3项当天专属核心步骤，2项阶段性轮换练习，以及当天的反思问题。**

### 五个阶段

| 天数 | 阶段 | 训练重点与交付 |
| --- | --- | --- |
| 01—20 | 觉察重启 | 建立真实生活基线，了解行动障碍 |
| 21—40 | 建立节律 | 将睡眠、饮食、活动和恢复安排进现实日程 |
| 41—60 | 认知进阶 | 从阅读到复述、证据判断、写作和小作品 |
| 61—80 | 拓展边界 | 主动联系、倾听、沟通边界和作品交付 |
| 81—100 | 长期主义 | 个人操作手册、低谷日预案和下一轮计划 |

每天都有**准备材料、参考记录格式（明确标为示意）、常见误区**，帮助使用者把三步练习真正落实为行动。日常辅助练习从包含160个分阶段项目的练习库中选取，跨阶段逐渐变化。课程相互关联，但不会被强制解锁。

## 实际怎样操作

1. 打开网站顶部的个人成长工作台，看到已完成天数、建议继续的课程和日历计划日。第一次使用可展开“30秒上手指南”。
2. 点击“继续学习”沿上次记录推进，也可以使用“日历今天”“上一天/下一天”或输入 Day 编号直达。
3. 按时间选择轻量、标准或深入模式，阅读当天要求与预期成果后再勾选实际完成的步骤。
4. 通过“这一课怎样做得更扎实？”打开逐日准备说明和可复制的记录模板。模板中的方括号需要填写真实情况，不是个人进度。
5. 在反思框记录真实行动、问题和成果，系统自动保存到当前浏览器。另可标记当天精力（可选）。
6. 每周使用复盘区域回看一周的学习；下次进入网站可以从个人工作台直接继续。

**不同训练模式的完成条件：** 轻量完成核心第1步；标准完成核心3步；深入完成核心3步、至少1项辅助练习，并写下不少于8字的反思。系统根据实际条件确认完成，不会单凭打开课程页面就加上完成标记。

## 适合日常使用的界面与功能

- 蓝白色编辑式工作台，第一屏即可看到下一堂建议课，免去找进度、反复滚动。
- 100天完整地图、5个阶段入口；课程目录支持**关键词、阶段、领域和完成状态**组合筛选，默认先显示12项，可逐批展开。
- 单日课程支持编号跳转、上/下一天和相关前置课程快捷入口；课程之间可按用户意愿跳转。
- 任务勾选不销毁正在输入的笔记节点；完成条件与本地保存状态随操作更新。
- 每周进度统计、八领域训练覆盖记录、最近课程快捷入口，以及完整周复盘笔记。
- 桌面、平板、手机布局与移动端底部导航；深色模式、键盘交互及打印样式。
- JSON完整备份与导入、Markdown成长档案导出、浏览器打印/另存PDF。
- 数据管理折叠面板，清除当日需确认，全部重置须输入确认词并二次确认。

## 重要的隐私和数据说明

- 使用原有浏览器存储键 `yixw_growth_100_v1`，**不迁移、覆盖或清空旧版记录**。旧任务的完成状态和笔记仍保留，旧版勾选不会被错误标为新版3步全部达标。
- 勾选、笔记、周复盘、起始日期与模式仅保存在**当前设备当前浏览器的 localStorage**；不需要账号，不上传到GitHub，不存在自动跨设备同步。
- 清除浏览器数据、更换浏览器或使用隐私模式可能丢失记录。建议每周导出 JSON 文件备份，并在新设备自行导入。
- 导入会在确认后覆盖当前浏览器的100天记录；重置操作不可撤销，务必先导出备份。
- 不建议填写姓名证件号、病历或其他不必要的敏感信息。

## 科学依据与适用边界

网站引用了以下公开、可核对的资料：
- [CDC · 成人睡眠](https://www.cdc.gov/sleep/about/)；

- [WHO · 健康饮食](https://www.who.int/news-room/fact-sheets/detail/healthy-diet)；
- [NCCIH · 冥想与正念的效果、安全性](https://www.nccih.nih.gov/health/meditation-and-mindfulness-effectiveness-and-safety)；
- Carpenter, Pan & Butler, 2022, [*The science of effective learning with spacing and retrieval practice*](https://doi.org/10.1038/s44159-022-00089-1), *Nature Reviews Psychology*.

**课程模式、天数、步骤与时间安排属于自主学习的组织方案，并不是临床处方或经验证的百日干预疗效。** 不建议因计划而挤压睡眠、过度运动或限制必要饮食。若有伤痛、慢性疾病、饮食障碍、持续失眠或明显心理困扰，应寻求相应专业人员建议。

无需安装构建工具。作为静态文件夹直接使用已有 GitHub Pages 站点。若更改课程编号及其含义，请先考虑旧浏览器进度的对应关系；不应静默改变 Day 编号导致旧笔记错配。

回归测试（仓库根目录）：

```bash
python3 tests/validate_growth100.py
```

在提供 Chromium/Chrome 的环境下，还将运行真实浏览器交互和390px手机视口溢出检查。GitHub Actions 工作流 `.github/workflows/validate-growth100.yml` 负责自动执行。项目保留在主站仓库的独立 `personal-growth-lab/100-days/` 目录中；**不是单独创建的新仓库**。
