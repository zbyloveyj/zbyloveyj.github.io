# 日有寸进 · 100 Days of Becoming

一个开源、轻量、无需登录的 **100天自我成长练习站**，是「一心问道 · 个人成长实验室」第二套课程。

**在线网站：** https://zbyloveyj.github.io/personal-growth-lab/100-days/

**前一套课程：** [21天口才与表达训练](https://zbyloveyj.github.io/personal-growth-lab/)

## 为什么是100天

这里没有“100天后脱胎换骨”的承诺。目标是用足够长的一段时间观察和实践作息、饮食、运动、阅读、思考、专注、冥想、表达与关系维护，然后找出真正适合自己、能持续一年的规则。

## 五个阶段 / 100份不同的每日内容

| 阶段 | 天数 | 重点 |
| --- | --- | --- |
| 觉察重启 | Day 01–20 | 记录现状、整理环境、建立微习惯 |
| 建立节律 | Day 21–40 | 睡眠、饮食、运动和休息 |
| 认知进阶 | Day 41–60 | 阅读、主动回忆、批判思考、深度工作与写作 |
| 拓展边界 | Day 61–80 | 表达、倾听、关系、边界、勇气与创造 |
| 长期主义 | Day 81–100 | 复盘、减法、长期行动系统与下一阶段计划 |

所有100天的主题、三个操作步骤、一个反思问题 **已经完整编写**，不是简单生成的重复打卡模板。

## 每天怎样用

1. 进入首页，在「我的起点日期」中选择开始训练的日期（默认首次访问日期）。
2. 在「轻量 / 标准 / 深入」中选择适合当天工作强度的版本。
3. 按照当天的七个锚点开始：睡眠、饮食、运动、阅读、专注、正念、主题练习。
4. 当天主题附有三个具体步骤和一个反思问题；用文字记录真实观察。
5. 自主确认完成；错过几天并不清空进度，可回看或补做。
6. 每周复盘，最后导出个人成长报告。

健康行为的建议为一般性参考，不代替医疗建议；不设置硬性早起时刻、热量限制或每日运动强度指标。任何不适或特殊健康情况需按自身情况调整。

## 网站功能

- 100天完整课程与五阶段说明
- 每日7项可勾选任务；自选3种训练强度
- 每日反思记录、精力状态、每周复盘笔记
- 100格可交互日历、各阶段进度、15周练习图表与习惯完成统计
- 明暗配色、响应式手机/平板/电脑排版
- JSON 备份/恢复、Markdown个人总结导出、浏览器打印/保存PDF
- 零外部字体、零跟踪脚本、零后端服务，不读取麦克风或通讯录

## 隐私与数据边界

数据只保存在 **当前浏览器的 localStorage** 中，不会自动上传到 GitHub，也不会同步到其他设备。清除浏览器数据、使用隐私模式或更换浏览器可能丢失记录，建议每周通过 JSON 导出按钮自行备份。导入功能会在确认后替换当前浏览器的全部100天记录。

## 技术结构

```
100-days/
├── index.html        # 页面结构、内容区和链接
├── assets/
│   ├── style.css     # 视觉系统、响应式、暗色与打印
│   └── app.js        # 打卡、进度地图、周统计、导入导出
├── data/
│   └── program.js    # 100天原创主题与任务
└── README.md
```

无需构建工具：将本文件夹部署到任意静态网站服务即可。它目前作为完整独立的课程目录存放在 **zbyloveyj/zbyloveyj.github.io** 的 `personal-growth-lab/100-days/` 下，复用既有的 GitHub Pages 发布流程。它**目前不是单独的 GitHub 仓库**，如后续需要可整体迁出部署。

## 可维护性

- 编辑 `data/program.js` 可以逐日修改主题、步骤和反思问题，保持100天的编号不变，以便用户历史打卡继续对应。
- 编辑 `assets/app.js` 的 `activityPlan` 可调整每日七项任务的强度和安排。
- 编辑 `assets/style.css` 可调主题、字体和页面布局。
- 使用浏览器开发者工具查看 JavaScript 错误，使用手机尺寸和打印预览检查排版。

**理念：** 不把成长变成又一份沉重的任务。留住真实、缓慢、能再次开始的改变。
