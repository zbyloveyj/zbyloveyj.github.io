# 日有寸进 · 100 Days of Becoming

**项目定位：** 100天、五个阶段、有证据的个人成长实践。把规律作息、均衡饮食、身体活动、阅读、专注、情绪觉察、沟通与复盘组织成渐进式课程。

- 在线网页：<https://zbyloveyj.github.io/personal-growth-lab/100-days/>
- 源码目录：<https://github.com/zbyloveyj/zbyloveyj.github.io/tree/main/personal-growth-lab/100-days>
- 第一套课程：[21天口才与表达](https://zbyloveyj.github.io/personal-growth-lab/)

## 设计原则

**不是每天机械勾选同样七项。** 所有100天均有独立标题、明确的三个核心步骤、一个预期成果、一个反思问题，以及和之前相关课程的衔接。每一天另有两项互补的生活巩固练习，按课程阶段轮换，不会与当日主线重复。

- **100 个不同的每日主题与成果**：每个成果要求留下明确的文本、安排、记录或作品，而不是只阅读教材；
- **99 个前置关联**：Day 01 为起点；其他日子可打开与其主题相关的早期课程，不强制解锁；
- **160 项阶段化辅助练习库**：8个领域 × 5个阶段 × 每领域4个变体，给100天提供200个具体辅助任务位置；
- **15 周的进阶主题**：每周可查看重点，并填写本周留存、调整与停止的行动；
- **3 个努力水平**：轻量、标准、深入采用不同的确认完成规则，避免在忙碌日过度承诺。

## 五段式成长路径

| 阶段 | 练习日 | 预期结果 |
| --- | --- | --- |
| 01 觉察重启 | Day 01—20 | 形成生活基线，知道限制和阻力在哪里 |
| 02 建立节律 | Day 21—40 | 找到可持续的睡眠、饮食、运动与休息安排 |
| 03 认知进阶 | Day 41—60 | 从阅读和复述走向证据核查、主动回忆与可交付写作 |
| 04 拓展边界 | Day 61—80 | 练习主动联系、倾听、反馈、沟通边界与微型作品 |
| 05 长期主义 | Day 81—100 | 精简生活规则，形成异常日预案及下一轮30天行动计划 |

阶段与每天的具体数值属于**个人学习组织方案**，不是医学研究给出的普适最优训练时长或保证结果。

## 每日操作

1. 在网页选择起点日期。推荐按 Day 顺序进行，但课程完全开放。
2. 阅读“本周目标”“阶段目标”“今天要留下什么”，确认今天的核心训练方向。
3. 按顺序完成当日三个不同的核心步骤，每项均有单独的操作文字与完成条件。
4. 从两项与今日主题不同的辅助训练中，自主选择适合自己的一项或两项。
5. 在当日输入框写下真实观察与成果；每周填写复盘笔记。
6. 根据实际选择“确认完成”，不追求全勤，也不会因错过日期清空进度。

**三档完成条件（网站会校验）：**

| 模式 | 通过条件 | 适合 |
| --- | --- | --- |
| 轻量 | 勾选核心第1步 | 忙碌、调整、恢复日 |
| 标准 | 勾选核心3步 | 正常学习工作日 |
| 深入 | 核心3步 + 至少1项辅助 + 至少8字反思 | 时间充裕，希望沉淀完整证据 |

核心步骤、预计成果与前置课程是一种**教学上的练习逻辑**，而不是认定100天能必然改善睡眠、运动能力或心理状态的临床干预结论。每阶段强度的变化优先体现在**任务质量**，而非强行逐日增加运动量或减少饮食。

## 数据和隐私

- 所有任务状态、日期、模式、笔记与自评存在**此设备当前浏览器 localStorage**，不上传到 GitHub，也不自动同步；
- 导出 JSON 文件可备份，另可导出包括预期成果和实际完成情况的 Markdown 报告；
- 网站提供浏览器打印排版，可在打印对话框中另存为 PDF；
- 浏览器清除数据或设备更换可能导致记录丢失；建议每周导出 JSON；
- 导入之前要求确认，会覆盖本设备对应网站的现有100天记录；
- 旧版浏览器记录的每日笔记、已确认完成状态以及旧任务勾选仍保留；**旧版任务勾选不自动冒充新版三步完成条件**。建议按新版内容继续记录。

## 科学依据与边界

页面增加“循证原则与适用边界”，明确区分 **公共健康指导** 与 **本站自主编排的课程**：

- CDC 成人睡眠指导：<https://www.cdc.gov/sleep/about/>
- WHO 身体活动指导：<https://www.who.int/initiatives/behealthy/physical-activity/>
- WHO 健康饮食原则：<https://www.who.int/news-room/fact-sheets/detail/healthy-diet>
- NIH/NCCIH 正念的证据与安全边界：<https://www.nccih.nih.gov/health/meditation-and-mindfulness-effectiveness-and-safety>
- Carpenter 等, *Nature Reviews Psychology*, 2022：<https://doi.org/10.1038/s44159-022-00089-1>

**健康安全：** 身体活动从可接受的强度开始并结合恢复，出现疼痛停止；饮食强调足量、多样与个体适配，不进行不必要的热量限制；冥想不要求“清空思绪”，不适者可停止或选择睁眼觉察。若有持续失眠、伤痛、疾病、饮食障碍或显著心理困扰，请寻求专业人士意见。此网页不能代替医疗或心理治疗。

## 检查方式

```bash
python3 tests/validate_growth100.py
```

此脚本检查100天标题/成果唯一性、99条前置关联、160个辅助变体、每天两项不与主题重复的练习，以及数据链接、JS语法和页面基本可用性。若本机有Chromium/Chrome，还会在无头浏览器运行打开Day 01 / Day 100、跨天导航、轻量/标准规则、浏览器存储和暗色模式的检查。

目前以课程文件夹形式发布于已有的 GitHub Pages 仓库，尚未建立独立的新仓库；21天口才训练及其本地数据与本课程隔离。
