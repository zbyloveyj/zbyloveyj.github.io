## 第一期 · 21天口才与表达系统训练

以 **2026-10-20** 为新一轮学习起点，按实际完成情况自主推进。网站**不会按自然日期强迫解锁**，也不会将未做过的课程标为完成。

完整开放21课，每课建议60分钟，分为三个阶段：

| 周次 | 课程 | 目标 |
|---|---|---|
| 01 | Day 01—07 | 声音、易混音、语速与停顿、重音、第一次测评 |
| 02 | Day 08—14 | 先说结论、逻辑论证、证据边界、故事叙述、即兴表达 |
| 03 | Day 15—21 | 倾听、说服、答问、会议汇报、受众适配、5分钟演讲 |

每课都有完整的分钟安排、专项练习、直接可读的句子、原创朗读短文、复述示范、生活与科研场景、错误纠正、100分自评与录音任务。没有“以后补内容”的空白课次。

## 每天独立PDF教材

21节课均提供独立、可打印的PDF手册，路径为 `downloads/pdf/Day-01.pdf` 至 `Day-21.pdf`。网站的课程页可一键下载，首页设有21份PDF目录。

在原有练习基础上，新增逐课教练讲解、逐分钟训练动作、增加难度的句子练习、独立挑战与参考答案、量化评分指引及回听问题。学习记录保留在浏览器端，PDF不包含用户隐私数据。

## 功能

- 全部课程可直接打开；可自主勾选任务和标记完成
- 每日自评、文字复盘与进度汇总；进度存在浏览器 localStorage
- 一小时计时器；麦克风录音可直接下载到本地（需浏览器支持和用户授权）
- JSON 格式的学习记录导出和导入（跨设备迁移时请手动备份）
- 响应式排版、纸张打印、手机/平板/电脑自适应
- 不依赖框架、不用 CDN、不连接后端服务器、不发送训练音频

**隐私：**录音在浏览器内生成、下载，不保存到网站服务器；本地学习记录不会自动同步或上传。清理浏览器数据会失去本地记录，请主动导出备份。

## 迁移为单独的 GitHub 仓库

这个栏目已按独立静态项目组织，不依赖主站的样式、脚本或图片。需要迁移时：

1. 在 GitHub 新建 public 仓库（例如 personal-growth-lab）；
2. 将此目录内全部文件上传到新仓库根目录（保持 assets/ 和 data/ 层级）；
3. 仓库 Settings → Pages → Source 选择 Deploy from a branch，Branch 选择 main、/(root)；保存后等待 GitHub Pages 完成构建。

如果将项目放在不同的 Pages 子路径，建议更新 index.html 的 canonical URL；所有 CSS 和脚本使用相对路径，迁移后仍能正常工作。

## 内容原则

练习重在真实录音和可复核的进步，不以21天结束时的自评分数替代他人反馈或长期训练。
