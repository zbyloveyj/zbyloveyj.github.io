# 从读研到做研究

作者：一心问道

一本面向研究生及准备进入学术研究者的实践指南。从报考、专业与导师选择，到文献阅读、研究设计、统计分析、学术写作、学术伦理、毕业与职业发展，分九编五十章编写，并附有练习和研究工作模板。
