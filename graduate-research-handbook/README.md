# 从读研到做研究 · 在线阅读

- 作者：一心问道
- 规划：九编、五十章
- 当前发布：九编五十章全部正文初稿（2026年10月），并将逐章扩写、更新来源与编辑校对
- 阅读网址：https://zbyloveyj.github.io/graduate-research-handbook/

站点采用原生HTML/CSS/JS，无需运行时服务。支持手机、平板、电脑自适应；目录检索、章节导航、进度记录、字号调整、明暗模式、收藏、摘录与笔记导出。

内容在 `content/` 目录下，新增章节时同步更新 `index.html` 内的目录元数据和 `data/catalog.json`。

浏览器笔记保存在localStorage中，不跨设备同步；清除浏览器数据会丢失笔记。

具体招生和学位政策以当年正式文件为准。部分研究案例为教学性简化。
