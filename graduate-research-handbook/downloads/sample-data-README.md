# 科研数据分析训练：完全模拟数据

这里的 CSV 由确定性数学公式自动生成，仅用于学习数据字典、清洗、分组描述、批次因素与脚本复现。**不对应任何真实患者、实验或受试者，不能用于临床、社会或科学事实推断。**

字段：
- id：模拟样本编号
- group：0 或 1，模拟比较组
- age：模拟连续协变量
- batch：A/B 两个模拟批次
- score：模拟数值结果，含人为设计的组别、年龄、批次项和波动

推荐练习：
1. 查看数据结构、缺失值和是否有重复ID。
2. 对两组分别计算均值、标准差和样本量。
3. 与未经调整的组间均值差比较，观察回归调整年龄和批次后的估计。
4. 说明为什么“在模拟数据中发现组别差异”不等于真实的因果发现。

脚本：
- `analyze-demo.py`：只使用Python标准库，不需第三方依赖。
- `analyze-demo.R`：使用Base R读取数据、拟合示例回归并输出模型摘要。

从本目录运行脚本；所有结果仅供教学。
