# 学术论文投稿前检查

## 科学与数据
- [ ] 研究问题与标题、摘要、方法和结果一致
- [ ] 主要分析、样本量、效应量、P值与CI已核对
- [ ] 所有图表来自可追踪数据和分析流程
- [ ] 阴性结果、重要限制和探索性分析得到恰当说明

## 合规与作者
- [ ] 各作者资格、顺序与贡献已经确认
- [ ] 伦理审批、知情同意和数据许可描述准确
- [ ] 利益冲突、资助与AI使用披露符合要求
- [ ] 无未经许可的第三方图像或数据

## 投稿材料
- [ ] 期刊Scope确实覆盖研究主题
- [ ] 原创研究/综述/方法论文类型正确
- [ ] Cover Letter与重要声明真实
- [ ] 文献与DOI逐条核对
- [ ] 图表、补充材料和可用性声明齐全
- [ ] 费用、开放获取与版权许可已核实
- [ ] 目标期刊投稿指南已按当前版本阅读
