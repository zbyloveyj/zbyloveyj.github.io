# 研究生入学90天训练清单

## 第1—2周：认识团队与制度
- [ ] 核对培养方案、课程和正式考核节点
- [ ] 完成适用的安全、伦理与数据权限培训
- [ ] 阅读课题组两篇代表性公开论文
- [ ] 完成一页研究地图：问题—方法—材料—合作
- [ ] 建立工作目录、备份和文献库

## 第3—4周：阅读与训练
- [ ] 精读两篇原创研究及一篇综述
- [ ] 对一个公开数据或标准操作完成入门练习
- [ ] 记录主要方法的前提和限制
- [ ] 准备一次不超过五页的组会汇报

## 第5—8周：自主完成小任务
- [ ] 明确小任务的输入与交付成果
- [ ] 保存原始材料、过程日志和版本
- [ ] 对一个异常结果做出具体检查
- [ ] 说明最需要补充的两项专业基础

## 第9—12周：整理研究作品
- [ ] 完成一份有方法、有证据、有局限的小报告
- [ ] 整理数据字典、脚本或实验记录
- [ ] 根据反馈改进作品
- [ ] 写出下个季度的主要目标

## 90天末的复盘
1. 现在能独立完成什么？
2. 哪项方法自己仍然不懂为什么要用？
3. 哪一次失败帮助我识别了真正的问题？
4. 下个阶段最值得投入的两项任务是什么？
