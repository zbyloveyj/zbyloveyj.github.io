# 第二十八章　从原始数据到可以分析的数据

> 本章目标：能够核实数据来源和分析单位，建立变量字典，正确处理缺失、重复和批次问题，并用一份可复现的清洗日志记录重要研究决策。

## 28.1 为什么数据清洗首先是一项研究判断？

研究生小周获得两张数据表：一份临床表包含100名受试者，每人一条记录；另一份检测表包含部分受试者的多次检测。直接按受试者编号合并后，数据增加到145行。他认为“样本量已经扩大”，随后把145行当成145名独立对象进行回归分析。程序运行正常，但样本数的科学含义已经被误解。

这种错误说明，数据处理的起点不是选择一个能够运行的函数，而是明确研究问题和观察单位。一个数据文件里的一行可能代表一名受试者、一次随访、一张图像或一次仪器读数。一个人有三次测量，不等于研究招募了三名独立对象；同一材料重复测量三次，也不必然构成三个独立实验单位。

因此正式清洗前，研究者应该先回答四个问题：每个文件来自哪里，是否具有必要使用权限；每一行代表什么；关键变量具体怎样测量；不同文件之间应当通过什么关系连接。对这些问题没有把握时，应暂停分析并核对原始说明，而不是通过不断运行统计模型寻找异常。

## 28.2 用原始文件、变量字典和处理日志保护证据

建议在获得资料时记录文件来源、数据版本、取得日期、负责人和必要的授权条件。原始输入应尽量保持不被直接覆盖，清洗、转换和建模分别产生新文件，并使用脚本追踪主要步骤。涉及受试者隐私或合作限制的数据，应在机构批准的环境中处理，不得为了共享代码方便而直接上传公开代码仓库。

变量字典至少包含变量名称、实际含义、数据类型、单位、有效范围、特殊缺失编码、测量时点和来源。例如一个字段值为0，究竟表示真正的零、实验未检出还是问卷没有填写？某个临床评分代表总分还是单个维度？同一名称在不同医院是否使用相同量表？这些问题不能凭表格标题猜测。

可以先对少量记录进行人工核查，将数据字典与实际文件比对，再编写自动化检查。若发现编码不一致，应通过有权限的原始来源确认，而不是擅自把未核实的值更改成自己认为合理的类别。

好的数据管理不以“最后表格没有任何空值”为目标，而是能够明确知道哪些观察具有可靠解释、哪些仍存在限制，以及每项处理对研究样本产生什么影响。

## 28.3 主键和数据合并：一个可以运行的教学示例

下面是完全模拟的数据，仅用于说明一对多关系。先建立一份三名对象的临床记录，再建立其中某人拥有两个测量时间点的检测记录。代码需要Python与pandas。

~~~python
import pandas as pd

clinical = pd.DataFrame({
    "id": ["A", "B", "C"],
    "group": [0, 1, 1]
})
measurement = pd.DataFrame({
    "id": ["A", "B", "B", "C"],
    "time": [0, 0, 1, 0],
    "score": [10.0, 13.0, 11.5, 12.0]
})

assert clinical["id"].is_unique
merged = clinical.merge(
    measurement, on="id",
    how="left", validate="one_to_many"
)

print("临床独立对象数:", clinical["id"].nunique())
print("合并后记录数:", len(merged))
print("合并后独立对象数:", merged["id"].nunique())
print(merged)
~~~

运行结果应为三名独立对象、四条合并记录。这里的validate参数用于验证预期的连接关系，却不能自动判断哪次测量最适合自己的研究问题。若目的是比较基线状态，需要依据方案明确选择相应时间点；若目的是评价时间变化，则应保留重复测量结构，并在后续分析中考虑同一对象内部的相关性。

在正式数据合并前，至少核查主键唯一性、各数据表的记录数量、缺失编号和预期的一对一或一对多关系。合并后还应比较唯一对象数是否变化、是否引入不应存在的重复以及重要变量的取值是否符合字典。不能因为连接语句没有报错，就默认数据结构已经正确。

这套检查同样适用于多模态研究。临床变量可能按受试者记录，脑影像可能每人多次扫描，宏基因组也可能存在重复采样。跨模态数据整合必须先说明分析的单位和时间关系，再决定数据结构，不能把不同模态简单当作具有同样行数的矩阵。

## 28.4 怎样理解缺失数据与异常值？

缺失可能来自未采集、受试者未返回、测量失败、文件丢失或某个指标在特定对象上不适用。首先应当确认哪些值确实缺失，并区分录入错误与原始资料中不存在的信息。随后检查缺失比例是否与组别、中心、时间或其他已测量变量有关，以理解它可能怎样影响研究。

假设一项长期随访中，病情更重的参与者更容易退出。若仅分析完成随访的人，留下的样本可能不再代表最初的研究群体。直接删除缺失行会产生什么偏倚，需要结合研究设计判断；反过来，简单使用均值填补也可能改变数据分布和估计精度。适当处理方法需要根据缺失机制假设和分析目标选择，并通过敏感性分析说明重要限制。

异常值同样不是一类必须删除的“不干净数据”。某个极端测量可能是合法的罕见情况，也可能来自设备故障或单位编码错误。应首先核对原始记录、仪器和标准化操作，只有在具有合理依据时才进行修正或排除，并保存决定原因。若无法确定异常原因，可以进行有说明的稳健性比较，而不能只保留让结果变得显著的观察。

研究者还需区别真实零、检测下限和缺失。例如组学数据中的某些零值可能受检测深度与稀疏性影响，不能不经考虑就全部解释为生物学上不存在。变量转换与后续统计方法应与实际测量含义保持一致。

## 28.5 标准化与批次校正为什么无法替代好设计？

在多中心或多批次研究中，不同仪器、试剂、操作流程和人群构成可能共同影响结果。假设所有患者样本都来自采样批次A，对照几乎全部来自批次B，那么疾病状态与技术批次高度重合。即使采用复杂校正算法，也可能无法从数据中分离两种影响，因为缺少必要的组间交叉信息。

研究者应尽可能从设计阶段避免这种情况，例如在允许的条件下合理平衡组别和批次，统一必要的测量流程并保留详细的采集记录。分析阶段可以检查批次分布、进行适当的分层或敏感性分析，但不能把“软件已经校正”当作不存在剩余偏差的证明。

预测模型还有一个特殊风险。如果研究者在全部样本上根据结局标签筛选特征，再把数据分成训练与测试，测试信息已经参与模型开发。若标准化参数也使用了本应独立的测试数据，同样需要评价是否发生信息泄漏。真正的独立模型评价要求与学习有关的处理步骤遵循训练与测试分离的原则。

变量变换本身也需要解释。对数变换、中心化、标准化或组成数据转换可以在适当条件下有用，却不是能够随意叠加的美容步骤。选择应由变量类型、研究目的和模型假设决定，并完整记录具体参数。

## 28.6 怎样写一份真正有用的清洗日志？

一份合格的清洗日志应覆盖每项可能改变研究样本或主要结论的重要决定。例如将某些值重新定义为缺失，应该说明依据的原始变量说明；排除样本需要记录数量、条件和理由；选择某一次随访应说明与主要结局时间的关系；批次处理与标准化则需要保存能够复现的脚本和参数。

可以采用以下简化结构：

| 决策 | 依据 | 对研究的影响 |
| --- | --- | --- |
| 统一变量单位 | 正式测量说明和字典 | 增强不同来源的可比性 |
| 检查重复ID | 受试者和记录单位定义 | 防止错误增加独立样本数 |
| 处理缺失 | 数据来源和分析计划 | 影响样本构成与估计 |
| 检查批次 | 仪器、日期和采集日志 | 评价可能的技术混杂 |

如果研究过程中发现原来的清洗方法存在问题，应保留旧版本并说明何时改变、改变什么、主要结果是否受到影响。清洗规则不应该由某次分析是否显著来决定。

在工作结束时，将原始输入、数据字典、处理脚本、样本流程和质量报告对应起来。另一名具有授权的合作者应能够理解从最初文件到最终分析表格发生了哪些变化。

## 28.7 本章实践：自己构造错误，再学会识别

首先下载本书提供的完全模拟数据，保存一份未修改的输入文件。然后在独立副本中人为增加一条重复编号、将一个合法数值换成未经定义的缺失编码，并给一条记录设置不合理的年龄值。目标不是制造逼真的临床数据，而是学习自动化检查和科学记录。

接下来编写程序识别这些问题，并为每个异常决定是否可以根据已知来源修正、是否需要保留不确定性、是否应该暂停相关分析。再比较处理前后的记录数、独立对象数与基本描述统计，说明为什么数据清洗会影响研究结果。

最后提交数据字典、处理脚本、清洗日志和一页质量报告。请另一名同学只使用这些材料重新运行检查。如果对方不能解释为什么某个样本被排除、某条记录被保留或者某个变量被转换，说明研究记录还不够完整。

**本章小结。** 数据清洗不是让表格变得整齐，而是保护和理解研究证据。能否追溯来源、明确观察单位、解释每个重要处理决定，决定后续统计结果是否值得信赖。

## 本章综合实训：合并后样本数量为什么变大

**任务情境。** 使用虚构的一对多数据表练习主键和重复时间点，区分记录数与独立对象数，并判断基线分析和纵向分析的不同需要。

**具体做法。** 用合成数据构造一对多的测量表，先预测合并后的行数和唯一对象数，再在代码中验证连接关系。人为设置一项缺失编码和一条异常值，分别记录能够核实与无法确认的部分。

**验收作品。** 数据字典、清洗脚本和合并检查报告。 **核验要点。** 把清洗前后的样本流向、数据字典和脚本交给同伴重跑，确认不会重复计数。 本项为教学训练，不代替所在单位的正式要求。
