# 第三十章　怎样选择和使用统计分析方法？

## 30.1 选择方法之前先回答五个问题

很多学生学习统计的方式，是先记住“正态用t检验，非正态用秩和检验”“多个变量用回归”等口诀。这样的记忆在少数简单场景中可能有帮助，但一旦遇到配对、失访、医院层级或多种结局，就容易选错方法。真正决定分析方案的是研究设计、数据结构和希望估计的具体量，而不只是某个变量在直方图中是否接近钟形。

建议在打开软件之前写出五句话。第一，研究对象是什么，最小独立观察单位是谁？第二，主要结局如何测量，是连续评分、二分类状态、计数还是事件发生时间？第三，组间比较是独立还是配对，是否存在多次测量或中心聚类？第四，想估计的是平均差异、关联参数、风险、预测性能还是某项干预的效果？第五，哪些潜在混杂和质量问题需要在设计或模型中处理？如果五个问题中有两三个仍回答不清，应暂缓正式分析，优先核对变量字典和研究方案。

例如一份数据有200行，并不代表存在200名独立受试者。它可能是100名学生的期初、期末两次记录，也可能是50个对象在四个时间点的测量。把每一行直接当作独立观察进行统计，可能错误估计标准误与不确定性。统计方法看似同名，其所依赖的数据关系却决定了结果能否解释。

特别要区分推断目标。研究者可以用回归来描述不同变量在样本中的关联，也可以开发模型在新对象上预测结果，但“关联参数显著”不自动代表具有良好的个体预测能力；预测性能优秀也不意味着算法中最重要的变量具有因果作用。研究设计应在问题形成阶段就明确这一点。

## 30.2 两组比较与多组比较

连续变量的两组比较可能使用适合假设条件的t检验，也可能采用其他稳健或非参数方法。多组比较可根据设计考虑方差分析、回归或其他方法。

是否使用某个检验，不能仅由“数据看起来正态”决定，还需要考虑样本独立性、方差结构、研究目标和参数解释。

多组比较时应说明总体检验、事后比较和多重比较控制的关系。

## 30.3 配对数据与重复测量

配对数据最直观的例子，是同一批受试者在干预前后接受相同测量。假设研究记录了20名受试者的两次评分，分析目的不是比较“前20行和后20行”这两组毫无关系的数据，而是研究每一个人的前后变化。配对方法利用个体内部的对应信息，其假设与独立样本方法不同；若受试者中有人缺少第二次记录，还需要讨论缺失或失访的可能影响。

在R中可以使用内置的sleep教学数据练习这一结构。数据包含同一对象在两种条件下的记录，真正需要理解的是ID与条件之间的对应关系。下面代码先将长格式整理成一人一行的宽格式，再进行配对比较：

~~~r
data(sleep)
wide <- reshape(
  sleep,
  idvar = "ID",
  timevar = "group",
  direction = "wide"
)
stopifnot(nrow(wide) == length(unique(sleep$ID)))
print(wide[, c("ID", "extra.1", "extra.2")])
result <- t.test(
  wide$extra.2, wide$extra.1,
  paired = TRUE,
  conf.level = 0.95
)
print(result)
~~~

运行以后应先查看每人的差值分布，再判断配对t检验的相关假设是否合理，并解释结果是“条件2减条件1”的平均差值。不要只抄下输出P值，更不能因为这个示例数据的两种条件不同，就自动对任何真实干预作出因果推断。

如果研究包含三个或更多时点，问题可能进一步涉及时间变化和个体间差异。某些研究适合重复测量模型或混合效应模型，但选择随机截距、随机斜率与协变量的依据应来自设计和数据，而不是通过反复尝试直到获得最小P值。中心聚类与重复测量还可能同时存在，此时需要更仔细地确定层级结构。

## 30.4 相关分析什么时候合适

Pearson相关用于描述某些条件下的线性关联，Spearman相关更关注秩次关系。相关系数的选择应考虑变量特点、关系形态和异常值。

如果研究涉及明显的年龄、性别、批次等混杂因素，仅报告简单相关可能不足以支持目标解释。是否进行调整及采用何种模型，应根据研究假设和数据结构决定。

## 30.5 线性回归和逻辑回归

线性回归常用于分析连续结局与解释变量的关系；逻辑回归可用于二分类结局。选择模型时需要理解变量编码、系数含义、异常观察、共线性和必要的诊断。

对二分类结局，不能把逻辑回归的优势比直接当成风险比；对连续结局，不能脱离变量单位解释系数。

分析结果应报告参数估计、不确定性与主要调整因素，而不仅是哪些变量达到统计显著。

## 30.6 生存分析与时间事件数据

当研究结局是某事件发生的时间，并且部分受试者尚未发生事件或失访时，普通的均值比较往往无法合理处理删失信息。

生存分析中的Kaplan–Meier方法和Cox比例风险模型等，可以用于适当场景，但需要理解删失、时间起点和相关假设。比如Cox模型的比例风险假设是否合理，就可能影响结果解释。

正式临床研究还需要结合专业统计指导与领域报告规范。

## 30.7 混合效应模型与多层级结构

多中心医院、班级内学生、同一受试者重复测量等数据具有聚类或层级结构。在适当场景下，混合效应模型可以描述固定效应和群组间变异。

但模型越复杂并不一定越好。如果只有少数研究中心，某些随机效应估计可能不稳定。选择模型时应检查数据是否足以支撑参数，并对假设开展诊断。

## 30.8 高维研究的多重检验

组学数据、脑影像或多变量筛选可能一次检验成百上千的特征。若对每个检验都使用0.05阈值而不考虑多重比较，很容易出现大量偶然显著结果。

可以根据推断目标采用控制家族错误率或假发现率的策略，并清楚报告检验数量、调整方法及显著性标准。预先选择的主要假设和探索性筛选不应混为一谈。

## 30.9 怎样处理缺失、异常值和敏感性分析

正式分析前，应当检查缺失是由于未采集、测量故障、退出研究，还是不适用某个变量。不同缺失机制可能对应不同偏倚风险。比如一项随访研究中，健康状况较差的人更容易中途退出，那么只分析完成全部随访的人，可能使最后结果偏向相对健康的人群。把缺失值统一替换为均值，不仅可能改变估计，还可能不恰当地压缩数据变异。

对异常观察也不应只看它偏离均值多少。某项医学指标很极端，可能是真实罕见的观察，也可能是单位录入错误。应先查原始记录和测量规则，能够证实的错误按可追溯的程序处理；无法核实的情况则需要合适的稳健性分析与透明说明。研究者不能因为某个样本使结果不显著就把它删除。

建议将敏感性分析明确为“围绕关键假设的必要检验”，而不是“不断更换分析直到得到想要的结论”。例如主要结果使用预先确定的缺失处理方法，补充结果可以讨论适当的完整案例分析或其他合理模型，但应解释为什么这样比较。若不同合理分析给出相互矛盾的结果，研究发现可能对模型假设非常敏感，这本身就应该进入Discussion，而不是被藏在没有解释的补充表中。

## 30.10 一个实用的统计决策表

| 研究问题 | 数据结构 | 可能的方法 |
| --- | --- | --- |
| 两组连续结局 | 独立样本 | 合适的均值比较或回归 |
| 两次评分变化 | 同一批受试者 | 配对方法或适当模型 |
| 二分类结局与协变量 | 独立或适当聚类数据 | 逻辑回归及必要的层级处理 |
| 多时点纵向变化 | 重复测量 | 纵向模型或混合效应模型 |
| 事件发生时间 | 存在删失 | 生存分析 |
| 多个高维特征 | 大量同时检验 | 多重比较控制与独立验证 |

该表用于方法定位，不替代对模型前提与研究对象的检查。

## 30.11 本章实践：写一份统计分析计划

本章作业不是提交一张统计检验选择流程图，而是使用一份公开或完全模拟的数据，完成一份可以在分析前审阅的计划。第一部分用不超过150字定义研究问题和主要估计目标；第二部分明确分析单位、结局类型、比较组别以及是否配对、聚类或重复测量；第三部分给出主要模型与重要假设；第四部分规定缺失、异常值与必要的多重比较处理；第五部分解释将报告哪些估计、区间和验证结果。

建议先独立完成方案，再运行程序。若在分析中发现原计划存在严重缺陷，应在日志里说明具体错误和修改时间，并清楚标记修订后的结果性质。不要将新的探索性模型在结果得到以后重新写成从一开始就预先指定的主要分析。

提交的最终作品包含四个文件：数据字典、分析计划、可重复的代码和一页结果解释。请一名同学从未接触该项目的视角核查能否回答“分析了什么、为何采用这个模型、结果有多精确、它不能说明什么”。

为了评价学习成果，可以采用四项标准：设计和变量理解占30%，模型选择与假设说明占25%，代码与结果可重复性占25%，结果解释与局限占20%。分值只是教学建议，重点不在于取得满分，而在于找出需要继续训练的环节。

## 统计方法的实际选用：四个对比案例

第一种情况是比较独立的两个群体在某项连续指标上的分布。可以先检查数据的抽样、分布、方差和异常值，再根据研究问题考虑适当的均值比较或回归，而不是一上来就运行所有检验，从中挑选最显著的结果。

第二种情况是同一组患者的治疗前后评分。因为两次数据来自同一对象，观察之间有关联，不能直接当作两个完全独立样本。应考虑适当的配对方法或重复测量模型，并对失访和治疗过程中的其他影响保持谨慎。若没有随机对照设计，即使评分下降，也未必能直接把全部变化归因于某项治疗。

第三种情况是预测某人是否发生一种二分类事件。可以考虑逻辑回归等模型，但需要弄清变量编码、研究对象来源、类别比例与预测阈值，并区分优势比、风险比和实际预测概率。第四种情况是比较不同时间的事件发生风险，此时可能需要能处理删失的生存分析，而不是简单比较最终发生事件的人数。

上述案例说明，统计方法的选择首先由结局类型、样本独立性、研究目的与数据结构决定。方法名称并不存在脱离研究问题的优劣排名。

## 结果没有达到预期，应该怎样检查？

首先确认代码与数据没有明显错误，例如变量编码相反、缺失值被错误当作零、同一受试者重复计数。随后检查模型假设、异常值、样本规模和估计不确定性，判断是否有合理的替代分析需要开展。

如果结果在多种合理方法下仍然不显著，应如实报告，讨论当前数据可以排除多大的效应范围，而不是反复更改协变量直到出现想要的星号。如果某项调整确实来自新发现的方法问题，需要保存原计划与变更原因，并明确新的分析属于验证还是探索。

建议为每项主要结果附上一页“模型选择说明”：为什么使用此模型、哪些基本假设已检查、重要协变量来自哪里、结果与哪张图对应。这个小习惯能够明显提高统计写作的透明度。

## 综合练习：配对与独立样本

**任务情境。** 使用R自带sleep数据比较同一对象不同条件下的评分，检查配对关系、差值分布和结果方向；将分析计划写在运行代码之前。

**具体做法。** 先确认教学数据是独立样本、配对数据还是重复测量，再根据结局类型写出主要分析模型。使用R内置sleep数据完成配对检验，对照不恰当的独立检验解释两者的假设差异，补写缺失值与敏感性分析方案。

**验收作品。** 可运行R脚本和统计分析计划。 **核验要点。** 统计模型、对象结构、报告的效应单位和方法学文字必须完全一致。

## 本章小结

统计选择不是寻找“最容易显著”的按钮，而是寻找与研究问题和数据结构相匹配、能够正确表达不确定性的分析方案。
