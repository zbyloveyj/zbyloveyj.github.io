# 第二十五章　从研究问题到完整研究方案

> 研究方案是一份关于“为什么研究、怎样做、如何判断结果”的工作约定。它让研究团队在开始之前识别关键风险，也为之后解释方法变化留下依据。

## 25.1 为什么先写方案比先分析数据更重要

很多新生拿到一份数据后，第一反应是立刻运行统计检验。等看到显著结果，再尝试解释它意味着什么。这样容易在研究问题、变量选择和分析方法之间形成事后循环。

一个较好的研究方案应先说明主要问题和需要的证据，再规定合理的数据处理与分析路径。计划可以根据实际情况修改，但重要改变应当有理由、有记录。

## 25.2 研究背景应该怎样写

研究背景不应变成对某个领域的百科式介绍。一般先说明现实或理论上的重要问题，再整理与其直接相关的已有证据，指出尚未解决的具体限制，最终引出本研究目标。

例如，关于疾病预测模型的方案，可以从应用需求转向已有模型的外部验证问题，而不是花大量文字讲述人工智能发展的历史。

每一项关键背景判断都应由能够核实的文献支持。

## 25.3 怎样表述研究目标

目标应具体到研究对象、主要问题与可判断的结果。避免“全面揭示所有机制”“构建世界领先范式”等过于宽泛且难以验证的表述。

例如，“评估模型在三个独立人群队列的判别性能及其对数据来源差异的敏感性”，就比“建立最先进的智能诊断体系”更适合一项范围明确的研究生课题。

目标可以包含主要目标和次要目标，但每一个目标都应对应必要的研究内容和分析证据。

## 25.4 研究内容如何拆分

研究内容之间应具有合理逻辑，而不是把所有能做的技术写成平行模块。可以沿着数据质量、主要分析、独立验证和结果解释逐步推进。

例如第一部分评估样本与变量的可比性，第二部分检验预先提出的主要关联，第三部分在独立数据中评估可重复性，第四部分讨论异质性来源和方法局限。

每一部分都应清楚回答“为什么做这一步”“需要什么输入”“产生什么可以检查的输出”。

## 25.5 技术路线图应该表达什么

好的技术路线图是研究逻辑的可视化，不是把所有软件和算法名称塞进彩色框。

通常可以用“研究对象与材料—质量控制—核心分析—独立验证—结论解释”五个环节描述。对于实验研究还要体现对照、重复和测量；对于质性研究则应展示材料选择、编码、解释和可信度检查。

箭头应反映真实的流程或关系。不能因为图画得好看，就暗示尚无证据支持的因果机制。

## 25.6 统计分析计划应包含什么

分析计划至少说明主要结果变量、比较对象、重要协变量、基本统计模型、缺失数据处理、必要的多重比较控制与敏感性分析。

如果是机器学习研究，还需说明训练、调参与测试的分离方式，交叉验证、独立测试和模型评价指标，避免数据泄漏。

若分析以探索为主，应诚实标注探索性质，不应宣称所有结果都具有预先验证的地位。

## 25.7 研究预注册与方案变更

部分学科和研究类型适合预注册，它能够帮助区分预先计划的检验与后来探索得到的发现。但预注册不是所有研究的统一强制模板，具体需要根据设计、伦理与相关规范判断。

研究实施中可能因数据质量或技术问题修改方案。修改本身不一定不合理，关键在于记录时间、原因、受影响内容，并在最终论文中透明说明。

## 25.8 项目风险与备选方案

合理的风险表应关注真正影响研究可行性的事项，如关键数据授权失败、样本量不足、技术测量不稳定、合作节点延迟和重要假设不成立。

对每项风险写出可观察的预警信号与应对措施。例如，若外部验证队列无法获得，可以选择先形成一项范围更清楚的方法评估，而不是虚构能够完成跨人群验证的承诺。

## 25.9 一份研究方案的建议结构

| 部分 | 应回答的问题 |
| --- | --- |
| 背景 | 问题为什么重要，已有证据是什么 |
| 研究目标 | 本研究准备得到哪类新认识 |
| 研究内容 | 研究分为哪些逻辑相连的任务 |
| 对象与材料 | 数据、样本或文本从哪里来 |
| 方法与分析 | 如何获取、处理、比较和解释证据 |
| 验证与质量控制 | 怎样判断结果可信 |
| 伦理与规范 | 是否具备必要的授权与安全条件 |
| 风险与进度 | 关键依赖、里程碑与替代方案 |

这份结构可按学科调整，不必机械套用。

## 25.10 本章实践：完成五到十页的研究方案

选择一个明确的问题，写出研究背景、主要目标、研究内容、数据或材料、分析计划、验证措施、资源需求与风险表。让另一名熟悉该学科的同学尝试判断：仅凭方案，能否理解研究如何实施？

如果答案是否定的，就优先改进方法的具体性，而不是增加宏大形容词。

## 一份研究方案怎样从头写到尾：案例框架

仍然以“预测模型的跨中心泛化”为例。一份方案开头应该解释模型可能在开发队列内表现较好，却缺乏跨机构证据的实际问题。随后通过真实文献梳理已有模型采用的评价方法，指出目前最需要解决的一个限制：不同医院之间的性能是否稳定，以及哪些数据差异可能影响表现。

接着明确研究对象和数据来源。比如计划使用多个已经具备相应授权的独立队列，说明这些队列的纳入排除、主要结局定义、测量流程和样本结构。若某个队列尚未获得许可，就必须标记为待落实资源，不应把它当作已经具备的研究基础。

第三步是规定模型与验证路线。需要确定开发数据、调参数据和真正独立的外部测试数据，说明特征处理和模型选择如何避免泄漏，预先确定核心评价指标与必要的敏感性分析。假设模型外部表现下降，也应通过分层和数据质量检查分析可能原因，而不是无限更换模型以得到较高的数字。

最后设置里程碑和风险控制：在第一阶段确认数据权限与字典；第二阶段完成质量控制与主要模型训练；第三阶段开展锁定后的独立验证；第四阶段解释结果、整理图表和撰写论文。实际时间安排应与研究资源和培养制度匹配。

## 科学假设、研究内容与技术路线怎样避免重复

写申请书时，常见的问题是将相同一句话分别放进“科学问题”“研究目标”“研究内容”和“技术路线”，只是每次更换一个动词。实际上，这几部分有不同功能。科学问题是尚未知道的事实或关系；研究目标是希望形成的具体知识结果；研究内容是计划完成的工作；技术路线则说明这些工作如何按照逻辑顺序实施。

以同一案例为例，科学问题是“模型跨医院适用性受到哪些条件限制”；研究目标是“量化独立数据上的性能与差异”；研究内容包括数据质量核查、模型评价和分层分析；技术路线则体现不同数据集的进入、处理、训练、验证与解释步骤。若任何一部分脱离了其他部分，就应检查整体方案是否存在逻辑断裂。

## 为什么好的风险方案不等于保证成功

假设研究原计划获得某种关键样本，却可能因伦理、资金或合作进度无法获得。可以预先设计是否允许使用合法的替代数据、是否能够将问题收窄为方法评价，或者是否需要调整研究目标。这样的备选路径不应该偷偷改变主要结论，而应确保在资源变化时仍能开展有科学价值的工作。

此外，如果模型不支持预期假设，研究者也应能够报告结果，解释为什么外部验证失败可能提供重要知识。研究方案最值得保护的不是某个理想结果，而是方法与证据的可信程度。

## 本章小结

研究方案的价值在于把科学判断变成可以执行、检查和修订的计划。研究问题、设计、资源和验证相互匹配，方案才真正具有可行性。
