# 第三十二章　科研数据可视化与可重复分析

## 32.1 图表首先要回答一个问题

制作图表之前，应先写下读者看完图应该理解什么：两组数据的分布是否不同？某变量随时间如何变化？模型在独立样本上的表现怎样？

如果一张图只因为颜色丰富而吸引注意，却无法让读者理解研究问题，它并没有完成科学交流任务。不要把多个不同问题硬塞进一张复杂面板。

## 32.2 常见科研图怎样选择

选择图表之前，最好先区分自己想展示的是原始数据的形态、变量之间的关联、模型估计，还是一个随着时间变化的过程。展示原始分布时，散点、箱线、点图或其他合适的分布图可能比只有均值的柱状图更充分；研究两个连续变量之间的关系时，散点图能够帮助检查非线性、离群值和分组差异；比较多项估计值时，带有区间的点估计图往往比只列显著性星号更加直观。

假设某研究比较两组独立受试者的实验指标，样本量不大，但其中一组数据存在明显长尾。只画两根均值柱形并加一个标准误，读者可能无法看出偏态与个别极端观察。如果研究对象和期刊要求允许，可以展示单个样本与合理的分布摘要，并在正文解释使用的统计方法。若样本非常多，单个点可能相互遮挡，透明度、分箱、抽样展示或适当密度图才更有意义。图形选择没有脱离样本规模和问题的统一答案。

对于纵向研究，同一受试者的不同时间点若只展示各组平均值，可能隐藏个体间完全不同的变化趋势。在适当规模下，可以使用连接线展示配对轨迹，同时再提供群体层面的估计。但如果受试者很多，所有轨迹叠加又可能产生视觉混乱，需要清楚区分“原始变化范围”和“主要模型估计”两个不同目的。

医学预测研究还可能使用ROC曲线、校准曲线和决策相关图表。它们回答的问题不同：ROC重点展示不同阈值下的判别能力，校准关注预测概率与实际结局发生情况的一致性。模型具有较高的AUC并不保证其预测概率足够准确，因此不能把一张ROC曲线当作临床应用证据的全部。

## 32.3 为什么要显示样本量与不确定性

平均值与柱状图经常隐藏分布。对于样本量适合的场景，可以展示单个观察点并配合适当的汇总指标；涉及估计的图表应在可能情况下显示置信区间或其他清楚定义的不确定性。

误差条必须解释它代表标准差、标准误还是置信区间。三者含义不同，不能在图注中混用。

## 32.4 视觉编码影响科学判断

坐标范围、分组颜色、点大小、比例和排序都会影响读者的感受。如果柱状图的纵轴被截断，细小差异可能看起来极其夸张。某些散点图在透明度不足时会严重遮挡数据。

可以优先采用清晰的坐标、易区分的颜色、统一的字体与适当的留白。彩色不应成为唯一的分组区分手段，以兼顾灰度打印和色觉差异。

## 32.5 图注应当如何写

图注应让读者在不依赖正文的情况下基本理解图的内容，说明研究对象、变量、样本数量、统计方法和标记含义。

例如“星号表示显著”远远不够，需要解释比较的是谁、使用什么方法、阈值怎样定义，以及是否进行了多重检验调整。

图中展示的统计结果应与正文报告一致，不能为了排版手动修改数字。

## 32.6 R和Python绘图的可重复流程

科研绘图最值得养成的习惯是从经过核验的数据文件开始，由脚本生成全部输出，而不是手工在图片上反复修改数字或显著性标记。下面使用本书配套的完全合成数据文件 synthetic-demo.csv 作为练习。它包含虚构组别、年龄、批次与评分，不对应真实患者或实验，也不提供任何临床科学证据。

首先用Base R读取数据，确认变量类型和样本数，再制作既能显示分布又能保留个体观察值的图。代码将结果保存为矢量PDF，便于放大和后续编辑：

~~~r
d <- read.csv("synthetic-demo.csv")
stopifnot(nrow(d) == 64, !anyDuplicated(d$id))
d$group <- factor(d$group)
pdf("synthetic_score_distribution.pdf", width = 6.2, height = 4.4)
boxplot(score ~ group, data = d,
        xlab = "Simulated group",
        ylab = "Simulated score",
        col = "white", outline = FALSE)
stripchart(score ~ group, data = d,
           vertical = TRUE, method = "jitter",
           jitter = 0.12, add = TRUE,
           pch = 16, col = grDevices::rgb(0.2, 0.35, 0.3, 0.45))
dev.off()
~~~

这里的箱线图帮助显示数据分布，散点揭示实际观测的离散情况，两者都不能独立证明组别产生因果影响。outline = FALSE仅关闭箱线图默认的异常值符号绘制，不会从数据中删除异常值，单个数据点仍可通过散点层显示。实际研究还应注意数据独立性、模型调整与图注中误差含义等问题。

图表保存以后，应在README里记录输入文件、脚本名、使用的R版本和输出文件。若后来决定改变坐标范围或图形排列，尽量修改脚本重新运行，而不是直接用图片编辑器遮盖或移动某些不符合预期的结果。对于正式发表，还需要核对期刊要求的输出尺寸、文件格式和版权许可。

此外，建议比较两种不同的图。第一种只展示分组均值，第二种在合适范围内展示数据分布和原始观察。请让没有看过数据的人说明哪一张更有利于判断差异是否由少数样本主导；若两种表达强调不同的分析目标，应解释为何不能简单宣布某一种图在所有情境下都更“高级”。

## 32.7 图表与统计模型如何一致

如果正文报告的是控制年龄、性别后的模型系数，而图只展示未经调整的两组均值，读者可能误以为图直接代表调整后的结果。应在正文和图注中明确区分描述性结果和模型估计。

同样，如果数据来自同一受试者的多次测量，绘图时可以使用配对连接或纵向轨迹，使数据结构不被简单柱状图遮蔽。

## 32.8 什么是可重复分析

可重复分析要求他人在拥有适当权限和相同或兼容的数据环境下，能够按照方法与代码重新获得主要计算结果。它涉及输入数据、脚本、软件版本、参数、随机种子和输出。

这不等于所有数据都必须公开。涉及隐私或商业保密时，可以合理共享分析流程、模拟数据或经过授权的受限访问方案，同时说明无法公开的原因。

## 32.9 建立分析流程README

README可包括研究目的、输入数据字典、运行顺序、软件版本、需要的依赖包、主要参数、输出说明和限制。对大型项目，还可以使用环境配置文件与测试脚本减少版本变化导致的问题。

如果需要靠作者口头解释每一步才能重新运行，研究的计算可复现性仍然不足。

## 32.10 本章实践：把一个分析结果改造成论文图

第一步，用本书模拟数据制作一张两组评分的分布图，并写出不少于100字的图注，说明数据是如何生成的、每个点代表什么、箱线图与散点层各自表达什么。第二步，将这张图与包含年龄和批次的回归结果对照，讨论未经调整的分布与调整模型的组别系数为什么不能混为同一项结果。第三步，在分析脚本中改变图像尺寸和字体设置，确认统计数据没有随着美化而改变。

第四步，建立一个最小可复现项目目录，其中至少有原始模拟数据、图表生成脚本、输出PDF和README。邀请同学不通过你的个人电脑操作记录，尝试根据说明重新生成相同图表。如果缺少某个包、工作路径不正确或者图中单位不清楚，就修订说明并重新测试。

最后按照五项标准检查：研究问题是否明确、图形是否忠实、样本与不确定性是否合理展示、图注是否能独立理解、脚本是否能复现。可以把这些标准分别赋予20%的教学权重，但不应让这张表替代真正的专业判断。数据可视化训练的最终目标，是让读者在面对新的研究时也能够选择正确而诚实的表达方式。

## 一张科研图怎样从“能看”变成“能解释”？

假设你要展示两组受试者的临床评分差异。第一版只使用两个不同高度的柱状图，并在上方标记一颗显著性星号。这样的图可能隐藏真实分布、样本数量和异常观察，也不能说明误差条表示什么。

在研究对象和期刊版面允许的情况下，可以考虑使用单个观察点与适当的分布摘要，清楚标注各组样本量，再根据研究问题显示效应大小及不确定性。如果采用了协变量调整，图应明确展示未经调整的原始观察还是调整模型的估计，不能把两者混为一谈。

有些图非常适合展示原始数据，有些图适合展示模型结果。关键不是一律使用某一种“顶刊风格”图，而是选择最能帮助读者理解研究证据的表达方式。

## 让图表可以从代码重新生成

一个可重复的绘图项目至少需要明确输入文件、变量字典、绘图脚本、必要的统计结果与软件环境。不要在原始数据表里手动删除“看起来不合群”的点，也不要为了美化图形修改实际数值。对于因数据质量原因需要排除的观察，应在分析记录中说明依据。

建议设置统一的图表命名方式，并在图注写明变量、单位、样本量、误差条和统计方法。若正文结果随着重新分析发生变化，应重新运行绘图流程，而不是只用图片编辑工具手工改动标记。

图形设计中的颜色和排版可以持续优化，但科学含义必须保持稳定。特别是对具有连续变化的指标，不应通过不合理的色阶截断来制造明显边界；对于不同分组，应避免单独依靠颜色区分。

## 图表内部审查怎么做？

正式将一张图放入论文前，可以邀请其他研究者只看图和图注，回答四个问题：图中的每个点代表什么？组间或变量之间的比较是什么？主要估计有多大不确定性？图允许得出的结论是什么？

如果对方无法回答，优先检查图注、坐标轴、样本量和图表类型，而不是立即增加装饰元素。科研图应当让研究得到更准确的理解，而非仅仅吸引注意。

## 综合练习：科研图怎样忠实于数据

**任务情境。** 对同一份模拟数据分别画均值图和个体分布图，标出样本单位、误差含义与模型调整条件；用脚本重新生成而不是手动改数字。

**具体做法。** 利用本书合成CSV绘制原始点与分布摘要，另制作一张包含模型估计与不确定性说明的图。由同一脚本输出矢量文件、图注和样本量信息，对照两种图能回答的问题。

**验收作品。** 矢量图、图注、绘图脚本与README。 **核验要点。** 让同学只看图与图注解释分析单位、误差条与结果边界，检查是否可重复生成。

## 本章小结

科学图表是证据表达，而不是装饰。清晰、诚实、可重复的图表，比复杂但难以理解的视觉效果更有价值。
