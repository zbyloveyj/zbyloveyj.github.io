# 第十九章　如何进行批判性阅读与证据评价？

> 批判性阅读不是专门寻找别人的错误，而是认真判断研究设计与证据能回答哪些问题，以及哪些解释仍需进一步验证。

## 19.1 论文发表并不意味着研究永远正确

同行评议能够发现一部分问题，但期刊审稿通常无法重新开展所有实验，也不能完整检查每个数据来源。研究结论仍需后续的复现、独立验证和新证据检验。

因此，尊重已发表研究与保留合理质疑并不矛盾。阅读论文时，先尝试公平理解作者为什么这样设计，再检查其证据是否足以支持结论。

## 19.2 首先判断问题与设计是否匹配

如果研究希望描述某地区疾病患病情况，应检查抽样、测量和代表性；如果研究声称某种干预产生效果，就需要考虑对照、随机化、基线差异和时间顺序；如果研究主要提出新的理论解释，评价重点可能是论证逻辑和已有证据的适配性。

不能用某一种学科的证据模板硬套所有研究，但任何研究都应有与问题相称的方法。

## 19.3 样本选择偏倚如何影响结论

假设一项疾病研究仅从单一医院招募患者，而健康人来自体检中心。两组在年龄、用药、疾病严重程度和采样流程上可能存在系统性差异。

即使统计模型找到显著关联，也需要判断观察到的变化是否可能由这些因素造成。统计调整能够帮助控制部分已测量因素，但无法自动消除所有选择偏倚或未测量混杂。

评估研究时应检查纳入排除标准、样本流程图、组间比较与缺失信息。

## 19.4 统计分析常见的四个危险信号

第一，只报告达到阈值的P值，而几乎不讨论效应大小和估计精度。第二，在大量比较中没有说明多重检验或研究的探索性质。第三，使用复杂模型却缺少独立验证，甚至发生训练与测试信息混用。第四，事后修改主要分析方案，却写得像研究开始之前就已经确定。

这些情况不一定都构成学术不端，但可能降低结论的可信程度，需要通过更完整的研究报告与独立证据判断。

## 19.5 相关性与因果性为什么容易混淆

两项变量有关联，并不意味着其中一项一定导致另一项。年龄、用药、生活方式或研究环境可能同时影响两者，甚至可能存在反向关系。

例如，观察到疾病患者的某个微生物丰度较高，不能仅凭这一结果说明该微生物造成疾病。它也可能受到治疗、饮食或疾病本身的影响。

因果推断需要更明确的设计和假设，如合适的随机实验、纵向证据、自然实验或其他有严格条件的推断策略。不同方法具有不同边界。

## 19.6 什么是稳健性与敏感性分析

稳健性分析关注结论是否高度依赖某一项模型选择、样本处理或变量定义。例如，更换合理的缺失数据处理方法、控制关键协变量、在不同亚组中检查趋势，可能帮助理解结果的稳定性。

但不能把反复尝试直到出现显著结果称为“稳健性”。分析需要说明选择依据，并区分预先计划与探索性检查。

如果不同合理分析得到明显不同的结论，这本身就是重要信息，应诚实报告和讨论。

## 19.7 为什么不同研究可能不一致

不同研究的样本、测量工具、地区、实验流程、分析方法和研究目标可能不同。两篇论文结果不一致，不能立即断定其中一篇存在错误。

应尝试检查差异是否来自研究对象或方法，也可能反映真实效应在不同条件下有所变化。跨研究复现是了解知识边界的重要过程。

研究者需要警惕把“在一个队列没有复现”过度解释为“过去所有研究都无效”，也不能因为有一篇正面结果就忽略多项高质量阴性证据。

## 19.8 怎么评价证据等级

不同研究设计能够支持不同类型的推断。临床干预问题可能重视随机对照试验和经过严谨方法开展的系统综述；诊断研究需要评价其参考标准、研究人群与实际场景；机制实验需要考虑模型与人类疾病的对应关系。

证据等级并不是对所有领域、所有研究问题通用的简单排行榜。研究者还必须关心偏倚风险、直接性、精确性、一致性与其他背景条件。

对于研究质量的正式评价，应使用适合该研究设计的专门工具，而不是凭“发表于高影响力期刊”判断。

## 19.9 研究争议与撤稿应该如何理解

论文更正、撤稿或争议是学术记录变化的一部分。发现错误不一定意味着所有作者都故意造假，具体情况要依据公开事实和调查程序判断。

如果某篇论文已更正或撤稿，后续研究者应检查这些变化对自己引用的论断有何影响，必要时更新研究方案和文献表述。

批判性阅读强调对证据负责，也要求避免没有依据的个人指责。

## 19.10 一张批判性阅读检查表

| 方面 | 核心问题 |
| --- | --- |
| 问题 | 研究目的和主要结局是否清楚？ |
| 样本 | 来源和选择过程是否可能引入偏倚？ |
| 测量 | 变量定义与数据质量是否可靠？ |
| 方法 | 分析是否适合设计？是否有信息泄漏？ |
| 推断 | 是否报告效应量、不确定性和必要校正？ |
| 稳健性 | 结论是否经合理验证与敏感性分析？ |
| 解释 | 是否把关联过度描述为因果？ |
| 透明性 | 有无充分的方法、数据或代码说明？ |

这张表帮助提出问题，不是自动计算“论文质量总分”的公式。

## 19.11 本章实践：比较三篇结果不一致的论文

围绕同一个问题选取三篇研究，分别写出样本、方法、主要结果、潜在偏倚和结论范围。随后说明，它们的差异可能来自什么？哪些额外证据最有助于解决争议？

最后写出一段200字的综合判断，避免简单地宣布某篇论文绝对正确。

## 用同一套问题比较三项矛盾结果

假设研究A报道某种微生物与疾病风险呈正相关，研究B没有复现，研究C却观察到相反方向。最容易作出的反应，是选择期刊影响因子最高的一篇作为“正确答案”。这种做法忽略了不同研究之间可能存在的人群、测量和分析差异。

应该先制作比较表，分别列出样本来源、年龄和用药情况、研究设计、物种检测方法、协变量控制、统计模型与多重比较策略。如果研究A主要来自单一医院，B来自不同地区，C包含不同的治疗阶段，那么三者表面上研究同一个问题，实际估计目标可能并不一致。

接下来判断差异是否可能来自真实异质性。如果不同人群的饮食、生活方式或疾病阶段确实影响目标关系，那么“某个关联只在特定条件下出现”本身也可能是值得研究的发现。当然，观察到不同方向还不能自动证明存在真实的生物学异质性，需要进一步的统一分析和独立验证。

最终写出的综合判断，应使用与证据相称的语言。例如：“现有观察性研究对关联方向尚不一致，研究人群、测量和统计处理差异可能部分解释结果变化；目前不足以确定该特征在所有人群中的稳定关联。”这比简单评价“研究A有用，B和C可能不对”更接近科学推断。

## 批判性阅读中常见的两种极端

第一种极端是无条件相信论文。看到一篇研究发表在知名期刊，就默认样本、分析与结论全部可靠。第二种极端是为了显示批判性思维，对所有没有自己完全理解的研究都使用否定性语言。这两种做法实际上都跳过了公平评价证据的过程。

更成熟的态度是先解释研究问题和实际设计，再指出可以核实的限制，最后说明这些限制对结论的影响程度。比如“缺少独立验证”会影响对模型可推广性的判断，但未必否定其作为初步方法学研究的全部价值。批评的目标应当是更准确地理解研究，而不是证明自己的观点比作者更高明。

## 本章小结

批判性阅读的价值，在于让研究者既能理解已有成果，也能看清它们的边界。科学的进步不依赖无条件相信权威，也不依赖对一切研究的否定，而依赖公平、可检查的证据判断。
